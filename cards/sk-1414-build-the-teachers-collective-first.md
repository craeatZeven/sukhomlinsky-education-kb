# Card sk-1414 — 要培养集体，先培养教师集体

## 原文/Excerpt

> 为了培养学生集体，我们就要培养自己——教师集体。我们对知识的追求、我们的求知欲、我们孜孜不倦的劳动、我们在思想领域和书籍世界中的丰富阅历—只有这些才能使学生集体产生智力上的需求，培养集体的方法和兴趣，激发他们的智力，发展他们的禀赋和才能。

校勘记录（已校勘 3 处，改前→改后）：

- 自已→自己
- 了培养学生集体→为了培养学生集体
- 忘法→方法

## 中文转述/说明

要建学生集体，**先建教师集体** —— 教师自己对知识的追求、求知欲和阅历，才是学生智力需求的来源。

## 教育场景/应用

教研组的读书与讨论不是形式：学生的智力生活从那里长出来。
