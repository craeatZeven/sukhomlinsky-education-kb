## 三、判据先验过（这一步比结果重要）

第一版跑出 **1,326 组「疑似同源」**，看着像发现了大问题。看 Top 命中才发现全是
**卷首总目录 / 后记 / 版权页**（每卷都印同一份「1. 《全面发展的人的培养问题》①」，100% 重叠）。
→ 判据本身要修：**排除卷首卷尾 + 要求小节足够大**（shingle ≥150）。修完：**39 组 / 11 个类**，
Top 命中变成真正的平行文本。**「先验判据，再看结论」——否则 1,326 这个数字会直接把人带偏。**

## 五、结论：剩余量是**上限**

- 旧口径（按章节）给出的"剩余 ~113 章"**没有扣这些同源重复**，是**上限**。
