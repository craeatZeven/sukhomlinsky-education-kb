# Card sk-2303 — 教育的智慧，在于发掘每个人创造性劳动的独特源泉

## 原文/Excerpt

> 对一个生来身心都健康的人，我们决不能说他无所作为。共产主义教育的智慧和真正的人道在于，发掘每个人身上的创造性劳动的独特的源泉；帮助每个人观察自己，感知自己的这种独特性，帮助他们成为精神上坚强的、不可战胜的自我奋斗的战士。

## 中文转述/说明

这段话针对的是一种很省事的判断：把某个孩子归入「没什么出息」那一类。作者不接受这种判断，理由不是安慰，而是每个人身上都有一处别人替代不了的擅长；教育的本事就在于把它找出来，还要让孩子自己看得见这处与众不同。看得见之后，他才有撑住自己的支点，遇到挫折也不会整体否定自己。所以这里的关键动作有两个：教师负责发现与指出，学生负责把它认下来，两者缺一，劳动就只剩完成任务。

## 教育场景/应用

- 给每个学生建档，记录他不费力就能做好的具体事情（修锁、配饲料、给同学讲透一道题），每学期补一次。
- 布置任务时留出可由学生自选做法和成果形式的余地，让他的门道有地方施展。
- 对已经认定自己「什么都不行」的学生，先用一件小而能做成的事把证据摆在他面前，再谈长远目标。
