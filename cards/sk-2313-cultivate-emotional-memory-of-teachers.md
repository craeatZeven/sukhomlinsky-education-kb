# Card sk-2313 — 敏锐的情感与记住学生的能力，是教师可以培育出来的

## 原文/Excerpt

> 我们工作的时间过得很快，我们与学生的交往也稍纵即逝，但并非无影无踪：它们保留在我们的记忆里，镌刻在我们追忆往事的激动的心坎里。它们越是鲜明，越是更深更多地铭记在心，学生的吸引力就越强烈，与他们新的交往带来的快乐就越深沉，在新一届学生身上发现的特点就越多。教师敏锐和丰富的情感，教帅在心里铭记和保存与学生交往情景的能力，是可以获得的，是能够在自己的教育生涯中培育出来的。

## 中文转述/说明

这里讲的不是天赋，而是一种可以练出来的职业能力：把与学生相处的时刻真正存进记忆。交往本身很快就会过去，但它在教师心里留下多少痕迹，决定了他后面还能看见学生多少。记忆里的情景越鲜明、越具体，学生在他眼里就越有吸引力，新一届学生身上的特点也越容易被发现。反过来，如果这些交往在记忆里没留下东西，教师就慢慢只剩下一套讲了多年的老话。所以「记住孩子」不是多愁善感，而是教师修养的一部分，值得当成一项功课去经营。

## 教育场景/应用

- 每周留十分钟，写下本周记住的两三个具体场面（谁说了什么、当时是什么表情），不问对错只求具体。
- 与同一个学生相隔几个月的两次谈话之间，翻一次旧记录，看他身上新出现的东西，而不是只对旧印象。
- 教研活动里交流「你记得这个孩子什么」，把记住学生当作教师修养来练，而不是当作闲谈。
