# Card sk-1388 — 怎样培养父辈和孩子们之间的和谐关系

## 原文/Excerpt

> 人世间几代人—年老的一代、创造力旺盛的一代，还有刚刚问世仅仅开始意识到自已存在的新一代，同时生活在这个世界里。……无论你成了什么人物和将来成了什么人物，你必须敬重老一辈。……尊重、敬慕老一辈，这是我们生活的法则。之所以应当尊重老人，是因为他们比你聪明，精神上比你富有。在跟长辈交往的时时刻刻，都要善于向他们学习。……这些教诲在培养两代人之间(父辈与孩子们之间)的和谐关系上起到非常重要的作用。我认为有一点十分重要、就是使少先队员们和共青团员们都能理解老--辈的智慧价值。……在你未将自己的激情传输给年轻一代时，不应让任何一种明暂思想悄然消逝，不应让任何一种深刻的道德信念熄灭。……那些有如太阳已近地平线的老年人，正是我的学生们最聪明的老师。他们每讲到祖国的神圣时刻，总是把爱和恨的火焰、战士的激情灌输到少年心灵中去；他们的每句话，都是即将离别的遗教和赠言。

## 中文转述/说明

这一节回答的是“和谐关系从哪儿来”这个问题。苏霍姆林斯基先摆出代际结构：年老的一代、创造力旺盛的一代、刚开始意识到自己存在的新一代同时生活在一个世界里，一个人的父母也是别人的孩子，人类种族就这样代代相传。由此得出法则——敬重老一辈，因为他们比你聪明、精神上比你富有；与长辈交往的时刻都要善于向他们学习，不要自以为是、过于自信。

方法层的关键在于“把智慧价值讲给年轻人听”。他特别指出，教育者要做的一件事是使少先队员和共青团员理解老一辈智慧的价值，在把激情传给年轻一代的同时，不让任何明智思想和深刻道德信念熄灭。他把“有如太阳已近地平线的老年人”称为学生们最聪明的老师：他们讲到祖国的神圣时刻，会把爱和恨的火焰、战士的激情灌输到少年心里，他们的话是即将离别的遗教和赠言。

这一节结尾还有一个贯穿全篇的支点——成年人自身就是“调准孩子们信念的一种音叉”：我们的个人品行、思想方法、彼此间的关系以及社会的道德价值，共同决定孩子会形成什么样的信念。如果话与行为脱节，就会培养出两面三刀的人，也会把整个老一代人装进被扭曲的镜子里；不尊重别人的孩子，也不可能尊重真理。所以代际和谐不是要求孩子单向服从，而是成人先做到值得尊敬。

## 教育场景/应用

- 与 sk-0089（现有卡）连读：sk-0089 是实践卡，逐条整理“十不准”这份行为清单并给出家校公约的改写建议；本卡取原则与方法层，回答“为什么要敬重老一辈”“和谐关系靠什么机制维持”，落点是理解老一辈智慧的价值和成人做“音叉”这两条，不重复清单本身。
- 组织学生采访祖辈或社区老人，重点不是记录事迹，而是让学生说出“他哪一点比我聪明、比我精神富有”，把尊重从礼貌升级为承认智慧。
- 家长会可用“音叉”这个比喻做自查：我们在孩子面前说的话和我们的行为是否一致；一旦脱节，孩子学到的是表演而不是信念。- 邀请老人进课堂时避免变成表演式活动，让老人讲他们真正经历过、带着情感的时刻，而不是背材料。
- 用于处理代际冲突：把“准不准”的争执转成“先听完再判断”，先请长辈发言，再讨论分歧。
- 与 sk-1188（现有卡）连读：sk-1188 落在敬老的具体制度与祖孙精神交流，本卡补出代际三层的整体框架与成人示范机制，两者可组成“结构—制度”的完整读法。
