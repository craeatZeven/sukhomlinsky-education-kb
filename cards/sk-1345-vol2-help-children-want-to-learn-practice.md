# Card sk-1345 — 为使儿童愿意好好学习该做些什么

## 原文/Excerpt

> 我坚信，儿童脑力劳动的人道化，使这种劳动巾于想要给亲爱的妈妈和爸爸带来快乐而高尚起来。这是推动儿童自觉而勤奋地从事脑力劳动最有力和最强大的刺激力。……四年级学生科利亚有一天说：“我应该好好学习，妈妈有心脏病。”这孩子感到，假如他的成绩单上出现了不及格的分数，母亲的心是会难过的。如果你想使儿童愿意好好学习，并力图以此给母亲和父亲带来快乐，那就要珍惜、爱护和发展他作为劳动者的自豪感，这就是说，儿童应看到和体验到白己的学习成绩。不可让儿童由于落后或有什么不行而感到尤穷的痛苦。儿童的乐观主义、对白己的力量有信心，是把学校和家庭联结起来的一条结实的绳索，足把母亲和父亲吸到学校方面来的一块磁石。……要让母亲和父亲，形象地说，站在儿童知识的摇篮旁，直接参与他的学习，同他一道为他的成绩而高兴，对他的成功和不快表现出由衷的关切。……我们力图让父母明白：学业成绩的评分，并不表示道德品质的评分。违反这点，就会给儿童造成很深的创伤，有时会摧残儿童的心：把学科评分和道德面貌等同起来，就是不假思索地追求表面上不错的指标-数字。我们认为，不可把一切结为一个简单的结论：分数好，孩子就好；分数“不合要求”，就等于学生“没有达到水平”。……应当坚定地告诉自己，3分表明知识完全合格。……家长也不会要求自己孩斤F做不到的事情，要知道，不是所有的儿童都具有同等的能力：一个儿童的学习能轻易地得到“5分”或“4分”，而另一·个儿童能得到“3分”就是不小的成绩了

## 中文转述/说明

让孩子愿意学习的第一个做法，是把学习动机接到家庭情感上：儿童脑力劳动的人道化，在于他想给妈妈爸爸带来快乐。科利亚说“我应该好好学习，妈妈有心脏病”，他并不是被分数驱动，而是知道自己的劳动能让母亲安心。所以教师要珍惜、爱护和发展孩子作为劳动者的自豪感，让他看得见、体验得到自己的成绩，不能让他因为落后而陷入无穷的痛苦。孩子的乐观主义和对自己力量的信心，是把家庭和学校系在一起的那条结实绳索。

第二个做法是让家长真正站到“儿童知识的摇篮旁”：直接参与孩子的学习，为他的成绩高兴，对他的成功与不快都表现出由衷的关切。苏霍姆林斯基介绍的具体安排是——上学前两年就开始家校共同工作，未来学生每周到校一次（入学前半年每周两次），由将来教他们的教师带着学字母、读和算；同时给家长上课，教母亲父亲、祖母祖父怎样在家继续教，方法的基础是培养对知识和书本的热烈兴趣、让游戏和有目的的脑力劳动结合、家长与儿童经常思想交往。这样做还能防止家长产生“狠狠压一下就能得5分”的想法。

第三个、也是最要紧的说法：评分不等于道德评价。家长必须明白，学业成绩的评分并不表示道德品质的评分；把学科评分和道德面貌等同起来，就是不假思索地追求表面上不错的指标数字，会给儿童造成很深的创伤。不能得出“分数好，孩子就好；分数不合要求就等于学生没达到水平”这种结论。

第四个做法是纠正对“3分”的舆论：教师应当坚定地告诉自己，3分表明知识完全合格。如果所有教师对这件事都有正确看法，蒙混过关的现象就会绝迹——不及格的知识不会被评定为3分。家长也不会再要求孩子做他做不到的事，因为不是所有儿童都有同等能力：一个孩子轻易得5分或4分，另一个孩子能得到3分就已经是不小的成绩。

## 教育场景/应用

- 家长会上讲清楚一句话并反复讲：“评分不是品德评分。”让家长把“你怎么又考这么点分”换成“这次哪些地方你觉得比上次有进步”。
- 给孩子设计能“看见”的成绩：把单元进步、作业改正、阅读量等做成可对照的记录，让落后的孩子也有劳动者的自豪感。
- 学前与低年级衔接：入学前半年到两年安排家长参与识字与算术的共同教学，给祖辈也讲清方法，避免家里用“压一下”的方式抢跑。
- 教师内部统一评分口径：3分代表知识完全合格，不及格的知识不评3分；不要用分数给孩子下道德判决。
- 家访或个别沟通时，先报孩子具体的努力与进展，再谈分数，防止孩子把成绩单和母亲的心脏、眼泪绑在一起。
- 与 sk-0180（principle）、sk-0182（principle）连读：那两张分别确立了“学业评分不是道德评分”的原则和“3分是合格、儿童能力不等”的原则；本卡给出的是把它们落到家校日常说法与做法上的操作细节——家长怎么参与学习、教师怎么统一评分口径、孩子怎么看见自己的成绩。
