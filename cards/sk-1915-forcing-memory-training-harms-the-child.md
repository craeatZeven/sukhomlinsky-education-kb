# Card sk-1915 — 能力差的学生不只是记性差

## 原文/Excerpt

> 生活随时随地告诉我们，能力差的学生，并不单纯就是记忆力降低的儿童。这些儿童的思维处于一种受抑制的、静止不动的、“僵化的”状态之中。也有过这样的时候：我尝试用直接对记忆施加影响的办法来改善他们的思维能力。但是这些尝试都完全归于失败了。

## 中文转述/说明

这段先把诊断改对了：能力差的学生并不只是记忆力降低，他们的思维处于一种受抑制的、静止不动的、「僵化的」状态。既然问题不在记忆这一环，对记忆直接施加影响的办法就注定失败——作者说自己试过，全部归于失败。紧随其后的那句结论落在下一个 unit（本卡未收，见卡内说明）：强迫儿童背诵、要他把背过的东西再现出来，用这种办法「锻炼」记忆力是不行的，而且对孩子有害——神经系统和整个机体极度疲劳，记忆反而更坏，因为破坏了记忆与脑内许多过程那个大系统之间的和谐。教学上「多背几遍」的直觉，在这里被同一段论证判为既无效又有损伤。

## 教育场景/应用

- 面对一个越是多背越退步的孩子，先停止加练，改为记录他的疲劳、情绪和遗忘曲线，把证据摆给家长看。
- 课堂上区分两类困难：真记不住，与「记住了但一动手思考就丢掉」。后者要减少同时负荷，而不是延长重复时间。
- 教研组把「每天留堂重背」这类常规做法拿出来审一遍，逐条对照是否在破坏记忆与其余过程的协调。
