# Card sk-2580 — 分析能力离开实际就只剩模仿：技术思考来自体力与脑力的结合

## 原文/Excerpt

> 如果一个学生的分析能力不是在紧密联系实际的基础上发展起来的，他就会不顾实际需要，模仿地去进行某种实践活动，而这里需要的恰恰是认真思考和认真设想。尤其在进行机器的修理和复原的过程中，解决那些设计性的问题时，进行智力方面的实验具有更为重大的意义。这里必须把零件之间的具体的相互关系和相互作用搞得十分清楚明白。是否具有这种技术方面的思考能力，取决于这个人在从事劳动时是否曾经把体力与脑力紧密地结合在一起。

## 中文转述/说明

他把「分析能力」从纸面拉回到劳动现场：如果分析不是在实际材料和真实需要上长出来的，学生就会不看需要、照搬模仿地做——而恰恰这种场合最需要认真思考和认真设想。修理、复原机器时，「智力实验」比手上动作更要紧：必须把零件之间具体的相互关系和相互作用搞清楚。结论落在一句很硬的话上：有没有技术性的思考能力，取决于这个人劳动时是否曾经把体力与脑力真正结合起来。教学上的含义是双向的：脱离操作的思维训练容易变成套路，而动手劳动若不要求解释「为什么这样装、这样修」，也只是一项体力活。

## 教育场景/应用

- 上实验课或劳动课前，先让学生写下「可能出现故障的两种原因」和怎样区分，再动手。
- 拆装时要求学生边做边口述零件之间的相互关系，教师只追问「你怎么知道的」。
- 评价一次操作，不只看结果对不对，还看学生能否说出自己排除错误假设的过程。
