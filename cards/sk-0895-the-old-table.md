# Card sk-0895 — 一张旧桌子

## 原文/Excerpt

> 在城边的一栋小房子里住着一个大家庭……房子中有一间儿童室。那里放着一张用松木做的旧桌子。他们既在桌上做功课，又在桌上做手工。可以在桌上放满工具，可以在桌上削木片、粘东西、锯木头、敲钉子。在这张桌上男孩子们制作了一架飞机——真正的，带小马达的飞机。每天，都有很多朋友到科利亚和他哥哥这里来。大家一起做功课，一起制作机器，很有意思。……在新的刚建成的高楼里分给了他们一套房子。……父亲为新住宅买了新家具：抛光的桌子、沙发、书橱、椅子。……旧家具——书橱、椅子，以及旧桌子，已经无处可放了。它们被搬到院子里，一把火烧掉了。旧松木快乐地燃烧着，妈妈却哭了。……“在这张桌子上不许做手工，只能做功课。但是，在放上练习本和课本之前，必须用纸盖好桌子。”“那么，孩子们还可以来吗？”科利亚问。“可以，不过，最好你们到他们那里去。”科利亚在大大的抛光桌子边坐下，忧伤地、遗憾地回想起那只松木制作的旧桌子。

## 中文转述/说明

一张松木旧桌子既是课桌又是工作台：孩子们在上面削木片、粘东西、锯木头、敲钉子，还做出一架带小马达的真飞机；朋友们每天聚到这里，一起做功课、一起做机器。全家搬进新楼、换上抛光家具后，旧桌子被搬到院子里烧掉——旧松木烧得很快乐，妈妈却哭了。新房里那张光亮的桌子只许做功课，还要先铺上纸，工具被收进箱子；科利亚问“孩子们还可以来吗”，妈妈建议他们到别人家去。最后科利亚坐在新桌边，忧伤地怀念那张旧桌子。

故事触及家庭教育中一个容易被忽略的问题：物质条件变好，如果同时收走了孩子动手、弄乱、和朋友一起创造的空间，反而可能让教育变窄。旧桌子承载的是劳动、友谊和共同成长的记忆。

## 教育场景/应用

- 可用于家校沟通：提醒家长在改善学习环境时，别把“干净整洁”变成禁止动手和同伴交往的理由。
- 可用于劳动教育：在家中或教室保留一个可以锯、粘、敲、拆的“工作角”，让孩子的创造有落地的地方。
- 可用于亲子讨论：和孩子一起找出家里某件旧物背后的故事，理解物品承载的记忆与情感。
- 可用于班级建设：讨论班级公共物品（图书角、工具柜）怎样既保持整洁又对所有人开放。
