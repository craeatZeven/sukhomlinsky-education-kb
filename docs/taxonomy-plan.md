> 出发点：**内容最重要**。分类不是给网站做导航的架子，而是「他和这些卡片实际上在谈什么」的准确表达。
> 数据脚本在 gitignored `local_working_copy/`：`taxonomy_diagnosis.py`、`concept_census.py`、`taxonomy_v2_experiment.py`、`story_organization.py`。

## 二、定稿结构：五层范畴 + 复分

不借生物学的字，**用教育学自己的范畴命名层级**，并且让每个层名自带它要回答的问题——层名本身就是内容：

| 层级 | 名称 | 回答的问题 | 数量 |
|---|---|---|---|
| 一 | **宗旨** | 教育要把孩子培养成什么样的人？ | 4 条 |
| 二 | **立场** | 怎么看待儿童、怎么对待儿童？ | 3 条 |
| 三 | **场域** | 教育在哪里发生、由谁承担？ | 3 条 |
| 四 | **内容与方法** | 教什么、怎么教？ | 5 条 |
| 五 | **衡量** | 怎么反馈、怎么评价？ | 2 条 |
| 复分 | **关照** | 面向哪一类具体孩子（可复用到以上各层之下） | 1 条 |

从上到下正好是「从为什么教 → 到怎么衡量」，方向感自带。**一层套一层，位置固定**——这才是「地图」能成立的前提。

```
形态 (2)   论述（他论教育，718 张）   故事（他写给孩子，668 张）
  │
  ├─ 论述
  │    范畴 (5)  宗旨 · 立场 · 场域 · 内容与方法 · 衡量
  │      条目 (18)  A1–A18（A18 关照为复分条目，可跨界出现）
  │        子目     每条目下 2–5 个（见 §三示例）
  │          卡片
  │
  └─ 故事
       组织 (3)  通读（原书顺序）· 处境（8 个）· 主角（5 个）
         子目     每一篇故事
```

**「宗旨」的处理**：宗旨层（A1–A4 + A19）在导航与地图上是独立一层（一级入口），**不作为并列筛选复选框**——它是纲，不该跟「评价与分数」平起平坐。筛选器里保留一个「宗旨」折叠组，需要时展开。
> **2026-09-10 修订**：A1 原设计为「总纲页、不持卡」，经外部评审后**恢复持卡**（实测 3 张）——共现多不等于没有中心论点；一个准确的小条目好过把它并进邻居。

**「关照」的处理**：学到图书馆学的现成做法——**复分**。学习困难学生是对**特定一类孩子**的关照，它横向复用到宗旨/立场/场域/内容/衡量之下，**不参与面积统计**（否则会把主归属重复计数）。

## 四、故事：按「处境 + 主角」分面

**为什么不能按教育主题切**：用品格词扫 668 篇故事是长尾——妈妈 31%、美 17%、劳动 11%，其余全部 <6%（诚实 1.2%、勇敢 2.2%、分享 0.7%）。这些故事**每篇是独立情境**，不是主题的例证。

**为什么「处境 + 主角」成立**：同样扫一遍分面词，**99% 的故事至少落进一个分面**（对比主题词只有 75%）：

| 分面 | 篇数 | 占比 |
|---|---|---|
| 处境：自然与季节 | 428 | 64.1% |
| 主角：母亲与家人 | 367 | 54.9% |
| 处境：美与歌 | 307 | 46.0% |
| 处境：劳动 | 224 | 33.5% |
| 处境：帮助他人 | 165 | 24.7% |
| 主角：动物 | 163 | 24.4% |
| 主角：成人（教师/司机/农艺师…） | 144 | 21.6% |
| 处境：学校与学习 | 136 | 20.4% |
| 主角：同伴 | 126 | 18.9% |
| 处境：离别与非 | 110 | 16.5% |
| 处境：恐惧与害怕 | 90 | 13.5% |
| 处境：羞愧与良心 | 79 | 11.8% |
| 主角：老人 | 59 | 8.8% |

**关键理由**：老师家长的检索意图是「**孩子怕黑**」「**想讲妈妈的故事**」——处境与主角比抽象主题更接近真实问题。

**三层组织**：
1. **通读**：按原书页码顺序读完 541 篇（现有 `stories.html` 已如此，保留）；
2. **处境 / 主角**：上面 13 个分面（新增筛选）；
3. **选集**：10–20 组人工策展，按**使用场景**组织（「一年级开学第一周」「亲子共读十分钟」「第一次面对失去」），带导读。

**故事卡仍保留教育条目作次标签**（搜索「诚实」能命中相关故事），但**不参与主归属与地图面积**。

**篇幅数据**：中位数 222 字，四分位 126–301 字，最长 804 字——都是 1–3 分钟能读完的短篇。**发现 1 篇摘录为空（0 字），迁移时一并核查。**

## 五、验证：分配规则（三轮实验才定稿）

| 规则 | 论述体分配 | A11 劳动与创造 | 最大条目 | 问题 |
|---|---|---|---|---|
| ① 纯关键词 IDF | 710 / 718 | 51 张 | 89（12.5%） | **会漏掉 66 张**（旧标签说是劳动教育，正文却没有"劳动"二字，如《永远的白杨树》《懒骨头和太阳》）；IDF 偏袒窄条目，"劳动使思维觉醒"被判给 A15 |

（首选权重 1.0、次选 0.4）；一张卡带多个旧标签时按权重取最高；**权重相同才用关键词 IDF 定夺**。

A5 尊严爱与信任 117 · A10 教师 84 · A6 了解儿童 83 · A8 家庭与母亲 75 · A9 集体与同伴 68 ·
A11 劳动与创造 65 · A15 思维与智力 60 · A13 阅读与书籍 43 · A7 健康与作息 35 ·
A18 学习困难 33 · A14 美与艺术 32 · A16 评价与分数 23（A1–A4、A12、A17 为小条目）

**与旧分类对照**：最大条目占比 **41.9% → 16.3%**；论述体唯一主归属 **9.0% → 100%**。

## 五·补、路径验收：以「他对劳动教育的看法」为例

（用户提的验收问题，实测见 `path_test_labor.py`）

**旧路径**：点「劳动教育」标签 → 225 张。

**新路径必须带上三件套，缺一个就会退步**：

| 件 | 内容 | 张数 |
|---|---|---|
| ① 条目页 A11「劳动与创造」 | 人工标签认定的核心 | **65 张** |
| ② **参见区（必备）** | 其他条目里同时谈劳动的卡，按条目列出：思维与智力 46 · 幸福与精神生活 43 · 家庭与母亲 28 · 尊严爱与信任 24 · 公民与祖国 21 · 健康与作息 20 … | **+311 张** |
| ③ 故事 · 处境「劳动」分面 | 故事里的劳动 | **85 篇** |
| ④ 全文兜底（可选） | 「查看全部提到劳动的卡片」 | 447 张 |

**结论：能找到，且更全（447 张 ≈ 旧路径的两倍），但条目页必须有「参见区」**——
只给 65 张核心卡，读者会感觉比以前的 225 张还少。

**这次验收改写了迁移规则**：主归属必须以人工旧标签为主证据；纯关键词法会丢掉 29% 的劳动教育卡。

## 六、一次性切换的迁移步骤（决策 4：不保留旧 slug 并存）

每步跑 `python scripts/validate_all.py`，任一步失败即停。

| 步 | 动作 | 产物 / 验证 |
|---|---|---|
| 1 | 新建 `taxonomy.yml`：5 范畴 + 18 条目 + 13 故事分面 + **旧主题→新条目映射表**（含首选/次选权重） | 单一事实源，页面与脚本都读它 |
| 2 | `scripts/classify_cards.py`：**以旧标签权重为主、关键词 IDF 定夺冲突**，给每张卡写 `primary`（论述）或 `story_facets`（故事） | 建议值 + 复核清单（权重相同、由关键词决定的卡） |
| 3 | 人工复核约 150–200 张，抽检与修正 | 修订写回 `taxonomy.yml` 的例外表 |
| 4 | 卡片 frontmatter 重写：`topics:` → `primary` + `facets`；**旧 12 个 slug 全部删除** | `check_kb.py` 校验 frontmatter |
| 5 | 生成 19 条目页 + 5 范畴页 + 14 故事分面页（`topics/` 目录重写） | 每页含「收录什么 / 不收录什么」判定规则 |

| 8 | 文档同步：`docs/kb-status.md`、`INDEX.md`、`SKILL.md`、`web/README.md` | 全链路 ALL OK |

**外部影响提醒**：`explore.html?topic=<旧slug>` 这类站外链接会失效（一次性切换的代价，已接受）。Pages 不支持 301，故只在站内做一次「旧地址 → 新地址」的提示页。

## 八、验证门槛（写进 `validate_all.py`）

> **2026-09-10 修订**：原第 2、3 条（每条 15–200 张、最大条目 ≤20%）经 GPT 评审后**降级为观察指标**，
> 不再作正确性门槛——"一个准确的大条目胜过几个为分布好看而扩张边界的小条目"。

1. 每张卡有且只有一个 `primary`（论述）或落进故事分面之一；
2. **（观察指标）** 条目主归属分布是否均衡、最大条目占比——用于发现异常，不用于判定对错；
3. 故事分面覆盖率 ≥ 95%；
4. **每个条目页都有「参见区」**（列出同时谈该主题的其他条目及张数）——路径验收（§五·补）证明缺了它会退步；
5. **盲审抽样**：从"由旧标签直接认定"的卡片中分层抽样 100 张，隐藏旧标签与算法答案独立判定，
   错误率与错误模式写入 `docs/classification-audit.md`；
6. 无摘录为空的卡片（当前已修为 0）。

### 9.2 三条设计批评

**(1) 取消「五层教育学层级」的宣称。** 宗旨/立场/场域/方法/评价是观察教育的**不同角度**，
不是逐级包含的分类树；「场域」还混了地点、关系与职业主体。
→ **部分采纳**：表述改为「五个观察角度」；`场域` 改名 `教育关系与组织`；
A7 健康与作息、A17 习惯与纪律移入「内容与方法」；A16 留在「衡量」。
**但层名是用户拍板要的（教育学范畴命名），改表述前先跟用户确认。**

**(2) 新增 A19 道德判断与品德培养；恢复 A1 持卡；A18 改为纯对象标签。**
一般德育（辨善恶、待人分寸、善行培养、道德认同）在现体系里确实缺位——散在 A5/A4/A17 之间；
A1 只有 2 张也构成准确的小条目，**共现多不等于没有中心论点**；
A18 不能一面声称不参与分区、一面分走 17 张卡。
→ **采纳**：新增 A19；恢复 A1 持卡；A18 改为复分标签（每张相关卡另有内容主归属）。

**(3) 故事分面改成多值字段。** 奶奶既是家人也是老人；帮助同伴的故事可能同时发生在学校。
→ **采纳**：改为「角色 / 场景 / 核心事件或情绪」三个字段可多选；S10「离别与非」拆为
「离别与思念」与「死亡与哀伤」；自动标注收紧（「出现黑夜」≠恐惧，「出现送」≠帮助）。

### 9.3 根本质疑：把「分配完成」当成了「分类可靠」（接受）

> 旧标签已被认定存在大量混装，却又被当作新主归属的最可信证据；只有候选范围完全没命中时才允许
> 跳出范围——一张真正属于 A2 的卡，只要碰巧命中旧范围里的泛词，就没有纠错机会。
> 所谓「703 张无需复核」因此不成立。

**我的补充（保留意见）**：旧标签的问题是**「粗」而非「错」**——单看一张卡，"它属于爱的教育"通常
是对的；错的是这套标签不是分区（41.9% 覆盖率、91% 跨类）。所以它**不是错误数据，而是无法自我纠错的先验**：
当候选范围合理，当免于复核的理由不合理。

**处置（写进流程）**：① 从 703 张分层抽样 **100 张盲审**（隐藏旧标签与算法答案）；
② 发现错误后复核同一映射路径的**全部**卡片；③ 旧标签降为候选线索，主归属依据"这张卡主要提出什么
主张、解释什么机制"，保留人工覆盖记录与待审状态；④ 分布指标降级为观察值；
⑤ 地图面积须标注为**「编辑主归属分布」**，不得解释为"思想各部分的比重"。

### 9.4 它指出的输入质量问题（我的疏漏）

打包给它的转述被截断（160 字）、出处被截断（90 字）；材料里混了两个版本的数字
（最大条目 11.7% / 13.1%，A17 是 4 还是 5，A18 是 14 还是 17）——中途扩充过关键词，
两份产物不同步；sk-0425 的转述把 communism 解释为「共同的幸福理想」，**编辑解释可能反向制造分类证据**。

**处置**：复核材料改为**引用完整卡文**（不截断）+ 统一版本号，并明确区分「原文 / 编辑转述 / 算法输入」。
