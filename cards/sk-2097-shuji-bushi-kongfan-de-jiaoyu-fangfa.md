# Card sk-2097 — 把优秀书籍和教师的语言说成空泛的教育方法，是扣错了帽子

## 原文/Excerpt

> 空泛的教育方法—这样的帽子有时也扣在没有它便不可能形成人的心灵的事物上，扣在教师的生动语言上，扣在激荡人的头脑和心灵的优秀书籍上。让我们来回忆一下季米特洛夫关于自己少年时代的一段叙述。阅读车尔尼雪夫斯基的长篇小说《怎么办?》，在他的个人生活中激发出多少焦虑和沉思啊！

> 说明：引文为原 unit 切片（133 字）：起点是完整句「空泛的教育方法—这样的帽子…」，终点是完整句「…激发出多少焦虑和沉思啊！」；该 unit 首句「能受到教育，而当他阅读书籍时，这不是教育。」承接上一 unit 的残句，故未纳入引文。无讹字，fixes 为空。本卡原拟用同章 unit 0018（谈杰出人物的书籍），因 10 字窗与已有卡 sk-1267《公民的起点》的套语「是最重要的教育任务之」重合而弃用，改选本 unit。复核：10 字窗 0 命中；12 字窗 0 命中。

## 中文转述/说明

作者在这里替书籍和教师的语言辩护：有人把「空泛的教育方法」这顶帽子扣在它们头上，但恰恰是它们能形成人的心灵。他随后举了保加利亚革命者季米特洛夫少年时代的例子——读车尔尼雪夫斯基的《怎么办?》在他心里激起大量焦虑和沉思，说明一本书的作用是实打实的，只是它不体现在分数和劳动成果上。对教师的含义是，别用立竿见影的标准衡量阅读，衡量它的应是学生内心是否起了波动。

## 教育场景/应用

- 听到同事说读课外书是不务正业、空谈时，用学生内心的实际变化来回应，而不是跟着压缩阅读时间。
- 推荐一本书后，关注学生是否因此开始自己琢磨问题，而不只看他能否复述情节。
- 记录那些让学生久久不安或反复回想的阅读，把它们当作教育起作用的证据。
