# Card sk-1240 — 请记住，没有也不可能有抽象的学生

## 原文/Excerpt

> 不能要求学生做他做不到的事。任何一门课程的教学大纲，只不过是一定水平和一定范围的知识，而不是活生生的儿童。不同的学生，是以不同的方式达到这种水平和掌握这个范围的知识的。……教育和教学的艺术和技艺，是发挥每个学生的力量和可能性，使他们感到在脑力劳动中取得成绩的喜悦。这就是说，在学习方面应予个别对待，不仅在脑力劳动的内容（习题的性质）上如此，在时间上也是如此，有经验的教师在-节课上给一·些学生两三道甚至四道题，而给另一些学生仅仅一·道题。一个学生的题较复杂，而另一个学生的题则较简单。……儿童从作业的得分中看到了自已的劳动和努力，学习给他带来精神上的满足和获得知识的喜悦。……他这样讲述他的备课情况：“我仔细考虑每个学生将做些什么。我为所有的学生挑选他们都能做好的作业。如果学生在掌握知识的道路，上没迈出哪怕是小小的--步，那对他来说，这是-堂无益的课。无效的劳动，大概是学生和教师都面临的最大的潜在危险。”……请看看帕夫雷什中学的教师阿·格·阿里申柯和姆·阿·雷萨克的数学课。在解题时（解题占90%的时间），他们的班似乎分成了几个组。第-组是成绩最好的学生，他们不需要任何帮助就能轻而易举地解答任何习题。……对这个组，除大纲规定的习题外，教师还选择超出大纲范围的材料。要给这些学生的头脑以力所能及的、但不是轻而易举而是需要经过努力才能完成的作业。……第二组是勤奋努力的学生，对他们来说，出色地完成任务需要经过紧张的脑力劳动、探求和克服困难。……第四组学生理解和做习题都很缓慢。他们在一堂课上比第二、第一组学生可能少做一半或2/3的习题，但对他们无论如何不能催促。……第五组是个别学生，他们不能解答中等难度的习题。教师要专门为他们选一些能使他们取得哪怕成绩不大的习题。……你可以在学生的眼神里看到时而精神高度集中，时而进发出喜悦的火花（找到了正确的路子），时而沉思默想(从哪个方面解题)。

## 中文转述/说明

这一节的重点不是“因材施教”这个结论，而是它在一堂课里怎么落地：同一份大纲、同一个知识点，作业要在难度和数量上分档。苏霍姆林斯基举出的实例是帕夫雷什中学阿里申柯与雷萨克的数学课——解题占课堂90%的时间，班内分成若干组：成绩最好的学生除了大纲习题，还拿超出大纲的材料，作业要“经过努力才能完成”，偶尔甚至给一道不能独立解答的题，教师只稍加指点；勤奋型学生独立完成中等难度、复杂题需帮助；理解缓慢的一组一节课比前两组少做一半甚至三分之二，但“无论如何不能催促”；还有个别学生解不了中等难度的题，教师专门为他们挑选能取得哪怕很小成绩的题。

分档的关键不是标签，而是三件事同时被调整：题的难度（简单/中等/复杂）、题的数量（一道到三四道）、允许的时间。文中明确说个别对待“不仅在脑力劳动的内容（习题的性质）上如此，在时间上也是如此”。特卡钦柯老师的备课自述给出了这套做法的起点：“我仔细考虑每个学生将做些什么。我为所有的学生挑选他们都能做好的作业。”判断标准是每一步是否真的迈出去了——没有迈出哪怕一小步，这堂课对他就等于无效劳动。

至于“每生脑力负荷怎么观察”，文中给出了可观察的线索：解题过程中学生的眼神“时而精神高度集中，时而迸发出喜悦的火花（找到了正确的路子），时而沉思默想（从哪个方面解题）”；能让学生因成绩而喜悦的课上，淘气行为也会消失，因为精力被引上了正轨。也就是说，脑力负荷不是靠事后测验推断，而是在课堂进行中通过神态、进度与求助方式读出来的。

值得注意的是，这些分组“不是固定不变的”——能让学生因取得成绩而喜悦的脑力劳动，其结果总是使才能得到发展。分档是当下的作业安排，不是给学生定终身的位置。

## 教育场景/应用

- 可用于分层作业设计：针对同一个知识点准备三档任务（基础一档、标准一档、挑战一档），三档都围绕同一目标，只是台阶不同；原文的“五组”可简化为三档，便于一位教师日常操作。
- 可用于调整三个变量而不是只调难度：同一堂课里，难度（简单/中等/复杂）、数量（一道到三四道）和允许时间同时分档，避免给慢的学生“同样的题、更少的时间”。
- 可用于课堂脑力负荷观察记录：课上快速标记每个学生的状态（专注/卡住/提前完成/求助）与完成量，课后把“眼神三类状态 + 进度 + 求助次数”记成两三行观察笔记，作为下次分档的依据。
- 可用于备课自查：借用特卡钦柯的问题——“我仔细考虑每个学生将做些什么”，如果某个学生这堂课注定迈不出哪怕一小步，就要改题而不是催他。
- 可用于解释分组是动态的：向学生和家长说明分组随掌握情况变化，避免分档变成贴标签。
- 与 sk-1172（请记住，没有也不可能有抽象的学生，现有卡）连读：sk-1172 讲的是这一节的原则层面（不存在抽象的学生、成绩的相对性、保护自尊心的小路）；本卡落在操作层面，专讲同一知识点的分档作业设计与课堂脑力负荷的观察记录方式。
