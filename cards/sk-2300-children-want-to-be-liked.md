# Card sk-2300 — 讨人喜欢的愿望是儿童的本性

## 原文/Excerpt

> 成为一个讨人喜欢的人的愿望是儿童的本性。无论是教师还是家长、共青团和少先队的负责人，时刻都不能忘记这一点。这种愿望（如果对它有了正确的理解）是学生（特别是在少年期和青年早期）获得高尚情操的取之不尽的源泉。

## 中文转述/说明

这段话把孩子的「求关注」重新标定了一次：它不是毛病，而是成长的正规发动机。麻烦在于它按本能运行——孩子还没来得及判断什么值得被称赞，就先伸手要掌声了；这时他分辨不出真正的成绩和表面的风光，谁给的反应大就跟谁走。所以大人的工作不是压住这股劲，而是给它装上方向：把注意力引到需要真本事、真付出的地方，让「被喜欢」和他自己认可的成长绑在一起。若长期得不到这样的引导，同一股劲就会转向卖弄、攀比和取巧，越走越偏。

## 教育场景/应用

- 课上少用泛泛的「真棒」，把肯定落在具体行为上（谁把实验数据记得最完整、谁帮同桌补上了缺页），让孩子的注意力跟着事实走。
- 对总想抢话、抢表现的学生，给一件需要负责到底的任务，让他的存在感来自事情做成，而不是来自被看见。
- 家长会上讲明一句：孩子想被喜欢是正常的，家里和学校都把夸奖对准努力的过程。
