# Card sk-1253 — “两个教学大纲”，发展学生的思维

## 原文/Excerpt

> 非常重要的是，教师要会正确地判断教学大纲中的“重点”知识，并要有运用知识的能力，思维和智力的发展，取决于“重点”知识是否巩固。这种“重点”知识，就是反映事物特性的重要结论、概括、公式、规则、定律和规律。……需要记住的材料愈复杂，需要记牢的概括、结论和规则愈多，学习过程中的“智力底子”就会愈厚实。……为了牢固地记住公式、规则、结论和其他的概括，学生应该阅读和思考许多无须记住的材料。阅读应和学习紧密联系。……这种阅读也可以称为建立学习和记住材料所必需的智力底子。……考虑到这个非常重要的规律，我在实际工作中经常想到两个教学大纲：第一个是必须学会并记住的材料，第二个是课外阅读以及其他知识来源。……物理是最难记住的--一门课……这门课我教过6年，总是力求使课外阅读配合每个新学到的概念。某个时候所学习的概念愈复杂，学生读的书就应当愈有趣，愈有吸引力。在学习电流定律时，我凑集了一套专门的小丛书，供学生个人课外阅读用。这套丛书包括55本有关自然现象的小书，主要是介绍物质具有多种多样的电性能的。……我在高年级教过3年生物课。……学生学习生命、生命物质、遗传、新陈代谢、有机体等第一批科学概念时，我从科学和科学普及杂志、书籍和小册子中为他们挑选了专门的材料。“第二个教学大纲”包括阅读这种小册子、书籍和文章，看过这些材料后就会对一系列复杂的科学问题产生兴趣，因而也对新书产生兴趣。……我建议所有的教师，要为记住和牢记不忘教学大纲的材料打好智力底子。

## 中文转述/说明

本卡只谈第二个教学大纲怎么排：书目清单怎么配、读物在时间上放在哪里。苏霍姆林斯基的排法有三条可操作规则。第一条是「按难点配量」：某个时候所学习的概念愈复杂，学生读的书就应当愈有趣、愈有吸引力——读物的难度要与概念的难度反向补偿，越难的概念配越好看的读物。第二条是「一套而不是一本」：教电流定律时，他凑集了一套专门的小丛书供学生个人课外阅读，共 55 本有关自然现象的小书，主要介绍物质多种多样的电性能；教生物课时，他从科学和科学普及杂志、书籍和小册子中为学生挑选专门材料。

第三条是阅读时机与单元进度绑定：他总是力求使课外阅读配合每个新学到的概念，也就是读物不是学期初一次性开出的书单，而是随着第一大纲的推进逐点落位。从他在物理和生物两门课的做法看，读物可以出现在概念学习的同时（配合新学到的概念），也可以紧接在第一批科学概念之后（学完生命、遗传、新陈代谢等概念后看科普小册子，进而对新书产生兴趣）；关键在于读物始终服务于「智力底子」，而不是独立的阅读任务。

他的落点很明确：第二大纲的目的是为牢记第一大纲打智力底子——需要牢记的材料越复杂，越要读大量无须记住的材料；学生因感兴趣而读得越多，需要牢记的材料就越容易记住。所以排第二大纲时，判断标准不是读了多少本，而是读物有没有让课堂上正在学或快要学的东西成为思维、分析和观察的对象。

## 教育场景/应用

- 可用于单元备课的第二张清单：每个难点概念后面挂 1—3 本（篇）读物，标注阅读时机（概念学习前铺垫 / 同时配合 / 概念学完后紧接），而不是笼统开一份学期书单。
- 可用于难度配比：概念越难，配的读物越有趣、越有吸引力；概念较易时，读物可以更偏资料性。
- 可用于成套读物建设：参照「55 本自然现象小书」的做法，围绕一个单元凑一套小丛书/小册子，允许学生个人自由取阅，而不是指定一本必读书。
- 可用于诊断记不住的学生：先查第二大纲是否长期空缺，再决定是否加背诵量；读物与概念脱节时，加量只会加重负担。
- 可用于跨学科（物理、生物）阅读推广：把科普杂志、书籍、小册子按概念点分类存放，随进度投放，并允许由一本引向另一本。
- 与 sk-0998（现有卡）连读：sk-0998 讲的是两个大纲的原理与「智力底子」的机制（为什么需要读无须记住的材料）；本卡落在第二大纲的排法——书目清单怎么配、阅读时机怎么随单元难点落位，差异在「怎么排」而不是「为什么读」。
