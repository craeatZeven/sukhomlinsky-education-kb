# Card sk-1574 — 营造智慧型体力劳动的环境

## 原文/Excerpt

> 学校要营造一种智慧型体力劳动的环境。要使体力劳动丰富多彩，充满精神活力。要使人觉得世世代代被认为是单调苦重的农业劳动并不简单，它是一种复杂的，饱含智力的劳动。

## 中文转述/说明

他的要求是**学校要营造一种智慧型体力劳动的环境**：使体力劳动丰富多彩、充满精神活力；**要使人觉得世世代代被认为是单调苦重的农业劳动并不简单，它是一种复杂的、饱含智力的劳动**。

## 教育场景/应用

这句是给劳动课定的调：要拆掉的偏见是「农业劳动不用脑子」。
