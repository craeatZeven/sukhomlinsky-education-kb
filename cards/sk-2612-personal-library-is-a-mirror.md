# Card sk-2612 — 毕业时书架只有教科书，说明教育并不成功

## 原文/Excerpt

> 你想让青年如饥似渴地追求知识，你就要关心精神文明的最重要的基地—图书馆。我指的不仅是学校图书馆，还包括学生的个人藏书。你的学生快要毕业了，他个人有多少藏书？如果他的书架上只有教科书，而且准备把它们转送给小同学，那就说明你对他的教育不是成功的。个人藏书—这是精神文明的源泉，也是一面镜子。

## 中文转述/说明

作者把「关心知识」具体化为「关心书在哪里」：想让青年如饥似渴地追求知识，就要关心精神文明最重要的基地——图书馆，而且不只是学校图书馆，还包括学生的个人藏书。他给校长一个可以当场核对的检验：学生快毕业了，个人有多少藏书？如果书架上只有教科书、还准备转送给小同学，那就说明教育不是成功的。个人藏书在他这里是「精神文明的源泉，也是一面镜子」。

## 教育场景/应用

- 毕业班座谈时，把「个人藏书多少本、都是什么书」当作教育结果的一项硬指标。
- 做阅读推广时，把资源投向学生的个人书架（赠书、旧书流转），而不只是馆藏。
- 家长会上，把「给孩子买书、留书」说成家庭教育的长期投资。
