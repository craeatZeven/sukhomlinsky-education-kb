# Card sk-1321 — 学习之母不应变成后娘

## 原文/Excerpt

> 民间教育学断言，复习是学习之母。然而，实际情况往往是，这位慈善的母亲变成了狠毒的后娘。当这种情况发生时，学生被迫在一天或几天之内做完几个星期或儿个月所做过的事情，例如，被迫复习10节课、20节课或更多节课所学过的教材。大量的事实和结论压顶而来，使他脑了里乱成一-团。……于是，不可能进行止常的脑力劳动，弄得学生精疲力竭，伤了身体。
>
> 怎样正确组织复习才符合教学规律呢?首先，我建议考虑课程和具体教材的特点。……
>
> 有经验的教师安排复习物理、代数、儿何、化学这类课程的规则，定律、公式、结论时，以完成实践性作业为主，如做练习、做习题、画图形、绘图表等。在这里，教师应特别注意的是，要使学生为完成-项实践性作业，应懂得两项或更多的概括性结论。完成这种性质的作业时，产生了一个对于智力发展十分必要的认识转化过程——概括性结论通过相互的联系和相互依赖性而获得重新理解。……
>
> 我建议在复习代数、儿何、物理这类科目时，采用我们学校优秀教师在实际工作中所用的综合复习法，这种复习法可以是多种多样的：例如，布置给每个学生的作业是制作儿何图形模型，借以复习一系列重要公式；或者学生根据教师的布置，制作能表明几个定理的儿何图形示意图。
>
> 人文学科如历史、文学的复习，则性质不同，复习七八堂课所学的教材，便意味着要读四五页书。……复习数量很大的材料时，似乎应当撇开材料，使主要的东西更明确，次要的东西不突出。如果学生复习时重读一遍全部教材，就会负担过重，而H主要的问题是，教材的主导思想会被忽略，其教育作用会降低。
>
> 还有一种复习方法。我教数学、物理、化学、生物时，总是遵循一个我认为很重要的要求：在每门课的笔记本专门留出的空白边上，用红铅笔记下应当永远记住的内容。学生翻阅课堂笔记时，可复习这些规则、公式、定律及其他结论（数学和物理每周复习次，化学每两周复习一次，生物每3周复习一次）。

## 中文转述/说明

“复习是学习之母”在实际教学中常变成后娘：学生被迫在一两天内做完几个星期做过的事，事实与结论压顶而来，脑子里乱成一团，还要同时应付其他功课，结果精疲力竭、伤了身体。苏霍姆林斯基的对策不是少复习，而是按学科性质把复习改造成几种具体的作业形式——这就是综合复习法。

第一种，理科公式与定理的复习用几何模型与示意图：布置给每个学生的作业是制作几何图形模型，借以复习一系列重要公式；或者按教师布置制作能表明几个定理的几何图形示意图。关键要求是“一项实践性作业要牵动两项或更多概括性结论”，让结论通过相互联系与依赖关系被重新理解。第二种，理科的解题复习：安排复习物理、代数、几何、化学的规则、定律、公式、结论时，以练习、习题、画图、绘图表等实践性作业为主，学生在解题中同时复习体积公式与三角函数，两个结论相互“连接”时会产生认识上的飞跃。

第三种，文科的“撇开材料”复习：复习七八堂课的内容意味着读四五页书，此时应当撇开材料、不看细节，使主要的东西更明确、次要的东西不突出，集中注意力于主要内容上——他把这种能力称为世界观形成的基础之一。第四种，笔记本红笔边注加周期回看：每门课的笔记本专门留出空白边，用红铅笔记下应当永远记住的规则、公式、定律及结论，数学和物理每周复习一次，化学每两周一次，生物每三周一次。

## 教育场景/应用

- 期末复习前先按学科分派作业形式：理科用模型、示意图、习题，文科用“撇开材料抓主导思想”的提纲式复习。
- 设计复习作业时保证“一项作业牵动两条以上结论”，例如一道题同时用到体积公式与三角函数，让结论互相照亮。
- 文科大范围复习不要求学生重读全部教材，改为用几堂课复习题目与章节的主导思想，学生只带提纲进课堂。
- 要求学生每科笔记本留出空白边，用红笔抄下“必须永远记住”的内容，并按数学物理每周、化学两周、生物三周的节奏回看。
- 与 sk-1029（现有卡）连读：sk-1029 讲复习组织的方法要点，本卡落在“综合复习法”的四种具体作业形式上（模型、示意图、文科抓主导思想、理科周期回看），一张是原则，一张是可布置的作业清单。
