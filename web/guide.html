How to Use

使用指南

给老师、家长和内容创作者的 5 分钟上手说明。

1. 三种用法

按教育专题

想知道他对某个方向怎么看，去专题。12 个方向各有一篇长文，读完还能接着筛卡片。

进入教育专题 →

按真实问题

手上是一件具体的事，就去问题检索。输“孩子说谎”“坐不住”，它把专题和卡片一起给你。

进入问题检索 →

按故事

只想读故事，去《做人的故事》541 篇，按原书页码排的。也可以点“随机一篇”。

进入故事索引 →

2. 一张卡片里有什么

  • 原文/Excerpt：来自原著/译本的短摘录，保留可核对的出处。
  • 中文转述/说明：把故事或论述讲清楚，并点出教育含义。
  • 教育场景/应用：给老师、家长的具体做法。
  • 出处核对：source、ref、是否已核对原文。

3. 引用与导出

  • 卡片详情页可以“复制引用”，格式包含卡片 ID、来源和出处。
  • 卡片详情页可以“打印 / 存 PDF”，打印时自动隐藏导航和无关元素。
  • 主题浏览页可以导出当前筛选结果为 JSON / CSV。
  • 书源页可以导出全库 JSON / CSV。

4. 给 Agent / 开发者

  • 仓库根目录的 SKILL.md 是 Agent 入口，INDEX.md 是唯一索引。
  • 每张卡都是独立 Markdown，frontmatter 带 id / type / topics / source / ref。
  • 网页数据由 scripts/build_site.py 从 Markdown 自动生成。

5. 版权与边界

公开仓库只收录短摘录、转述与出处；完整 OCR/全文放在本地，不进入 GitHub。原文权利归各自权利人，详见 NOTICE。
