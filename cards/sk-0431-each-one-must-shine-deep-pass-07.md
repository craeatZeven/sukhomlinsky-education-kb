# Card sk-0431 — 美只有在人为创造美而劳动时才能使人高尚

## 原文/Excerpt

> Beauty only ennobles a person when he labours to create beauty. We seek to ensure that a person labours not only for his daily bread, but also for joy.

## 中文转述/说明

苏霍姆林斯基认为，美本身不会自动使人高尚——只有当人通过劳动去创造美时，美才具有使人高尚的力量。因此他努力让学生不仅为糊口而劳动，也为创造快乐而劳动。（本段为苏霍姆林斯基原话英译，非 Cockerill 分析。）

## 教育场景/应用

适用于美育与劳动教育的融合设计：把“欣赏美”延伸为“动手创造美”（种植、布置、手作、校园环境维护）；在评估劳动项目时，不只问“做了什么”，还问“是否创造了可被感受的美与快乐”。
