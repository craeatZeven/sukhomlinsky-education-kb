# Card sk-1362 — 人应当尊敬地纪念自己的先辈

## 原文/Excerpt

> 要珍重与尊敬地去纪念死去的人。凡是心中没有过去的人，那他的心中就不可能有未未。每一个人都是一个特有的世界。每一块墓碑下都是一部世界史4。……墓地是人类的圣地，要善于保护这一圣地。在缅怀先辈的日子里你到墓地去吧。这对于培养你的公民觉悟和你的良心都是重要的、即使你的亲人中没有任何一个人葬在那里，那你也要到那里去，为的是去学会珍惜心中的荣誉和先辈的智慧。墓地是人类良心的卫兵：你亲人的坟墓，就是你心灵上的一面镜子。忘记你亲人的墓，就意味看你冷漠无情。……当我的每一代学生能够理解人的重要价值的时候，我都要对他们讲《为此要学会做人》的童话。……人生在世，不仅作为一个有思想有感情的人，而H作为代代柑传永恒链条中的有生命的一环；这一环是逝去的一代一代与未来的一代一代的连接；一个人越是珍重地去缅怀自已的父亲、祖父、曾祖父，他就越能深刻地感到自已对未来的责任。……这是由于人在自已的父亲、祖父、曾祖父身上看到白己的生活、白己的荣誉和自己品格的根源……我们同父母们谈到对长辈的尊敬问题。如果父母们不理解对长辈的爱这教育哲理的话，就会结出自已道德上愚昧无知的苦果。……一点点欺骗和口是心作，都会使你的孩子彻底地随落下去，都会变成虚伪和卑鄙行为的大水洼，这就是一条道德上的准则。……在孩了面前做个诚实的人，这是最有力的，最令人信服的一条道德教诲。……我们对孩子们所讲的这-切，但愿孩了们能将那些人们的形象铭刻在心中，永不忘却他们的名字。

## 中文转述/说明

本卡收的是这一节里的具体纪念场景与做法：墓碑、墓地、家族记忆怎样进入孩子心里。苏霍姆林斯基的起句是判断——“凡是心中没有过去的人，那他的心中就不可能有未来”，接着给出几个可以照着做的场景：把每一块墓碑看成一本书，因为“每一块墓碑下都是一部世界史”，要让孩子学会认识这个“特有的世界”、尊重人的个性；在缅怀先辈的日子到墓地去，即使亲人中没有一个人葬在那里也要去，为的是学会珍惜心中的荣誉和先辈的智慧。他把墓地称作“人类的圣地”“人类良心的卫兵”，把亲人的坟墓说成“你心灵上的一面镜子”，并把“忘记你亲人的墓”直接判为冷漠无情。

他给孩子的入口是童话。每当一代学生能够理解人的重要价值时，他都要讲《为此要学会做人》，让孩子把自己理解为“代代相传永恒链条中的有生命的一环”——这一环连接逝去的一代与未来的一代；一个人越珍重地缅怀父亲、祖父、曾祖父，就越能深刻感到自己对未来的责任，因为他在父祖身上看到自己生活、荣誉和品格的根源。

这条线要落到父母身上才稳。他专门同父母谈对长辈的尊敬，并警告：如果父母不理解“对长辈的爱”这条教育哲理，就会结出自己道德上愚昧无知的苦果；“一点点欺骗和口是心非”都会使孩子彻底堕落下去，变成虚伪和卑鄙行为的大水洼。所以最有力的道德教诲不是话，而是“在孩子面前做个诚实的人”，让孩子把先辈的形象铭刻在心中、永不忘却他们的名字。

## 教育场景/应用

- 缅怀日带孩子去墓地：即使亲人中没有葬在那里也要去，为的是学会珍惜荣誉和先辈的智慧——把扫墓当作公民课，而不是家族私事。
- 讲家族链条：用《为此要学会做人》这类故事让孩子把自己看成“代代相传永恒链条中的有生命的一环”，越缅怀父祖，越能感到对未来的责任。
- 墓碑即世界史：面对每一座墓碑讲一个“特有的世界”，让孩子学会尊重人的独特性与个性，而不是只记住一个名字。
- 家长座谈：专门同父母谈“对长辈的爱”这条教育哲理，并明确“一点点欺骗和口是心非”会变成虚伪与卑鄙行为的大水洼。
- 记名字：把讲过的先辈形象与名字留在孩子心里（“永不忘却他们的名字”），可做成家族或班级的纪念册。
- 与 sk-1189（现有卡）连读：sk-1189 立的是“尊敬地纪念先辈”这一原则（心中没有过去就不可能有未来、墓地是良心的卫兵、缅怀父祖才更懂对未来的责任），本卡取其中的场景与做法——缅怀日去墓地、讲家族链条的童话、父母座谈、记名字，把原则变成可以安排的纪念活动。
