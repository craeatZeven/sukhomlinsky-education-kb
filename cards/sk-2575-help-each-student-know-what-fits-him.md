# Card sk-2575 — 让学生知道自己适合干什么，是教师必须当作使命的事

## 原文/Excerpt

> 使学生产生爱好某种职业的思想，亦即确立选择专业的思想，是思想教育的一个重要方面。教师应当把下述任务当着自己的使命，即使每个学生最终能够充分显示自己的才能，使他们早在中小学时代就知道自己适合干什么，并下定决心选择某个职业。为此，教师首先要熟悉每个学生的特长、条件和能力。但这还不够。

## 中文转述/说明

苏霍姆林斯基把职业定向从「升学指导」提升为思想教育的一部分：学校要做的不是替学生填志愿，而是让每个学生在中小学时代就知道自己适合干什么，并有决心选一条路。这个任务被他直接写成教师自己的使命。方法上说得也很具体：先熟悉每个学生的特长、条件和能力——但他紧接着说「但这还不够」，把话题推向学生对祖国、对社会的义务感。对今天的教师来说，这段话提醒把「了解学生」落到可操作的地方：不是泛泛知道这个孩子成绩如何，而是清楚他在哪件事上有真正的能力、需要什么条件才能把它显示出来。

## 教育场景/应用

- 每学期为每个学生写一条「他擅长的具体事 + 需要什么条件才能发挥」的记录，而不是只记分数和排名。
- 班会或家长会上让学生自己讲一件「我做起来比别人轻松的事」，教师把它和职业方向的可能性连起来。
- 对暂时看不出特长的学生，别急着归入「没有方向」，先给他提供不同性质的尝试机会，再据观察下判断。
