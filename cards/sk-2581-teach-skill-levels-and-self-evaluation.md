# Card sk-2581 — 孩子要先相信技能分等级，才会去追最高那一级

## 原文/Excerpt

> 通过自己和周围人的经验，孩子们从小就应该确信，每项工作的劳动技能都有不同的等级和层次。掌握最高层次的技能应该对他们具有诱惑力。这样的目的是可以达到的，而要达到这种目的，就应该把动脑能力和动手能力结合起来，而且要批判地评价自己所做的一切。

## 中文转述/说明

他把「追求完美」拆成了可教的三步。第一步是认知：让孩子从自己和周围人的经验里确认，每项工作的劳动技能都有不同的等级和层次——并非所有做法都「差不多」。第二步是动机：让最高层次的技能对孩子有吸引力，成为他想够到的东西。第三步是条件：要达到这种目的，得把动脑能力和动手能力结合起来，而且要批判地评价自己所做的一切。这里的要害不是教师宣布一个最高标准，而是孩子自己看得清层次、量得出差距。对日常教学的提示是：笼统的「做得不错」会把层次抹平，质量台阶要显性化、可比较，孩子才能自我定位、自我要求。

## 教育场景/应用

- 展示同一件劳动成果的三个质量等级（例如木工接榫的松紧），让学生把自己的作品对号入座，再说下一步练什么。
- 劳动记录本留一栏「这次比上次好在哪、还差在哪」，由学生自己填，教师只核对是否具体。
- 少用「很好/不错」的笼统评价，多用「这一步达到了第几层要求」的具体定位。
