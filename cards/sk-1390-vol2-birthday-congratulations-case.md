# Card sk-1390 — 怎样祝贺亲人的生日

## 原文/Excerpt

> 在你亲人生日那天，要比往日早起一些。走到过生日的人跟前，并对他说：“我祝贺您生日。我衷心地祝您健康、幸福、精力旺盛，思路敏捷。”如果你祝贺小弟弟(或者小妹妹)的生日，可以向他提醒说，今天满几岁啦，使他高兴。在童年，年龄的增长，会带来兴奋心情；在少年，年龄的增长会带来欢乐；在青年早期，年岁的增长会带来焦急心情；在成年，年岁的增长会带来忧郁；而到了晚年，年岁的增长会带来悲伤。……在父母过生日时，向母亲或父亲要钱去给他们买礼物是很不妥当的。……生日礼物的价值，是道德价值，它是不能用物的价值来衡量的，而是用你准备带来欢乐时所倾注的精神力量来衡量。

## 中文转述/说明

这一节给的不是一条规矩，而是一个可照着做的场景：亲人生日那天，比往日早起一点，走到过生日的人面前，当面把祝福说出口——“我祝贺您生日。我衷心地祝您健康、幸福、精力旺盛，思路敏捷。”对小弟弟或小妹妹可以特意提醒他今天满几岁，让他高兴。场景的关键动作是“早起”和“走到跟前”：祝福不是留在心里的好意，而是一件要花力气做出来的事。

紧接着是分寸。苏霍姆林斯基列出年龄在不同人生阶段带来的不同心情——童年是兴奋，少年是欢乐，青年早期是焦急，成年是忧郁，晚年是悲伤——因此对父母、爷爷奶奶不要去数他们满多少岁，对姐姐尤其是二十多岁的姐姐更不要提年龄。他还给出判断标准：人的幸福不在于又增长了一岁，而在于这一岁给我们带来了什么。祝词也要合分寸，比如对孩子不要说“祝你长寿”，因为孩子没有足够的生活阅历去理解这句话。

礼物部分同样是场景化的做法。最珍贵的是亲手做的东西：自己栽培的鲜花、一张素描、一首诗、一本有自己作品的小纪念册，或者写一件终生难忘的小事。向父母要钱去买给父母的礼物很不妥当；如果实在懒得动手，就得迫使自己放弃一点最必要的东西去换一件礼物。他给出的尺度是：礼物的价值是道德价值，不能用物品的价钱衡量，而要用“你准备带来欢乐时所倾注的精神力量”来衡量。

## 教育场景/应用

- 与 sk-1215（现有卡）连读：sk-1215 是实践卡，整理“记住每个亲人生日、早起当面祝福、亲手做礼物、反对学校集体生日表演”等做法条目；本卡取原文的实例场景，重点还原“早起—走到跟前—说哪几句话”“对不同年龄的人该不该提岁数”“钱不够时怎么办”这些具体情境与判断，角度从“做法清单”转到“分寸现场”。
- 班级活动可做一次“生日祝福彩排”：让学生当着同伴把祝福说完整，教师只纠两点——有没有走到对方面前、话里有没有涉及不该提的年龄。
- 写话/口语训练：让学生写一件“终生难忘的小事”作为给父母的生日礼物，而不是写祝词套话。
- 家庭教育指导：把“生日表”贴在孩子看得见的地方，并由孩子自己负责记；礼物预算设为“零花钱省下来的那部分”。
- 讨论分寸：用年龄在不同阶段带来的不同心情这张表，引导学生理解为什么同样一句“又老了一岁”对不同的人意味完全不同。
- 提醒避免两个极端：把生日办成攀比礼物价值的场合，或办成学校大集体里所有人一起上台的表演——两者都丢掉了生日作为亲人节日的性质。
