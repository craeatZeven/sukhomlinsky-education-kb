# Card sk-0055 — 孩子第一次读之前，先听老师和父母朗读

## 原文/Excerpt

> 在第一次阅读之前，孩子应当听一听老师和父母是如何朗读的，感受一下艺术形象的美。不要让到大自然去“旅行”和阅读书籍脱节。如果孩子在阅读书籍之后体会不到其中词句的美，他也就看不出周围世界的美好。

## 中文转述/说明

阅读启蒙不是直接丢书给孩子，而是先让成人大声朗读，让孩子通过听觉感受语言与艺术形象之美；阅读还应与大自然的观察和生活体验连接。

## 教育场景/应用

亲子共读/低年级阅读教学中，成人大声朗读、营造“听书”经验，比单纯要求孩子独立阅读更能建立语感与阅读兴趣。
