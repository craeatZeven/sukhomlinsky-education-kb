# Card sk-0967 — 马跑了

## 原文/Excerpt

> 四班在上数学课，老师布置了自习题。……最后一排坐着维佳。他快要做完习题时，突然，课桌上掉下一张小纸条。……“老师，”维佳站了起来，“不知谁扔给我一张纸条……上课时难道可以写纸条吗？”“上课时不可以写纸条，”老师说，“但是，如果有谁给你写纸条，你就告诉老师，这样不好，维佳。纸条，这就是秘密，只应该你和你的那位同学知道。而你讲出了这个秘密。把纸条拿去，藏好，休息时读一下……”维佳脸红了。……维佳打开纸条，读了一遍。“维佳，”彼得里克写道，“我给你画了一匹长着火一般鬃毛的马。如果想要，就给你。”“给我马？”维佳说。“马跑了……”彼得里克轻轻地说。

## 中文转述/说明

四班上数学课，大家都在写习题。最后一排的维佳快做完时，桌上掉下一张小纸条。他以为又是彼得里克来要冰鞋，便站起来向老师报告：“不知谁扔给我一张纸条……上课时难道可以写纸条吗？”老师却说：上课时不可以写纸条，但别人给你写纸条，你告诉老师，这样不好；纸条是秘密，只应该你和那位同学知道，你讲出了这个秘密。老师让他把纸条收好，休息时再看。维佳脸红了，班里一片寂静，同学们投来惊讶和不满的目光。他打开纸条，上面写着：彼得里克给他画了一匹长着火一般鬃毛的马，想要就给他。维佳说“给我马？”，彼得里克轻轻地说：“马跑了……”

彼得里克画的那匹马，本来就是悄悄送给维佳的礼物；维佳当众“揭发”纸条，等于把一份心意变成了违纪证据，于是马“跑了”。老师的话点出教育中一个容易被忽略的原则：孩子之间的秘密和信任需要被保护，成人处理违纪时若只讲规则、不讲分寸，就可能伤害最珍贵的东西。维佳的羞愧，正是他意识到自己辜负了同学。

## 教育场景/应用

- 可用于教师成长：借老师“纸条是秘密”的处理，讨论规则之外还要有对学生关系的体谅。
- 可用于同伴关系：引导学生理解，同学之间的悄悄话、小礼物需要被尊重，不能随手公开。
- 可用于班级讨论：问学生“如果你是维佳”，练习在遇到可疑纸条时先看内容、再做判断。
- 可用于诚信与保密：区分“该报告的危险”和“不该公开的私事”，帮助孩子建立分寸感。
