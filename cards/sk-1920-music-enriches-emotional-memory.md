# Card sk-1920 — 音乐是丰富情感记忆的源泉——要使儿童对旋律的知觉同纯洁高尚的情感联系起来

## 原文/Excerpt

> 音乐是丰富情感记忆的源泉。我力图使儿童对音乐旋律的知觉同纯洁、高尚、崇高的情感及动机(这一点尤其重要)联系起来。当孩子们在大自然中听柴可夫斯基、格里格、贝多芬、巴赫的作品时，他们在自己的想像中形成了善良和邪恶的斗争场面；他们全心全意地站在善良、美好和公正一边。

## 中文转述/说明

这条判断把音乐放进情感教育的时间轴里：它的功能首先不是审美判断，而是丰富情感记忆——在心灵里存下可以反复调用的东西。作者给的做法带着两个约束：一是让对旋律的知觉同纯洁、高尚的情感及动机联系起来，动机比一时的情绪更要紧；二是听音乐要同大自然中的具体场景绑在一起，孩子才会在想象里形成善与恶的斗争场面，并自己选择站在善、美好和公正一边。音乐活动的评价因此不该停在「能不能听出主题」，而要看它有没有让善良的立场在孩子的想象里长出具体的对手。

## 教育场景/应用

- 让儿童听音乐时把旋律与纯洁高尚的情感和动机联系起来，而不只是辨认曲式与主题。
- 在自然环境中听音乐，帮学生在想象里形成善与恶斗争的场面，并让他们自己选择站在善、美好和公正一边。
- 把「有没有丰富情感记忆、在心灵里留下痕迹」当作评价音乐活动的标准，而不只是看会上多少首曲子。
