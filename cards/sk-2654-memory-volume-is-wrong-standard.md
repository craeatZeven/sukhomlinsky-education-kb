# Card sk-2654 — 以记忆量评价脑力劳动是读死书的祸根

## 原文/Excerpt

> 对学生脑力劳动的评价通常是以学生的记忆量和根据教师的要求复述的情况为依据的(我这样说是有充分根据的：学生背记内容的一多半—尤其是人文学科课程的内容其实是不必背记的。没有找到评价学生脑力劳动的正确标准，这是产生读死书现象的真正祸根，连能力强的学生也会因之变蠢)。我们在千方百计提高能力较差的学生的认知能力和记忆力的同时，应坚决根除他们这样的念头：他们的学习成绩是由死记硬背决定的。这些后进生能回答问题，当然要给好分数，不过必须真正对所学内容融会贯通。

校勘记录（已校勘 2 处，改前→改后）：

- 我们在于方百计→我们在千方百计
- 能问答出问题→能回答问题

## 中文转述/说明

作者指出对学生脑力劳动的评价通常以记忆量和复述情况为依据，而学生背记的内容一多半本不必背；没有找到评价学生脑力劳动的正确标准，是产生读死书现象的真正祸根，连能力强的学生也会因之变蠢。

## 教育场景/应用

设计过程性评价时，把“复述了多少”换成“能否用来解决问题”。
