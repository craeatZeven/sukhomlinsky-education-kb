# Card sk-0133 — 一生只能读约两千本书：童年选书要精，让好书值得反复读

## 原文/Excerpt

> It is better for the child to read only a little, but that every book impress it emotionally and intellectually, so that the person will return to it several times and discover ever new values there.

## 中文转述/说明

苏霍姆林斯基把阅读选书上升到“一生资源”的高度：人一辈子大约只能读两千本书，因此童年和少年时期读什么必须深思熟虑。他主张宁可让孩子少读，也要让每一本都产生情感与思想冲击，使人愿意反复回到书中、每次发现新的价值。这正是他反对“阅读量竞赛”、重视反复精读与内心吸收的原因。

## 教育场景/应用

- 制定班级书单时，用“是否值得重读”“是否进入人类文化经典”代替单纯求新求多。
- 设计阅读活动时，把“重读、复述、讨论、长期记得”作为质量指标，而不是只统计读了多少本。
- 面对家长的“别人读了一百本”焦虑，可用此原则解释：选对书并读进心里，比泛读更重要。
