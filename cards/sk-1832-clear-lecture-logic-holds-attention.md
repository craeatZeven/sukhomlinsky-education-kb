# Card sk-1832 — 讲课的思路越清晰，少年越能注意听讲

## 原文/Excerpt

> 为了使少年学生能注意听讲，我们力求使讲课的思路达到最清晰的程度。这一点对于那些思维操作比较迟缓的学生尤为重要。我现在才明白，为什么学生在小学里能相当容易地克服学习中的困难，而到了五、六年级，学生的学业成绩会陡然下降：原来是他们不能适应这个从质上来说新的思维阶段。有的教师讲课能够达到较高的清晰程度，而从有些教师那里就毫无所得，这就使情况更为严重了。

## 中文转述/说明

作者把「学生听不进」的责任先放回教师这一端：为了让少年注意听讲，教师要把讲课的思路做到尽可能清晰；思维本来就迟缓的学生，对清晰度的依赖尤其大。随后他给出一个很实用的解释——不少孩子在小学学得挺顺，到了五、六年级成绩陡然下滑，不是人变笨了，而是没有适应这个在质上不同的思维阶段。这条观察今天仍然成立：初中「滑坡」常被当成态度问题去处理，而这个判断提醒我们，先去检查思路的清晰度和台阶的设置。

## 教育场景/应用

- 某个班普遍听不进时，先复盘自己这节课的思路链条有没有断点，再谈学生状态。
- 给思维较慢的学生单独准备一版更清晰的讲解顺序，不靠课后补时长。
- 看到初中起始年级成绩整体下滑，先查教学是否跨过了一个没有铺好的思维台阶。
