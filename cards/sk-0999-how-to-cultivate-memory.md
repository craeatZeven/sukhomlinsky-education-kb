# Card sk-0999 — 怎样培养记忆力

## 原文/Excerpt

> 靠自己的努力、靠顽强的意志力获得的知识越多，逻辑认知对学生的情感触动得越深入，记得就越牢固，新知识在头脑中就越有条理。……我坚信，不论在课堂上或家里，儿童还没有达到能熟背和记住不忘的年龄时，应特别关心培养他的记忆力。上学前和小学学习时期，是为牢固的记忆力打基础的黄金时代。应设法使儿童在直接观察的过程中，能掌握有关周围世界的现象和规律的重要原理，而无须专门去熟背和记住。……要做到这一点，唯一的办法是：建立有意记忆和无意记忆的合理比例关系。

## 中文转述/说明

苏霍姆林斯基把记忆力问题放在思维和情感的土壤上来谈：靠自己努力和意志获得的知识、被逻辑认知深深触动过的知识，才记得牢、有条理。一个儿童如果只看见事物表面，在考察内部实质时没有任何“发现”，没有体验过发现意外联系时的惊奇感，就很难记住东西。

他因此把上学前和小学阶段视为培养记忆力的黄金时代：应让儿童在直接观察中掌握关于周围世界现象和规律的重要原理，而不必专门熟背。到了少年期，死记硬背尤其有害，会造成书呆子气；唯一的出路是建立有意记忆和无意记忆的合理比例——需要记住的教材要与大量只需理解、由兴趣驱动的阅读相配合。

## 教育场景/应用

- 可用于小学低段的记忆教学：多安排观察、参观、实验和动手活动，让孩子在直接经验中自然记住现象和规律，而不是提前逼背结论。
- 可用于中高年级的复习设计：为需要背熟的教材配几倍于它的、只需理解的有趣阅读，用无意记忆支撑有意记忆。
- 可用于诊断“记不住”的学生：先检查他是否缺少发现和惊奇的经验，是否长期只做机械背诵，再决定是补阅读还是补方法。
- 可用于提醒教师：讲课要能“点燃”学生课后找书读的愿望，让阅读成为记忆的活水，而不是额外的负担。
