# Card sk-1606 — 用记忆替代思考是一大陋习

## 原文/Excerpt

> 用记忆替代思考，用背诵替代对现象本质的清晰理解和观察是一大陋习，能使孩子变得迟钝。

## 中文转述/说明

苏霍姆林斯基借克莱因把中学生比作「装知识十年的炮」的戏言，说出自己的观察：**被迫死记并不理解、不能在意识中引起鲜明概念与形象的知识，会让孩子变得迟钝**。他给的判断很硬——「用记忆替代思考，用背诵替代对现象本质的清晰理解和观察是一大陋习」。**能背出来不等于懂了，而把背诵当懂，代价是思维本身被替代。**

## 教育场景/应用

- 评价一节「效果很好」的课：学生是在复述结论，还是在解释现象？可据此判断是否属于记忆替代思考。 - 可用于布置复习：把「背下这一节」改成「用你自己的例子讲清这条规则」，逼出理解。 - 面对靠背诵维持成绩、越到高年级越吃力的学生，优先补观察与解释的机会，而不是加背诵量。
