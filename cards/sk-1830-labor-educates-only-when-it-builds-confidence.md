# Card sk-1830 — 劳动只有在人于其中确立了自己的信心时，才成为教育力量

## 原文/Excerpt

> 但是只有在这样的条件下，即人在劳动中确立了自己的信心，认识到自己的力量、才能和天赋时，劳动才能成为强大的教育力量。只有当一个人热爱劳动时，劳动才能成为真正的教育者。因此，在少年期，使每个学生从许多种劳动中找到他能够获得幸福的那条道路是非常重要的。

## 中文转述/说明

他把「劳动是伟大的教育者」这句常被引用的说法加了一道条件：劳动要起作用，人必须先在劳动中确认自己——认识到自己的力量、才能和天赋；只有热爱劳动，劳动才真正成为教育者。这解释了他为什么强调少年期要让每个学生从许多种劳动里找到那条能给他幸福的路：找到这条路，劳动才从任务变成自我确认的场所。对安排劳动课的含义是，先问学生在这件事上有没有「我做成过」的经验，再谈劳动的教育价值。

## 教育场景/应用

- 排劳动课时给同一批学生多种工种试手的机会，让每个人至少在一件事上有「我做成过」的记录。
- 评价劳动教育不只看是否完成劳动量，还看学生有没有在劳动中认出自己的长处。
- 学生把劳动只当义务时，先在他的劳动成果里帮他找到那个能干的部分，再谈坚持。
