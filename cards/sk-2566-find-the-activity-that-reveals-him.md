# Card sk-2566 — 一件事上不成，不等于他没有出路：教师的任务是替他找到那件事

## 原文/Excerpt

> 我们细心地观察每个学生的精神发展，并力争使他们做好在特定阶段能够做成的事情。这里的可能性是无穷无尽的。例如，如果学生在一件事情上不得于，则他可能转向另一件事情。最终他能找到一种能充分揭示他的个性的活动。

## 中文转述/说明

苏霍姆林斯基在这里把「个别对待」落到一个很具体的动作上：先长期观察，再判断一个孩子当下能做成什么，然后据此给出路。承认「可能性是无穷无尽的」，等于承认一个孩子在某一件事上的失败不是对他整个人的判决——这件事不成，就换一件事，直到找到那件能把他的个性完整揭示出来的活动。对教师的要求因此不是安慰，而是持续提供可替换的路径；真正的转变发生在「我在这件事上成了」的那一刻，而不是在被反复要求补短的那一刻。

## 教育场景/应用

- 班上有个孩子作文总写不动，但拆装东西很稳：与其一次次退他的作文，不如先让他负责小组的器材与维修，再请他把拆装过程口述成文。
- 接手新班时用两周记录每个孩子在什么事情上会主动多待十分钟——这份记录往往比成绩单更早指出他的支点。
- 对反复不成的孩子，别在同一项练习上加量，而在同一能力方向上换材料、换成果形式（先说、再画、后写）。
