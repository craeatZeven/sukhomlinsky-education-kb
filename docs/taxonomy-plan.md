## 二、定稿结构：五层范畴 + 复分

不借生物学的字，**用教育学自己的范畴命名层级**，并且让每个层名自带它要回答的问题——层名本身就是内容：

| 层级 | 名称 | 回答的问题 | 数量 |
|---|---|---|---|
| 一 | **宗旨** | 教育要把孩子培养成什么样的人？ | 4 条 |
| 二 | **立场** | 怎么看待儿童、怎么对待儿童？ | 3 条 |
| 三 | **场域** | 教育在哪里发生、由谁承担？ | 3 条 |
| 四 | **内容与方法** | 教什么、怎么教？ | 5 条 |
| 五 | **衡量** | 怎么反馈、怎么评价？ | 2 条 |
| 复分 | **关照** | 面向哪一类具体孩子（可复用到以上各层之下） | 1 条 |

从上到下正好是「从为什么教 → 到怎么衡量」，方向感自带。**一层套一层，位置固定**——这才是「地图」能成立的前提。

```
形态 (2)   论述（他论教育，718 张）   故事（他写给孩子，668 张）
  │
  ├─ 论述
  │    范畴 (5)  宗旨 · 立场 · 场域 · 内容与方法 · 衡量
  │      条目 (18)  A1–A18（A18 关照为复分条目，可跨界出现）
  │        子目     每条目下 2–5 个（见 §三示例）
  │          卡片
  │
  └─ 故事
       组织 (3)  通读（原书顺序）· 处境（8 个）· 主角（5 个）
         子目     每一篇故事
```

**「宗旨」的处理**：宗旨层（A1–A4）**做成总纲页**，在导航与地图上是独立一层（一级入口），**不作为并列筛选复选框**——它是纲，不该跟「评价与分数」平起平坐。筛选器里保留一个「宗旨」折叠组，需要时展开。

**「关照」的处理**：学到图书馆学的现成做法——**复分**。学习困难学生是对**特定一类孩子**的关照，它横向复用到宗旨/立场/场域/内容/衡量之下，**不参与面积统计**（否则会把主归属重复计数）。

## 四、故事：按「处境 + 主角」分面

**为什么不能按教育主题切**：用品格词扫 668 篇故事是长尾——妈妈 31%、美 17%、劳动 11%，其余全部 <6%（诚实 1.2%、勇敢 2.2%、分享 0.7%）。这些故事**每篇是独立情境**，不是主题的例证。

**为什么「处境 + 主角」成立**：同样扫一遍分面词，**99% 的故事至少落进一个分面**（对比主题词只有 75%）：

| 分面 | 篇数 | 占比 |
|---|---|---|
| 处境：自然与季节 | 428 | 64.1% |
| 主角：母亲与家人 | 367 | 54.9% |
| 处境：美与歌 | 307 | 46.0% |
| 处境：劳动 | 224 | 33.5% |
| 处境：帮助他人 | 165 | 24.7% |
| 主角：动物 | 163 | 24.4% |
| 主角：成人（教师/司机/农艺师…） | 144 | 21.6% |
| 处境：学校与学习 | 136 | 20.4% |
| 主角：同伴 | 126 | 18.9% |
| 处境：离别与非 | 110 | 16.5% |
| 处境：恐惧与害怕 | 90 | 13.5% |
| 处境：羞愧与良心 | 79 | 11.8% |
| 主角：老人 | 59 | 8.8% |

**关键理由**：老师家长的检索意图是「**孩子怕黑**」「**想讲妈妈的故事**」——处境与主角比抽象主题更接近真实问题。

**三层组织**：
1. **通读**：按原书页码顺序读完 541 篇（现有 `stories.html` 已如此，保留）；
2. **处境 / 主角**：上面 13 个分面（新增筛选）；
3. **选集**：10–20 组人工策展，按**使用场景**组织（「一年级开学第一周」「亲子共读十分钟」「第一次面对失去」），带导读。

**故事卡仍保留教育条目作次标签**（搜索「诚实」能命中相关故事），但**不参与主归属与地图面积**。

**篇幅数据**：中位数 222 字，四分位 126–301 字，最长 804 字——都是 1–3 分钟能读完的短篇。**发现 1 篇摘录为空（0 字），迁移时一并核查。**

## 六、一次性切换的迁移步骤（决策 4：不保留旧 slug 并存）

每步跑 `python scripts/validate_all.py`，任一步失败即停。

| 步 | 动作 | 产物 / 验证 |
|---|---|---|
| 1 | 新建 `taxonomy.yml`：5 范畴 + 18 条目 + 13 故事分面的定义（名称、范畴、关键词、收录说明、示例子目） | 单一事实源，页面与脚本都读它 |
| 2 | `scripts/classify_cards.py`：按 IDF 规则给每张卡写 `primary`（论述）或 `story_facets`（故事） | 建议值 + 复核清单（得分接近第二名的） |
| 3 | 人工复核约 150–200 张，抽检与修正 | 修订写回 `taxonomy.yml` 的例外表 |
| 4 | 卡片 frontmatter 重写：`topics:` → `primary` + `facets`；**旧 12 个 slug 全部删除** | `check_kb.py` 校验 frontmatter |
| 5 | 生成 18 条目页 + 5 范畴页 + 1 总纲页 + 13 故事分面页（`topics/` 目录重写） | 每页含「收录什么 / 不收录什么」判定规则 |
| 6 | 站点改造：`topics.html` 分层、`explore.html` 按范畴/条目筛选、`stories.html` 加分面、`clusters.html` 标注每簇对应的条目 | 审计脚本全绿 |
| 7 | 地图：纵轴 = 5 范畴，条目面积 ∝ 主归属数；故事独立成块 | 面积合计 = 1386 |
| 8 | 文档同步：`docs/kb-status.md`、`INDEX.md`、`SKILL.md`、`web/README.md` | 全链路 ALL OK |

**外部影响提醒**：`explore.html?topic=<旧slug>` 这类站外链接会失效（一次性切换的代价，已接受）。Pages 不支持 301，故只在站内做一次「旧地址 → 新地址」的提示页。

## 八、验证门槛（写进 `validate_all.py`）

1. 每张卡有且只有一个 `primary`（或 13 个故事分面之一）；
2. 每个条目的主归属数量落在 **15–200**；
3. 最大条目占比 ≤ **20%**；
4. 故事分面覆盖率 ≥ **95%**；
5. 无摘录为空的卡片（当前 1 张待修）。
