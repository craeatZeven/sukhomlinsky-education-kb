# Card sk-1842 — 要让年轻一代确立使千万劳动者受益的高尚道德感

## 原文/Excerpt

> 要使成长中的一代确立用自己创造的价值使成千上万劳动者受益的高尚道德感。要使小伙子和姑娘们从精神上准备好投入共产主义社会的劳动，改造生产关系，这种改造必定会在集体农庄的乡村里得到实现。

## 中文转述/说明

这段话把「高尚道德感」的落点讲得很实在：要使成长中的一代确立用自己创造的价值使成千上万劳动者受益的道德感，同时要使小伙子和姑娘们从精神上准备好投入社会劳动、去改造生产关系，而这种改造必定会在集体农庄的乡村里得到实现。它的结构是「道德感—创造价值—受益者是具体的劳动者」，而不是抽象的品格要求。对今天仍然有用：如果道德教育只说「要善良、要奉献」，学生无从检验；一旦把受益者变成能指出来的具体人（同学、邻居、用户），道德感就有了对象和反馈，也因此能被学生自己确认。

## 教育场景/应用

- 每次公益活动前置一步「谁受益」：写出具体对象（哪个班、哪个院、哪些老人），活动后请对方确认受益点。
- 让作品与劳动成果优先用于他人：自制教具、翻译稿、科普材料送给真正需要的人，而不是只交给教师当作业。
- 评价表里加一项「你的劳动让谁的生活发生了什么变化」，用真实反馈作答，不写感想作文。
- 引导学生关注本地具体困难（村里、社区里的实际问题），把改善方案直接交给相关的人。
