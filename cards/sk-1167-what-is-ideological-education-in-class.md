# Card sk-1167 — 什么是课堂上的思想教育

## 原文/Excerpt

> 在教学和教育工作的实践中，有这样一种广泛流行的观点：学生在掌握知识的同时就在道德上受到了教育；掌握知识本身就是道德发展的过程。……生活使人们相信，掌握知识，懂得自然科学规则和社会学规律，能很好地回答问题以及获得很好的分数——这一切还不等于道德教育。在知识转变并发展为信念时，才是教育的开始。……要掌握知识，珍重信念。缺乏这种或那种具体知识，并不说明一个人在道德上没有教养。而缺乏信念，即使有知识，也说明一个人在道德上面目不清。……关于自然界和社会的实际知识，是形成科学思想、社会思想、政治思想和道德思想的基础。思想是实际知识与信念之间的桥梁。知识通过思想变成信念。

## 中文转述/说明

苏霍姆林斯基先破除一个流行观念：学生掌握知识的同时就自然受到了道德教育。他认为“通过教学的教育”“通过知识的道德教育”这类说法会让人产生无忧无虑的自我安慰心理——懂规律、会答题、拿高分，并不等于道德教育；只有当知识转变为信念、真理触及灵魂、激动人心，并促使学生用行动去捍卫时，教育才开始。因此，缺乏某项具体知识不说明道德上没有教养，而缺乏信念，即使有知识，也说明道德上面目不清。

他给出机制：实际知识是形成科学思想、社会思想、政治思想和道德思想的基础，思想是知识与信念之间的桥梁，知识通过思想变成信念。思想已不只是知识，其中含有“一小块灵魂”——个人对他知道的事物所持的个人态度，因而带有鲜明的感情色彩。落到课堂上，他要求教师：不要把教材讲成没有感情的说明，而要引导学生沿着科学的艰险道路旅行；自然科学课上要讲清科学真理的代价与为之斗争的思想家形象；人文学科课堂上没有、也不可能有思想上的中性材料，教师面对的始终是柯利亚、尼娜这样具体的、活生生的人，而不是抽象的学生。

## 教育场景/应用

- 可用于课堂教学反思：检查自己是“讲完了知识”还是“让知识变成了学生自己的态度”。
- 可用于理科教学：在讲概念和规律时补充科学真理的发现代价与思想家的故事，避免把理科讲成无价值判断的说明。
- 可用于文科教学：把史料、文本与学生自己的生活、立场和行动联系起来，而不是只做知识点梳理。
- 可用于德育工作定位：把思想教育落在日常课堂里，而不是另开一门课或只在班会上讲。
- 可用于教师成长：要求教师“思考知识”——预见每一条道理会触动学生心灵的什么部位、会引起什么问题。
