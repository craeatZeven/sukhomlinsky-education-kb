# Card sk-1373 — 年轻一代共产主义信念的形成（绪论）

## 原文/Excerpt

> 共产主义道德的决定性力量是信念。使每个受教育者形成坚定的共产主义信念，这是教育的主要任务之一。可惜许多学校在实际下作中没有对信念的培养给予应有的重视。最严重的缺点是：用单纯理解道德的概念，真理、规范来取代信念的形成。这个缺点产生的原因，在于忽视了道德教育不同于知识教育。……右些教师认为，道德行为就足把有关道德的概念，真理、规范运用于生活中，如同把科学基础知识运用上作业或下一步教学过程中那样。结果在教学中，道德教育常常被简单化，教师认为白已在道德教育讨程中的成就，就表现为学生知道如何对待劳动、如他对待公共财产，如何在公共场合自持，等等。……道德教育水平的这种标准，经不起生活的检验。例如，年龄大的学小比年龄小的学生对道德规范的了解要多，但在行动上，破坏公共道德的原则和规范的情况却更多可见，知识和信念不是等同的。……信念的形成问题之所以引起了本书作者的关注，首先考虑到品德教育的实际需要。在多年做学生集休1作期问，现实生活迫使我们要解决的问题，是受教育者的精神世界的形成，特别是他们对待社会职责的态度。……如何使受教育者将有关道德的概念、真理、规范方面的知识变为个人的深刻信念?信念的形成跟知识教学比起来，其特点何在?如何在日常思想教育实践中(在课堂上、在课外活动中)考虑这些特点?

## 中文转述/说明

这篇绪论把“道德教育不同于知识教育”从判断落成了方法问题。苏霍姆林斯基先立命题：共产主义道德的决定性力量是信念，形成信念是教育的主要任务之一；而许多学校最严重的缺点，恰恰是用“理解道德概念、真理、规范”取代信念的形成。原因就在于忽视了道德教育与知识教育的区别。

他把这种错误的教学观讲得很具体：有些教师以为道德行为就是把道德概念“运用”到生活中，如同把科学基础知识运用到作业里一样；于是德育被简化成验收“学生知道如何对待劳动、如何对待公共财产、如何在公共场合自持”。这种标准经不起生活检验——年龄大的学生对道德规范了解更多，破坏公共道德的情况却更常见，说明知识与信念并不等同。

方法上的转向是：不再问“学生知道了什么”，而问“知识怎样变成个人信念”。信念形成相对于知识教学有何特点、这些特点如何在课堂与课外活动中被照顾、道德发展与智力发展之间是什么依从关系、集体在信念形成中起什么作用——他把这些问题一一列出，作为全书要处理的对象，并明确把信念形成看作全部教育过程和学生全面发展的方向。

## 教育场景/应用

- 备课自检：把德育目标从“让学生知道 X”改成“让学生在某情境中愿意做 X”，并设计能产生真实选择、后果与内心冲突的活动，而不是靠讲清规范完成德育。
- 课堂做法：在学科教学中不只给结论，还揭示知识背后的世界观内涵与人的处境（例如一段历史、一项技术背后人的选择），让知识带上价值重量。
- 评价方式：不用“会不会背规范”验收德育，改用观察学生在无人监督时的行为、在集体活动中的承担、对弱者与公共财物的态度。
- 集体角度：把集体的共同事业、共同困难和共同评价当作信念形成的场所——信念不是个人独白，而是在集体关系中被检验和加固的。
- 与 sk-0084（现有卡）连读：sk-0084 是引文卡，只摘“知识和信念不是等同的”这一句判断；本卡取同一绪论的方法面，把这条判断展开成“怎样让学生把规范变成信念”的操作路径与要研究的问题清单。
- 教师成长角度：把“为什么学生知道却不做”当成自己的方法问题来反思，而不是归因于学生品德差。
