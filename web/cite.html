如何引用一张卡

选一张卡，页面给出三种可以直接粘贴的写法：中文脚注体、GB/T 7714 近似、Markdown 引用块。 书目里缺的字段一律写 [待补] 占位——这里不猜、不补。

索引载入后即可在本地匹配（编号、标题、中文转述都能搜）。

      这一页的数据从哪来
      
    
      每个字段都有出处；取不到就不写。下面写清每一条的来源，方便你复核或替换。
      

    
      
      
      原文引文
      web/data/cards/<id>.json 的 excerpt / excerpts（与卡片详情页同源）
      
      
      书名
      web/data/meta.json 的 sources[].title
      
      
      页码 / 章节
      同一份单卡 JSON 的 loc.page / loc.section（由 scripts/build_shards.py 从全文层生成）
      
      
      出版社 / 年 / 译者 / 责任者
      sources/<slug>.md 的 front-matter（本页内置一份静态副本）
      
      
      卡号链接
      card.html?id=<id>，按当前域名生成绝对地址
      
    
      

    
      页码的口径（必读）
      
    
      库里记的 page 是「扫描件第 N 页」（从 1 数起），不是纸本页脚印的那个页码——两者每卷偏移不同，本库不声称二者相等。
       所以三种写法里的页码，可以理解为「能回到扫描件的那一页」；要投给正式出版物，请照纸本把页码换掉。
       少数卡片没有 page，但 ref 字段里写了印刷页码（形如 p. 22），这种会标注「取自 ref」。两样都没有就写「页码待补」。
      

    
      本页没有的字段（需要人工补）
      
    
        
      
      • 出版地：13 个书源里没有任何一本记了出版地，GB/T 7714 这一格一律是 [出版地待补]。这是本页最大的缺口。
        • 
      
      • 出版年：只有 5 个书源有年份；《给教师的建议》与《选集》五卷本都空着，脚注与 GB/T 里写 [出版年待补]。
        • 
      
      • 版次 / 印次：《选集》五卷本未登记版次，GB/T 的版本项因此省略。
        • 
      
      • 具体篇目页码：loc.section 有的是小节名、有的是篇名，粒度不统一；脚注里照抄，不另行改写成「第 X 篇」。
        • 
    
      

    
      两条使用边界
      
    
        
      
      • 原文是逐字摘录，不是转述：卡片标 excerpt_status: paraphrase 的 11 张没有逐字原文，本页不会把它伪装成引文，Markdown 块里会写明「编者概括」。
        • 
      
      • 版权：中译本多仍在版权期内，本库只收短引文；引用时请控制在评论、教学所需的必要范围内，并注明出处。
        • 
    
      

    
      本页书目静态副本对应 sources/*.md 的 2026-10-20 状态；若那边改了书名/出版社/年份，请同步改本页的 BIB 常量。
