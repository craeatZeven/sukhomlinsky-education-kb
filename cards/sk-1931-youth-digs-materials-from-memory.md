# Card sk-1931 — 青年能从记忆里挖材料，把已知与新知接上

## 原文/Excerpt

> 青年不仅能够靠思维深入到事物、现象、相互依存性的实质中去，而且能在思考的过程中从记忆的储备里挖掘材料，把以前已知的东西跟新的东西进行对比和比较。教师常常感到惊奇的是，高年级学生能够援引大量的补充材料，用来证明或反驳某种提法或思想。

## 中文转述/说明

这条判断说的是青年期脑力劳动的一个新本领：思维不只能钻进事物的实质，还能在思考过程中主动回到记忆储备里去取材料，把以前知道的东西和新的东西摆在一起比较。作者用教师常有的惊讶来印证它——高年级学生能援引大量补充材料来证明或反驳某个提法。对教学的启示是：与其反复强调「把学过的记住」，不如给出需要调用旧知的真问题，让记忆被思考「取用」一次。

## 教育场景/应用

- 出题时设计必须调用前几年所学才能回答的问题，让旧知识被真正取用一次。
- 学生援引教材外的补充材料来支持或反驳时，先肯定这种做法，再谈材料是否可靠。
- 检查复习效果，不看能否复述，而看他能否用旧知跟新知作对比。
