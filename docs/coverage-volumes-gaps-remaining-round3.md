## 二、判定口径

1. **行来源**：解析 `docs/coverage-volumes-chapters.md` 的 6 列章节明细表。**本轮新增一条解析防护**：该文档 §四「下一步优先建卡：20 节」表与章节明细表同为 6 列，且其第 1 列编号 1–5 会与「卷次」列混淆（会被误读为 vol1–vol5 的 5 个 gap 行）。因此本轮要求**第 4 列必须是纯数字卡片数**，否则跳过。过滤后得到 **310 行**（143 `gap` / 154 `partial` / 13 `covered`），与文档 §二总览及第二轮口径完全一致。
   > 补充：本轮对照发现，章节明细表自第二轮以来**内容未变**（仅顶部「更新」说明改了一行），所以 143 / 154 / 13 的基线与第二轮逐项相同；两轮之间的所有数值变化都来自卡片库，而非审计口径漂移。
2. **卡片来源**：解析 `cards/*.md` 的 `id` / `source` / `title` / `ref`；只取 `source: xuan-ji-zh-vol1…vol5` 的卡片，按卷次过滤。当前五卷本卡 **516 张**。
3. **审计快照的边界已被精确复原**：五卷本卡中 `id ≤ sk-0993` 的恰好 **300 张**（vol1 40 / vol2 58 / vol3 52 / vol4 41 / vol5 109），与审计文档自述的「300 张（40/58/52/41/109）」**逐卷完全吻合**；`id ≥ sk-0994` 的为 **216 张**（vol1 27 / vol2 101 / vol3 45 / vol4 36 / vol5 7）。因此本轮继续把「审计之后新增」严格定义为 **id ≥ sk-0994 的五卷本卡**。
4. **匹配方式**：把「作品名 + 章节/篇目」与卡片的 `ref + title` 归一化后做**最长公共子串**匹配；对带编号标题额外去掉 `上篇/下篇 N.`、`第N章`、`第N次谈话` 前缀后做 core 匹配，`第N封信` 保留全串（避免退化为空串）。阈值：core/full 命中率 ≥ 0.70 且匹配长度 ≥ 4 字；「序言/前言/结束语/作者的话/代前言」等短标题要求同作品 + 短标题出现在 ref 中。
5. **判定**：
   - `gap` → **`now_covered`**（有 ≥1 张 `id ≥ sk-0994` 的卡命中）/ **`still_gap`**（无任何命中）/ **`uncertain`**（只有旧卡命中，口径无法判定）。
   - `partial` → **`improved`**（有 `id ≥ sk-0994` 的卡命中）/ **`unchanged`**（无新卡命中）。
6. **复现校验**：本脚本对第二轮时点（只保留 `id ≤ sk-1191` 的五卷本卡）重跑，得到 **now_covered 95 / still_gap 47 / uncertain 1；improved 27 / unchanged 127**，与 `docs/coverage-volumes-gaps-remaining-round2.md` **逐项一致**——说明本轮增量可归因于新卡，而非口径漂移。
7. **`still_gap` 的逐项复核**：对 27 个 `still_gap` 行做了「低于阈值的近邻匹配」扫描，最高相似度仅 0.583，且前几名候选均为共用「怎样培养…」「怎样教孩子…」等泛词的相邻篇目，**未发现被漏判的真实命中**。
