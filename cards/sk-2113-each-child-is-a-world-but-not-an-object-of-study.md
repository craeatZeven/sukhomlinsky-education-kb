# Card sk-2113 — 每个孩子都是一个独特的世界，但绝不能把他当研究对象

## 原文/Excerpt

> 每个孩子在思想、观点、情感、感受、快乐、不安、悲伤、忧虑等方面都是一个独特的世界。教师应当认清并熟悉自己学生的这个精神世界，但他绝不能把他们当做研究对象来对待。教师应当成为孩子的朋友，深入到他的兴趣中去，与他同欢乐、共忧伤，忘记自己是教师。这样，孩子才会向教师敞开他的心灵。学校，只有当它成为孩子过愉快而有趣的生活并努力求取知识和钻研科学的园地时，才能成为教育基地。

## 中文转述/说明

这条的分寸感就是它的全部价值：一面要求教师认清每个学生的精神世界，一面马上设一道禁令——不许把他当研究对象。理由是位置决定信息的深度：站在「研究」的位置上，孩子是被观察的客体，他会表演；站在「朋友」的位置上，他才把真实的东西拿出来。作者把这个要求推到底——「忘记自己是教师」，也就是暂时放下角色和权力，去分享同一件事的快乐与难过。对今天的教师这是一条反直觉的操作提示：想了解学生，先别加一张观察表，先找到一件你们能一起高兴的事。

## 教育场景/应用

- 想了解某个沉默的学生时，先找一个能一起做的活动（一本书、一场球、一次远足），再谈他的情况。
- 学生谈话时不录音、不当场记录、不追问，事后凭记忆写要点，避免变成访谈式关系。
- 班里按共同兴趣建活动小组，教师自己进一个小组当成员，而不是当组织者。
