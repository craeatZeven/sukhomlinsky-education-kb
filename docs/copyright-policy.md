# Copyright Policy — 摘录与转载政策

## 原则

本项目是**开放知识库**，不是“电子书库”。目标是把散落在作品里的思想做成可检索、可溯源的学习材料，而不是替代原著。

因此：

1. **不转载整书/整章全文。**
2. **短摘录**：单条卡片中的原文摘录控制为足以支撑观点的篇幅，不连续摘录形成“替代阅读”的章节。
3. **优先转述 + 链接**：能用中文转述 + 精确出处表达的，不贴大段原文。
4. **来源必须登记**：每本来源在 `sources/` 有元数据与 `rights_status`。

## rights_status 取值

| 值 | 含义 |
|---|---|
| `public-domain-verified` | 已核实公版 |
| `translation-license-unknown` | 译文版权状态不明，只用短摘录+转述 |
| `in-copyright-short-quotes-only` | 明确在版权期内，只用短引文 |
| `unverified` | 尚未核实，谨慎使用 |

## 删除流程

权利方认为某条摘录超出合理范围 → 提交 Issue/PR，维护者会删除或缩短该条。摘录是否合理按“目的与数量”判断：本项目为教育/研究用途，但数量仍需克制。
