# Card sk-1381 — 在当今做个革命者意味着什么

## 原文/Excerpt

> 这是一段最费力的道德上的教诲，它包括思想、事件、现象、事实的巨大世界——从占罗马在斯巴达克率领下的第一次奴录起义起，直到17岁的列宁因母亲得到大儿子业历山大被处决的消息而悲痛欲绝时，说出“我们不能走那条路”这句预言为止；从阿芙乐尔巡洋舰声炮响到少先队员从集体农庄已收获的田里拣来的麦穗打成-捧小麦为止。这里，无论在集体和个人的口头上也好(而崇高、鼓舞人的话语是少年心灵上燃起的火花)，实际行动也好、最主要的东西是什么呢?就是在集体和个人的智力生活和思想生活中应充满解放的——自由劳动的列宁思想。人要起来去反对压迫者，永远为自由劳动而斗争。在当今做个革命者，这意味着不仅要做个新的—自由的、创造性劳动的主人，而H要做个创造者。对待劳动、粮食和人的品格的态度，永远是衡量一个人革命修养的一把尺子。在田野里、在畜牧场、在锅炉和机床旁，在社会主义祖国的边防哨卡上，革命在继续进行。……在教育孩子们忠实于革命和共产党的思想时，我极力使小公民在童年时代就能用自己的才智去理解并用心去认识社会主义世界同资本主义世界是有着天壤之别的。这里有报道美国存在饥寒交迫现象的书信和照片。……我给孩子们读着美国-·位女教师关于4个小姐妹悲惨遭遇的信。信中说，几个月来，她们都过着忍饥挨饿的生活，正当孩子们--点吃的也没有的时候，她们的父亲又失业了。儿个小姑娘都饿成皮包骨了，一动也不能动了。4个小姑娘后来都死在医院里。……我是把我们人民走什么样的道路才能得到自由劳动的幸福，用什么代价才能获取有关衣、食、住、温暖的第二位的幸福的这种思想，点一滴地灌输到自己学生的头脑中去。

## 中文转述/说明

这一篇的操作面，在于把“革命者的责任”从口号变成课堂上能做的具体事。第一件事是让孩子的思想生活有具体的“材料世界”：苏霍姆林斯基说这段道德教诲包括从古罗马斯巴达克率领的第一次奴隶起义、到十七岁的列宁说出“我们不能走那条路”、从阿芙乐尔巡洋舰的炮响、到少先队员从已收获的田里拣麦穗打成一小捧小麦——事件、事实、形象是给孩子的心灵点火的东西，崇高、鼓舞人的话语是少年心灵上燃起的火花。

第二件事是给出衡量尺子。在当今做个革命者，意味着不仅要做自由的、创造性劳动的主人，而且要做创造者；而“对待劳动、粮食和人的品格的态度，永远是衡量一个人革命修养的一把尺子”。这句话把革命修养从政治表态转成了可观察的日常行为，并且明确革命在田野、畜牧场、锅炉和机床旁、边防哨卡上继续——也就是在学生每天能接触到的劳动现场继续。

第三件事是让孩子通过对比认识自己的处境。他极力使小公民在童年时代用自己的才智去理解社会主义世界同资本主义世界有着天壤之别，做法是读报道美国饥寒交迫现象的书信和照片、读一位美国女教师关于四个小姐妹悲惨遭遇的信（父亲失业、孩子挨饿、最后死在医院里）。第四件事是把“思考幸福”变成教育任务：他一再指出道德教育中一个严重疏忽，就是很少教学生去思考幸福——思考全体人民的幸福、每个家庭的幸福，思考人民走什么样的道路才能得到自由劳动的幸福、用什么代价才换来衣食住温暖这些第二位的东西；并强调让孩子体验忧虑、担心和良心的谴责，比单纯讲道理更重要。

## 教育场景/应用

- 用“事实世界”讲道理：不空谈革命，而是拿具体事件、书信、照片、人物故事做材料，让话语成为点燃少年心灵的火花。
- 把尺子交给学生：用“对待劳动、粮食和人的品格的态度”作为衡量革命修养的标准，让学生在值日、劳动、就餐这些日常场合自评。
- 把革命落到劳动现场：在田野、农场、车间、岗位等学生真实接触的场所讲“革命在继续进行”，让责任有落点。
- 用对比材料做讨论：借报道他人困苦的书信与照片，让学生自己理解今天的安定生活来之不易，而不是靠灌输结论。
- 与 sk-1234（现有卡）连读：sk-1234 是原则卡，讲“在当今做个革命者意味着什么”的道理；本卡取同篇的实践面，落点是事实材料的用法、革命修养的衡量尺子、对比式教学和“思考幸福”的具体教育任务。
- 教师成长方向：把“教学生思考幸福”列为明确的德育任务，并允许孩子体验忧虑、担心和良心的谴责，而不是只求课堂气氛愉快。
- 集体教育：让集体的智力生活和思想生活充满自由劳动的思想，靠集体的话语和行动共同维持。
