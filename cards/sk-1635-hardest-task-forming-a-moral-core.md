# Card sk-1635 — 教育者最困难的任务：形成坚不可摧的道德核心

## 原文/Excerpt

> 人的行为道德美是产生个人的信念和公民崇高精神的来源之一。我认为，教育者最困难的任务是：使每个学生形成一个坚不可摧的道德核心、树立理想、永远对坏事怀有毫不妥协的旺盛的斗争精神、养成在复杂的生活环境中能独立辨别方向的本领。

## 中文转述/说明

苏霍姆林斯基先给结论：**人的行为道德美是产生个人信念与公民崇高精神的来源之一**。接着他说出自己认为最难的那件工作——**使每个学生形成一个坚不可摧的道德核心、树立理想、永远对坏事怀有毫不妥协的斗争精神、养成在复杂生活环境中能独立辨别方向的本领**。他把「培养个性」直接等同于**培养坚忍不拔、不可战胜的道德品质**：有了它，人才能成为对别人产生良好影响的源泉，也才能**自己教育自己**。

## 教育场景/应用

- 德育目标不要写成口号清单，先问：这个学生的「道德核心」是什么？ - 可用于班主任与家长谈话：把重点从行为纠错转到品质形成。 - 也可用于评价设计：把「能否独立辨别方向」当成高年级的德育指标。
