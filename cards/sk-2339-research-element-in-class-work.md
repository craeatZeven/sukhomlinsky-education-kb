# Card sk-2339 — 智力的独立性来自课堂智力劳动中的研究因素

## 原文/Excerpt

> 智力的独立性和创造性之所以形成，是由于学生在课堂上的智力劳动中，即在初步感知知识的过程中，特别是在发展和加深知识的过程中，包含有研究的因素。例如，学生在着手学习新的几何图形或几何体的特性时，他们便绘出图形或制作表示各个组成部分及其相互依从关系的示意模型。

## 中文转述/说明

这句话把独立性和创造性从天赋话题拉回到课堂设计上：它们的来源被指认为智力劳动里的研究因素，而不是聪明或灵感。注意作者给的范围很宽——初步感知知识时要有，发展和加深知识时更要有，也就是说「研究」不是高年级或课外小组的专利，而是每一节课的常规成分。他举的例子是让学生自己画图、做示意模型来表示各部分的依存关系，这类动作迫使学生在动手之前先把关系想清楚。对教学的直接推论是：一节课若只有教师讲解和学生听记，就几乎没有研究因素，独立性与创造性也就没有生长的地方；反过来，只要让学生自己动手去表示、去解释关系，普通课也能长出研究性。

## 教育场景/应用

- 每节课至少安排一个学生自己动手的环节：绘图、做示意模型、解释依存关系，而不是听完就记。
- 备课检查里加一条：这节课的研究因素在哪里？若只有讲解与练习，补一个表示关系的动手任务。
- 把学生的自主绘图和模型当作理解证据保存，用于判断他是否真的看清了各部分的依从关系。
