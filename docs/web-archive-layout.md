# 网页版式：档案层 / 阅读层的分而治之（2026-09-10 实施并验收）

> 缘起：用户要求「找同类高级感网页」。调研 24 个站（`D:\Git\tools\web-standard\inspiration\2026-09-10-knowledge-archive-sites.md`）后，
> 发现两条硬结论：① 真正做长文阅读的高级站，栏宽都在 27–45 中文字/行，本站详情页是 64 字/行；② 8 个参考站里 6 个内容区圆角 0–2px、全站阴影 0–1 处，与工作区既有「杂志风精致化」（圆角 14px + 柔和阴影）方向相反。
> 用户拍板 **方案 C 分而治之**：列表走档案版式，详情保留杂志阅读。本文是实施与验收记录。

---

## 一、分工规则（一句话）

> **内容列表 = 档案**（目录行、零圆角、hairline、深色 chrome 层）
> **封面与详情 = 杂志**（圆角卡片、纸感、衬线大引文、阅读栏宽）

| 层 | 页面 / 区块 | 版式语言 |
|---|---|---|
| chrome 层 | 顶栏、页脚 | 暖深灰底 + 浅色字（`--chrome` / `--chrome-ink` / `--chrome-soft`） |
| 档案层 | 主题浏览、故事目录、最近更新、专题页卡片列表、问题检索结果、检索页结果、来源卡、案例卡 | 目录行（`.rows .row`）、圆角 2px、无阴影、hairline 分隔 |
| 杂志层 | 首页 portal 卡、卡片详情、首页随机原文 | 圆角 14px、柔和阴影、hover 上浮、衬线大引文 |
| 阅读层 | 卡片详情正文、专题正文 | 栏宽 `--read: 700px`、引文 21px、事实表 + 溯源块 |

## 三、验收（`local_working_copy/web-audit/`，CDP 驱动 headless Chrome）

**页面与交互**：18/18 页面零控制台错误、零页面异常；5 条交互流程全 PASS
（深度检索、故事深度检索、目录行结构 + 出处 popup、后端不可达自动降级、后端被屏蔽时降级）。

**版式机检**（`metrics.mjs`）：

| 检查项 | 结果 |
|---|---|
| 横向溢出 | 全部页面 **0** |
| 列表页首条目录行位置 | 主题浏览：桌面 1096 → **616 px**；移动 1675 → **540 px**（均在视口内） |
| 目录行字号 | 桌面 21 / 12 px；移动 **17 / 14 px** |
| 移动端触控目标 < 40px | 主题浏览 43 → **0** |
| 专题页（225 张卡） | 页面高度 32667 → **7184 px**，DOM 2506 → **504**（改为每屏 40 行 + 加载更多） |

**字阶与对比度**（`aesthetics.mjs`）：

- 字阶仍是 6 级 **12 / 14 / 17 / 21 / 26 / 34**，相邻级差 1.17 / 1.21 / 1.24 / 1.24 / 1.31（新增样式全部收回字阶，未引入 12.5 / 15 / 18 / 20 这类散值）；
- 对比度全部过 WCAG AA：正文 13.66:1 · 目录行引文 12.3:1 · 目录行元信息 5.04:1 · 顶栏导航 5.79:1 · 顶栏品牌 11.19:1 · 页脚 5.79:1 · chip 5.5:1。

**视觉复审**：第 3、4 轮视觉模型审图（截图在 `web-audit/shots/`）指出的可执行项已修——
元信息语义分组（加 `·` 分隔 + 移动端提字号）、悬浮控件遮挡（移入顶栏）、档案页统计卡过重（改安静小字）、故事页数字重复、详情页事实表与出处重复（新增 `KB.refShort()` 去重）、顶栏硬边（加细阴影）。

## 四、顺带修掉的两个数据/展示问题

1. **书源状态泄漏到前台**：`meta` 字段把 `status:registered` 拼进了出版信息，用户在出处 popup 和书源页都能看到这句内部术语。现在 `status` 拆为独立字段（供维护用），前台只显示「出版社 · 年份」。
2. **溯源字段未进前端**：`created` / `updated` / `reviewed_by` 一直在卡片 frontmatter 里，但构建链路没带出来。现在贯通到单卡 JSON，详情页新增「关于本卡」溯源块（编号 / 录入 / 校订 / 校验 + 修正入口）——参照 V&A 的 `About this object record`，让页面显得有制度而非个人笔记。

## 五、维护约定

- 新增列表页：用 `.rows` + `KB.cardRowHTML()`（不要用卡片网格）；新增详情/阅读内容：用 `.card--reading` + `--read` 栏宽。
- 砖红（`--accent`）只允许出现在 4 处（见 §二）；新增用法前先问「这是第 5 处吗」。
- 新增字号必须落在 12 / 14 / 17 / 21 / 26 / 34 上（`aesthetics.mjs` 会机检）。
- 回归：`node local_working_copy/web-audit/{audit,metrics,aesthetics}.mjs`。
