# Card sk-1958 — 少年寻找朋友，是正在成长的人的一种精神需要

## 原文/Excerpt

> 自我意识的发展，兴趣的差异，对自己个人爱好、力量和能力的认识，会加深少年了解自己同学精神面貌的兴趣。少年有着寻找朋友的“渴望”，这是正在成长的人的一种精神需要，他渴望找到思想、感情、兴趣、要求和观点与他自己的精神面貌和谐一致的朋友。

## 中文转述/说明

这条把友谊的起点放在认识自己上：少年先看清自己有什么爱好、力量和能力，才对外部发生兴趣——先是对同学的精神面貌感兴趣，然后才产生找朋友的渴望。作者随即给这种渴望定了性：它不是社交偏好或随大流，而是「正在成长的人的一种精神需要」，而且他要找的不是玩伴，是精神面貌与自己和谐一致的人。对教师的含义是：少年期成对交友、结成小圈子，是发展性的需要，不是纪律问题；该经营的是他有没有足够的精神内容可供识别，而不是先把圈子拆开。

## 教育场景/应用

- 看到少年三两人固定结伴时，先不当纪律问题处理，先看这个小圈子里在交换什么。
- 帮少年认识自己的兴趣、力量和能力的边界，让他知道自己想在朋友身上找什么。
- 评价学生的人际状况时，问的不是「有没有朋友」，而是他找到的人与他的精神面貌是否一致。
- 对交友迟迟没有起色的少年，先补他可以被别人认出的那一面，而不是催他去合群。
