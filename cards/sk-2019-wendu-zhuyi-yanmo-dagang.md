# Card sk-2019 — 按季度分配德育内容、要教师写大量计划，会把大纲淹没在文牍里

## 原文/Excerpt

> 有些人之所以做出“教育工作大纲无用”的结论，在我看来，是由于许多学校在教育实践中没有很好贯彻德育的一条重要原则—远景性原则，是由于忽视了教育大纲的特殊性。人们曾期待这个大纲，对它抱着很大的希望，可是有了这个大纲之后，有人却又像执行基础学科的教学大纲那样来执行它，即按季度来分配教育工作大纲规定的内容：在这个季度搞完谦虚品德的教育，下一个季度搞忠诚老实的教育，等等。有的地方则要求教师写大量的计划、日记和汇报。这件工作本来只要教师发挥创造精神就可以搞得生动活泼，却被文牍的浪潮给淹没了

## 中文转述/说明

这里指出大纲被判定“无用”的真实原因不在大纲本身，而在执行方式：把它当成学科大纲那样按季度切块——这一季度谦虚、下一季度忠诚老实——再叠上计划、日记、汇报。苏霍姆林斯基的原话很克制，只说文牍把本该生动活泼的创造精神淹没了。对今天做学校管理的人，这是一个可查的机制：任何一份德育要求，只要它带来的文书量大于它带来的教育动作，就会被执行成负担，然后被宣布为无用。

## 教育场景/应用

- 检查德育要求带来的文书量：表格、日记、汇报多于实际教育动作的，先砍文书。
- 明确反对按季度切块分配品德条目，改为按远景规划逐年展开。
- 学期末问教师“这份要求让你多做了什么”，把答案当作它是否值得保留的判据。
