# Card sk-1310 — 我们在儿童身上延续自己

## 原文/Excerpt

> 透过这个家庭教育的实例我欣喜地发现，儿童是通过劳动来认识世界的，并由此认识了事物和现象，在儿童的心中形成了道德的标准。这样儿童就形成了对待周围事物的态度，而且自幼就做到爱憎分明，对游手好闲、懒懒散散的行为嫉恶如仇。……我建议不要使孩子与尘世隔绝。认识人生应从认识人开始。……如果你们这些做父母的想使自已的孩子产生做好人的愿望；想使他们尊重自己的人格；想使你们的话和意愿成为他们的行为准则，那么你们就要使他们看到生命之树的全貌：从纤细的树根到枯死的枝条。……我们称这种家庭教育为社会教育。社会是一座大厦，它是由许多的砖，即家庭筑成的。一块块的砖坚实，大厦也就坚实；家庭这些砖糟糕，社会也就危险了。而糟糕往往就糟糕在缺乏责任感上。……创造家庭并使之得到巩固的力量是爱，是父母之间、父子之间和母子之间那种彼此忠诚、忠贞不渝的爱。然而，爱并非来自外界的一种灵感或祥光。爱是一种艰苦的劳动。“家庭就是靠不懈的爱的劳动建立起来的”—陀思妥耶夫斯基这样写道。爱的劳动是一种自觉的行为，它的目的就是在孩子身上再塑自已，延续自己内在的精神美。

## 中文转述/说明

《我们在儿童身上延续自己》把“家庭怎么安排”讲得很具体。第一件事是让孩子进入真实的共同劳动：小奥莉娅总说“我俩在干活呐”“我俩累了”，她在与奶奶一起做家务中认识世界、认识他人，并由此形成道德标准——自幼爱憎分明，对游手好闲、懒懒散散嫉恶如仇。所以家庭安排的要点不是给孩子安排课程，而是给他一个可以“我俩一起”的真实劳动位置。

第二件事是不把孩子与生活隔离。奶奶病重时，苏霍姆林斯基建议不要让五岁的孩子与尘世隔绝：认识人生应从认识人开始，人的生老病死对儿童也是一种教育。若父母想让孩子产生做好人的愿望、想让孩子尊重自己的人格、想让自己的话成为孩子的行为准则，就要让他看到“生命之树的全貌”——从纤细的树根到枯死的枝条。

第三件事是把爱当作劳动来安排。家庭得以巩固的力量是父母之间、父子之间、母子之间忠贞不渝的爱，但爱不是外来的灵感或祥光，而是一种艰苦的劳动，是自觉的行为，目的是在孩子身上再塑并延续自己内在的精神美。家庭教育因此是社会教育的砖：砖坚实，大厦坚实；砖糟糕，社会危险，而糟糕往往就糟糕在缺乏责任感上。

## 教育场景/应用

- 家务安排上给孩子固定岗位而非临时帮忙：让他和大人共用“我俩一起……”的说法，把劳动当成共同生活而不是任务分派；孩子做得慢也不要代劳。
- 允许孩子参与家庭中的真实事件，包括疾病、丧事、经济紧张等，用他听得懂的方式说明，而不是把他隔离在“小孩子不懂”的保护罩里。
- 与孩子一起复盘劳动成果（如孩子亲手做的手工、种的菜），让他的劳动被家人认真看待，劳动因此成为他认识世界和判断是非的入口。
- 父母把夫妻之间的忠诚与照顾当作日常可见的劳动示范：爱需要坚持付出，不能靠一时的情绪或灵感；家庭责任感缺失，孩子最先受损。
- 与 sk-0252（现有卡）连读：sk-0252 摘的是“爱是一种艰苦劳动”的价值判断，本卡补上家庭操作面——怎么排家务、怎么让孩子参与真实生活、怎么让爱变成可持续的自觉行为。
- 与 sk-0253（现有卡）连读：sk-0253 摘的是“儿童通过劳动认识世界并形成道德标准”这一发现，本卡把它扩展成家庭的整体安排：劳动位置＋不隔绝生活＋爱的劳动，三条同时落地。
