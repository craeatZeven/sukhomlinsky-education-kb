# Card sk-0904 — 如果时间停止，将会发生什么

## 原文/Excerpt

> 很久以前，一个男孩瓦西里克在一所不大的乡村学校中学习。……在一间被称为教师室的小房间里，挂着一只小钟——简便的挂钟。它们快乐地滴答、滴答地响着，计算着时间。……“给你学校的钥匙，瓦西里克，”老师说，“每天早晨，你到学校来，打开校门，到教师室去，把重锤拉上去。如果你忘了，没来学校，灾难就会发生。”“什么样的灾难？”瓦西里克害怕了。“时间将会停止。”瓦西里克惊奇地睁大眼睛。他不知道，老师是在开玩笑，还是说的真话。……瓦西里克沉思起来：“如果时间停止了，那会发生什么呢？”他试图想象，会发生什么样的灾难，但胡思乱想什么结果也没有。不过，为了让不幸不至于发生，早晨，他早早起床，来到学校，打开校门，倾听着挂钟均匀的嘀嗒声。他高兴地确信：时间走着，时间没有停止。然后，他把重锤拉了上去，关上校门，回家去了。……瓦西里克微笑着，他知道，无论是安谧、快乐的早晨，还是安逸的人们，还有从院子里跑到乡村街道上去的飞快的小车，所有这一切之所以存在，是因为他把挂钟的重锤往上拉，时间，才幸运地没有停止。

## 中文转述/说明

夏天，二年级读完的瓦西里克骄傲地告诉父母自己已经是三年级学生。老师去休假，把一件“大事”托付给他：学校教师室里那只靠重锤走动的挂钟，一昼夜下来重锤会降到很低，若没人往上拉，钟就可能停止走动。老师把钥匙交给他，说每天早晨来把重锤拉上去，“如果你忘了，没来学校，灾难就会发生”。“什么样的灾难？”“时间将会停止。”瓦西里克分不清这是玩笑还是真话，但他心里有个声音暗示这是玩笑——可也许，真的会发生这种事呢。他想不出时间停止会带来什么灾难，却还是每天早早起床，打开校门，听挂钟均匀的嘀嗒声，确信时间没有停止，再把重锤拉上去。

故事的妙处在于：孩子并不是被“灾难”吓住才坚持的，而是在承担一件被托付的小事中，慢慢把自己和整个村庄的清晨联系了起来。他知道安谧的早晨、安逸的人们、街上跑过的小车之所以存在，是因为他拉了重锤。一件看似微不足道的日常劳动，被孩子理解为世界正常运转的一部分，责任感便由此生根。

## 教育场景/应用

- 可用于劳动教育：给孩子一件真实、连续、有意义的“小事”（如每天给花浇水、开关教室窗户），让他在坚持中体会自己对集体的作用。
- 可用于班主任工作：把班级中的具体岗位交给学生，并说明这件事与大家生活的关系，比空讲“要有责任心”更能长出责任感。
- 可用于儿童研究：孩子分不清玩笑与真话时，往往不是幼稚，而是在认真对待成人交给他的世界，成人应珍惜这种认真。
- 可用于家校沟通：请家长在家中留一件需要孩子长期负责的小事，不催不代，让孩子自己发现“因为我在做，所以一切都好”。
