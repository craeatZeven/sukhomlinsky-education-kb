# Card sk-2109 — 滥用权力和把学习当惩罚，会把学生的心地变得粗暴冷酷

## 原文/Excerpt

> 教师如此滥用自己对学生的权力，将会导致儿童心灵空虚，产生人对人的不信任，甚至相互仇恨。在这种气氛中根本谈不上集体，因为儿童喜爱的学习活动并没有把他们团结起来。凡是教师利用学习作为惩罚手段，因而使学习变成学生痛恨的事情的地方，学生就会怕教师，他们的心地就会变得粗暴、冷酷和无情。

## 中文转述/说明

作者把「用抄写多少遍来罚学生」这种常见做法追到结果上：滥用权力的第一层代价是儿童心灵空虚、人与人之间不再信任，甚至相互仇恨；第二层代价是集体根本谈不上存在，因为把他们聚在一起的学习活动，已经被教师做成了学生痛恨的事。他给的因果很直白：凡是在把学习变成惩罚的地方，学生就会怕教师，心地变得粗暴、冷酷、无情。所以这不是「管得严不严」的问题，而是把评价手段挪去做惩罚，直接损害了学习本身和师生关系。

## 教育场景/应用

- 不用抄写、罚做题、加作业作为纪律手段；要处理纪律问题，就在纪律的范围内处理。
- 检查自己的常规做法里有没有「学习任务＝惩罚」的暗示，例如把作业量与过失挂钩、拿分数当威慑。
- 发现学生是怕自己而不是服理时，先撤掉惩罚性任务，再谈关系修复——怕教师本身就是这条判据的警报。
