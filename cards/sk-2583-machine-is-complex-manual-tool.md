# Card sk-2583 — 不把机器看作放大的手工工具，学生就学不会整体地看技术

## 原文/Excerpt

> 智力的发展在很大程度上还取决于学生对手工性劳动与机器的工作之间的关系理解到何种程度。只有当一个人把机器看成是一种完全复杂化、自动化了的手工性劳动的工具，他才能把它当做一个整体来对待。这是能在综合技术方面见多识广的重要先决条件。学生们应该学会很好地使用手工工具来进行劳动，其目的首先在于更好地了解机器的构造和工作原理，因为机器就是由这些工具改造而来的。

## 中文转述/说明

他把「综合技术眼界」的根扎在一个认识上：机器不是凭空出现的新东西，而是复杂化、自动化了的手工劳动工具。学生只有先这样看机器，才能把机器当作一个整体来对待；而这正是综合技术方面见多识广的先决条件。所以他主张先学好手工工具的使用，目的不是怀旧，而是为了理解机器的构造和工作原理——机器本来就是由这些工具改造而来的。对技术教育的含义：如果从机器操作起步、跳过手工工具这一环，学生拿到的是操作步骤而不是整体理解；反过来，手工课若不指向「机器是怎么来的」，也只剩练手。

## 教育场景/应用

- 上机器操作课前，先用同样的任务做一遍手工工具版本，让学生说出两者结构和受力上的对应关系。
- 让学生画一张「从手工工具到这台机器」的演变图，标出哪些部分被保留、哪些被替换。
- 检查理解时问「这台机器坏在某个部位，你能从手工工具的经验里怎么找原因」，而不只考操作步骤。
