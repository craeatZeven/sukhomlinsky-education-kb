# Card sk-2153 — 备课前先弄清我在对谁讲话，否则就是给抽象的人上课

## 原文/Excerpt

> 假如我不知道，在课堂上我面对的是谁，不知道柯利亚和季娜、托利亚和瓦里娅在想些什么，那我就好像是在给抽象的人上课。在思考我在课堂上阐明的某些观念时，我考虑到的首先是我的每一个学生的心灵。应该用生动的话语来阐明这些观念，并且以活生生的心灵和思想的颤动来充实自己话语的力量。

## 中文转述/说明

这段话的落点不在「要爱学生」，而在备课的第一个动作：把面前的人具体化。苏霍姆林斯基说的是，他准备一节课时，脑子里先出现的是柯利亚、季娜这些具体的名字和他们此刻的念头；如果这一步没有，讲课就变成对着一个抽象的「学生」说话，观念再正确也落不到人身上。今天可迁移的做法，是把「学情」从一句口号变成教案里的一栏：这节课我要对谁讲、他们此刻在关心什么、哪一句话可能正好戳到谁。这样备出来的课，话语才有分量。

## 教育场景/应用

- 写教案时加一栏「这节课我要问谁」：写下三个具体学生的名字，以及预计他们会卡在哪一步，课后回来核对是否猜中。
- 接手新班的前两周，用课间十分钟轮流和每个学生单独说三句话，记下他最近在意的一件事，备课时当作例子用进去。
- 讲一个较抽象的观念前，先在心里过一遍班上哪几个孩子会听不懂、哪几个会立刻反问，把要反问的问题提前准备好答案。
