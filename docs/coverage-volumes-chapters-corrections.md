## 四、处置

1. **补卡**：2026-09-09 新建 `sk-1259`–`sk-1262`，分别对应第 33、36、40、52 篇（原文行号 3914–3978 / 4071–4118 / 4313–4356 / 5177–5224）。

3. **重建审计表时的口径建议**：per-unit 卡片归属**以卡片 `ref` 自写的行号/节名为准**，不要用「标题相似度」自动归位——后者会被同作品名的长公共子串吸卡（如《年轻一代共产主义信念的形成》第 3 章标题与作品名共享 9 字，导致任何含作品名的卡都被第 3 章吸走，见 `local_working_copy/vol2-density-report.md` §2.5）。
