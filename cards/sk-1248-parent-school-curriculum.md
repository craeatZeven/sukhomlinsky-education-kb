# Card sk-1248 — 怎样培养母亲和父亲做好学校和家庭的协同教育工作

## 原文/Excerpt

> 据我看来，没有比让母亲和父亲学会如何教育儿童更为重要的任务了。我们根据多年的.1.作实践，得出-个结论：不关心家长的教育修养，任何教育和教学任务都不可能完成。家长教育学，即父母关于怎样培养斤女成人的初步知识，是整个教育理论和实践的基础……我们这里设有家长教育学校，其中分为：学前邵、至年级学生家长部，四至八年级学生家长邵，九至Ⅰ年级学生家长部。在送自己孩子人学前3年.母亲和父亲就开始在家长教育学校里学习。他们每两周听一次课，由校长、主管教育和教学工作的副校长、主管课外工作的副校长和3年后将担任-年级工作的教师讲课，下面就是家长教育学校学前部1964\~1967年的工作计划（在这里学习的家长，其子女于1967年秋季人---年级学习）：……(1)4\~7岁儿童身心的发育；(2) 怎样预防儿童患病；(3)儿童的生活制度、饮食和身体锻炼；(4)4\~7岁儿童的智育；(5)母亲和父亲如何关怀儿童语言和智力的发展；(6) 怎样预防儿童的神经官能症；(7)4\~7岁儿童的劳动教育；(8)怎样培养儿童尊敬长者；(9) 学前儿童的大自然教育；……(34)怎样防止儿童任性；(35)家长的权力是什么以及怎样使用这种权力；(36)怎样不用惩罚进行教育；(37)惩罚是利多还是弊多；(38)仆什么可以和什么不可以要求于儿童：(39)教育子女是父母最重要的社会义务。……内为你作为教师，必须准备和讲授这些题目……为了深刻思考过错，为了斤诚布公地交谈家庭具体情况下的教育，还有另一种工作方式，即同家长个别谈话……同母亲和父亲个别谈话—儿童不在场的谈话，是我们家长教育学校的--个有机组成部分、我特别强调了，这是儿童不在场的谈话。

## 中文转述/说明

苏霍姆林斯基把家长教育学校当作一项常规课程来办，而不是零散的家长会：不关心家长的教育修养，任何教育和教学任务都不可能完成，家长教育学是整个教育理论和实践的基础。学校按学段分成学前部、一至三年级、四至八年级、九至十一年级四个部，父母在孩子入学前三年就开始学习。

课程节奏是固定的：每两周听一次课。讲课人也有分工——校长、主管教育和教学工作的副校长、主管课外工作的副校长，以及三年后将要接一年级的教师。这样，讲课的人就是将来要面对这批孩子的人，家长与教师的信任关系在入学之前就已经开始积累。

学前部的课程表本身是 39 个专题，顺序清晰可执行：从 4~7 岁儿童身心的发育、怎样预防疾病、生活制度饮食与锻炼、智育、语言和智力发展、预防神经官能症，到劳动教育、尊敬长者、大自然教育、需要与兴趣、对现实的认识和情感、人的情感、美育、创造、防止冷漠、克制欲望，再到儿童对学校教学的心理准备、家长的权力、怎样不用惩罚进行教育、惩罚是利多还是弊多，最后落在“教育子女是父母最重要的社会义务”。

讲法上有一条硬约束：不“揭人心事”、不当众点名，把家长教育学当作劳动、科学、技艺和创造来讲；需要深入分析家庭具体情况的，转为同母亲或父亲的个别谈话，而且必须是儿童不在场的谈话。

## 教育场景/应用

- 排一学期的家长课表：每两周一次课，专题顺序照苏氏学前部清单走（发育→健康→生活制度→智育→情感→美育→劳动→家长的权力与惩罚→社会义务），每次留出讨论时间，一学期讲十来个专题，跨三年讲完全部。
- 与 sk-1048（现有卡）连读：sk-1048 讲家长教育学校的建制原则——“学校先培养家长的教育修养”而不是要求家长配合；本卡把它落成可执行的课表（分部门、提前三年、每两周一次的节奏、讲课人分工与个别谈话安排）。
- 讲课人分工：校长讲总体与家校关系；教学副校长讲智育与入学准备；课外工作副校长讲情感、美育与劳动；三年后接一年级的教师讲“我们怎样看你们的孩子，你们应怎样看他”，让家长提前认识未来的班主任。
- 实习课安排：可参照书中做法，让家长在低年级集体公益劳动日里与教师一起带劳动，边教孩子边学当教育者——这一配套形式详见下篇 54。
- 讲课纪律：讲坏事不点犯过错家长的姓名，不用“照镜子”的方式逼家长承认失败；需要深谈的改成个别谈话，且明确儿童不在场。
- 与 sk-1056（现有卡）连读：sk-1056 讲父母行动统一与三种不理智的爱；本卡把这类内容固定在“家长的权力是什么以及怎样使用这种权力”“惩罚是利多还是弊多”两个专题里讲。
