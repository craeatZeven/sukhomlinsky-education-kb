# Card sk-1096 — 爱惜并发展青少年的记忆力

## 原文/Excerpt

> 死记硬背总是有害的，在青少年时期，尤其不可这样做。在这种年龄死记硬背会产生幼稚病——使成年人停留在幼稚时期，使他们智力迟钝，阻碍能力和爱好的形成。……过多的有意记忆简直可以使人变成傻瓜。……要做到这一点，惟一的办法是：建立有意记忆和无意记忆的合理比例关系。如果八年级学生应记住的教材数量用x表示，那么，在这个时期内学生应理解和思考的教材就应多几倍，为3x。……如果有意记忆以无意记忆为基础，即以阅读和思考为基础，那么，少年学生在学习课本的过程中就会产生许多问题。他知道得越多，他不懂的地方就越多；不懂的地方越多，他按照教科书学正课就越容易。

## 中文转述/说明

苏霍姆林斯基反对青少年用“分批背熟、再分批说给老师听”的儿童式方法学习。死记硬背会造成书呆子气，使知识脱离生活，甚至阻碍能力和爱好的形成。但中高年级教材又确实要求有意记忆，怎么办？他的答案不是取消背诵，而是调整比例：该记住的内容设为x，该理解和思考的内容就应是3x。

这个比例的关键在于让有意记忆长在无意记忆之上——以阅读和思考为基础。学生读不要求记住的有趣书籍，会记住许多东西，但这种记忆建立在兴趣、思考和“读书入了迷”的基础上，认识的情感因素起很大作用。思想越活跃，有意记忆就越发展。于是出现一个反直觉的结果：学生知道得越多，不懂的地方越多，而按教科书学正课反而越容易。

## 教育场景/应用

- 可用于中高年级学习方法指导：教学生把“要背的”和“要读要想的”按1∶3配比安排，而不是把全部时间用于背课本。
- 可用于减轻死记硬背负担：在布置记忆任务时，同时提供相关的有趣读物，让无意记忆为有意记忆打底。
- 可用于学习困难干预：对“背了就忘”的学生，先检查其课外阅读和思考量是否过少，而非加大背诵量。
- 可用于家长沟通：提醒家长不要用“多背几遍”解决理解性问题，把家庭时间分一部分给自由阅读。
