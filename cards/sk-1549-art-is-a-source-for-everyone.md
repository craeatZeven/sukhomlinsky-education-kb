# Card sk-1549 — 不论学什么专业，艺术都是经常源泉

## 原文/Excerpt

> 不论我们学生的未来专业是什么，我们认为，艺术应当成为每一个人精神财富的经常源泉。

校勘记录（已校勘 0 处，改前→改后）：

- 起点回补「不论我们学生的未」（选集作「不论我们学生的未来专业是什么」，原窗口切掉前 7 字）

- **起点说明**：起点为句中摘引（选集此处为「然而，不论是否如此，不论我们学生的未来专业是什么」，卡片自第二个「不论」起引；被切开的前一字「未」已在 2026-09-20 回补）· 待核

## 中文转述/说明

他的判断不看将来做什么：**不论学生未来的专业是什么，艺术都应当成为每一个人精神财富的经常源泉**。

## 教育场景/应用

「经常源泉」这四个字把它和「特长」区分开：不是给有天赋的孩子准备的。
