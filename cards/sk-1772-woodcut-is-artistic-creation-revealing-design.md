# Card sk-1772 — 木刻是艺术创作，每个人的思维与创作构思的特点正是在这种创作中展示出来

## 原文/Excerpt

> 在临近傍晚的时分，我们手里拿着小小的木刻刀就坐到这些小桌旁边。我们雕刻出别出心裁的木刻画—一些飞禽走兽以及一些只在神话中才有的与幻想出来的事物的雕像。这是一种艺术创作，每个人的思维与创作构思的特点就是在这种艺术创作中展示出来的。

## 中文转述/说明

这段文字值得注意的不是木刻本身，而是作者给这项活动定的性质：它被称作「艺术创作」，而作者认为每个人的思维与创作构思的特点正是在这种创作中展示出来的。换句话说，木刻在这里承担的是观察与表达的通道，而不只是手工课的一项技能。前文细节也说明问题——橡树阴下的小桌子、临近傍晚的时分、手里的小刻刀，活动被安排成一个能安静投入的场景；作者随后又坦承有些少年（佩特里克、瓦莉娅、尼娜）怎么也不能被木刻吸引，说明他并不把兴趣当作可以强加的结果。

## 教育场景/应用

- 安排手工活动时把它当「创作」对待，让学生在里面表达自己的构思，而不是照图纸复制。
- 提供能安静投入的场景（固定时段、固定角落、够用的工具），让创作有条件发生。
- 学生对手工活动没兴趣时按个体差异接受，不把兴趣当作必须达成的结果。
