## [2026-09-19] web | 分析页补上 h1（渲染器一直把一级标题降成 h2）

- 症状：14 个 note 页都没有 h1，axe 每页报一处 page-has-heading-one（moderate，09-17 起就在）
- 真因：`build_notes.py` 的 render() 写的是 `h{lvl + 1}`，把 Markdown 的每一级都降一级：
  文档标题（`#`）被渲染成 h2，于是**吃了章节标题的样式**（21px + 左侧 4px 强调竖条），
  真正的章节标题被挤到 h3（17px）——**竖条一直挂错在标题上**
- 而 CSS 里 `.note-body h1 { 30px 衬线 }` **早就写好了**，只是渲染器从没产出过 h1。
  又一次「写了但没实现」——和第十六版那条「注释里写着、代码里没做」是同一类
- 修：按 Markdown 原级输出（`#`→h1 / `##`→h2 / `###`→h3）。render() 只被 note 页调用，不影响别处
- 顺带：两页的表格第一列表头是空的（axe MINOR empty-table-header）——标题修好后这条才露出来——补上「维度」
- 结果：**14 个 note 页 a11y 全部干净**（改前 14 页各 1 处 moderate）
- 提交 d0740a4
