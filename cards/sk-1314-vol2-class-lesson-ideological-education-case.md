# Card sk-1314 — 什么是课堂上的思想教育

## 原文/Excerpt

> 以详尽地知道尤利乌斯·伏契克的悲剧性英雄的一生和斗争，连细节也不放过，然而，知道事实只是知识，还不是思想。当读者在内心里成为这位英雄的热烈钦佩者时，才会产生思想。如果你的学生准备与英雄并肩前进，愿意为这位共产党员英雄为之献身的事业贡献出白已的生命，那么，在这种情况下，你作为教育者所接触的就是思想。……即使是自然科学的-一些学科，也有很大一部分知识本身包含着激烈的思想斗争与冲突。许多科学真理是付出了很高的代价才获得的—很多杰出的思想家为之献出了生命。朋友!我建议你要特别细心对待这种真理的研究。在讲述太阳系时，要使自己的语言对那些反对因循守旧、愚昧无知、反对在精神1奴役人民的思想家充满深深的崇敬感情。要使为真理而斗争的思想家的形象给学生留下鲜明的印象，使青少年的头脑巾生-个想法：凡是真理，都是革命的。……在讲授人文学科的课堂上，没有、也不可能有思想上的中性材料。……你应该看到，你面前足具体的、活生生的、独特的人们———柯利亚和尼娜，瓦利亚和谢尔盖，等等。这些人都有自己的思想和感情、抱负和十劲。……教历史的教育艺术奥秘，是要赋予正在掌握知识的人以战土的灵魂。……只有通过时代的透镜，才能止确地看到和理解任何历史事件的意义。……必须对知识加以思考。要思考你从人类财富的宝库中吸取的-一切，以及向你的学生所灌输的一切。……思考知识，就是要了解、预见和估什每一条道理会触动人的心灵的什么部位，将引起什么思想、问题与疑团。

## 中文转述/说明

这一篇把“课堂上的思想教育”还原成几节具体的课。文学课上，教师让学生详尽知道尤利乌斯·伏契克的一生和斗争，连细节都不放过——但这仍然只是知识；只有当学生心里成为这位英雄的热烈钦佩者，愿意为英雄献身的事业贡献自己的生命时，思想才真正产生。也就是说，知识带出思想的转折点，是学生由“知道”变成“钦佩并愿意行动”。

理科课同样如此。苏霍姆林斯基指出，自然科学的很大一部分知识本身就包含着激烈的思想斗争与冲突，许多科学真理是付出很高代价才获得的，很多杰出的思想家为之献出生命。所以他要求：讲太阳系时，语言要对那些反对因循守旧、愚昧无知、反对在精神上奴役人民的思想家充满崇敬；要让为真理而斗争的思想家的形象给学生留下鲜明印象，使青少年脑中生出“凡是真理，都是革命的”这个想法。讲物理、化学、生物、数学，不要只是毫无感情地说明真理，而要引导青少年沿着科学的艰险道路作一次充满为真理而斗争动机的旅行。

文科课则没有思想上的中性材料。教历史的教师面对的从来不是抽象的学生，而是柯利亚、尼娜、瓦利亚、谢尔盖这样具体的、活生生的人，各有自己的思想和感情、抱负和干劲；思想只能存在于他们的心灵和头脑里。教历史的教育艺术奥秘，是要赋予正在掌握知识的人以战士的灵魂；而能否做到这一点，取决于两个条件——学校和集体生活中充满时代精神，以及教师的思想与个性和谐一致。最后落到教师身上：必须对知识加以思考，预见每一条道理会触动学生心灵的什么部位、会引起什么思想、问题与疑团。

## 教育场景/应用

- 可用于备课时设问：这节课结束时，学生是“记住了事实”，还是“对某事产生了自己的态度”？以伏契克一课为范例，把钦佩与行动意愿作为教学目标的落点。
- 可用于理科课堂：在讲太阳系、物质与能量、粒子等概念时补入科学真理的发现代价与思想家的形象，让理科知识带出价值判断，而不是纯技术说明。
- 可用于历史与文科课堂：把史料、事件与眼前具体的、有名有姓的学生联系起来，使他们对事件产生“参加者”的感受，而不是做麻木的知识需求者。
- 可用于“思考知识”的教研动作：教师在备课时逐条预估这条道理会触动学生心灵的哪个部位、可能引出什么问题与疑团。
- 可用于学校层面的条件建设：思想性不靠教师个人独撑，还依赖集体生活中是否充满时代精神。
- 与 sk-1167（现有卡，method）连读：sk-1167 提炼的是“知识—思想—信念”这条机制与结论，本卡补的是同一篇里支撑它的课例——伏契克的文学课、太阳系的理科课、面对柯利亚和尼娜的历史课，以及“赋予掌握知识的人以战士的灵魂”这一具体目标。
