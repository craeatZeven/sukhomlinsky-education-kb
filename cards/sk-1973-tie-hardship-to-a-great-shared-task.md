# Card sk-1973 — 要用困难锻炼意志，就得把困难拴在一件需要集体长期用力的大事上

## 原文/Excerpt

> 从这种有明确目标的劳动中每次所感受到的快乐，犹如滴滴细流汇集成个源泉，滋养了我们必达目的的信念。假若您要想借助困难去锻炼意志，加强信念，那就要把这些困难用无形的纽带同需要花费大力气、时间并要求集体在精神和思想上统一的某项重大工作联系起来。

> 说明：引文自本 unit 首句起截取至「……重大工作联系起来。」（其后无别的内容）。引文内「汇集成个源泉」疑漏一字（当作「汇集成一个源泉」），**漏字不补**，照原文收录。本 unit 未见其他真讹字。

## 中文转述/说明

这一段讲的是困难的接法。作者先说快乐是怎么来的：从有明确目标的劳动里一点一点感受到的快乐，像细流汇成源泉，才滋养出必定达到目的的信念——注意是「每次」和「汇集」，不是一次大成功。接着给出方法：想借困难锻炼意志、加强信念，就不能让困难零散发生，而要用一条无形的纽带把它拴在一件需要花大力气、需要时间、并要求集体在精神和思想上统一的大事上。这个判断很有操作性——零碎的苦只会消耗人，被纳入共同目标的苦才会转成信念，因为它让学生知道自己为什么忍。

## 教育场景/应用

- 把日常的小困难接到一项班级或学校层面的长期共同目标上，并让学生看到这条连线。
- 在长期项目的每个阶段留出回顾的时机，让学生自己说出已积累的「细流」。
- 避免让学生承受零散、看不出目的、也无人共同承担的辛苦。
- 组织需要跨小组配合的任务，使「集体在精神和思想上统一」成为完成条件之一。
