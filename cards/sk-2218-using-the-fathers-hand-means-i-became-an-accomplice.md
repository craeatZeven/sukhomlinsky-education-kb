# Card sk-2218 — 把家长叫来告状，就是用他父亲的手打他——我成了从犯

## 原文/Excerpt

> 教师，请您记住，如果我知道我的格里茨科或者彼得的父亲是一个上帝只赋予他生孩子本领的人，而我却把这位有能耐的家长叫到学校里来对他说：“您的格里茨科是个懒汉，他不想学习”，这样就会出现最简单的现象——我用他父亲的手来打格里茨科。我伤害了人的尊严。我成了从犯。

## 中文转述/说明

这条把家校沟通里最常见的动作翻了个面：请家长到校、当面说孩子懒，教师以为自己在履行职责，实际上是把惩戒的执行权交了出去——「我用他父亲的手来打格里茨科」。作者对这件事的定性毫不含糊：伤害了人的尊严，自己就是从犯。判据是责任归属：一旦要借别人的手才能使教育生效，教育者就已经把自己那一份责任推出去了。

## 教育场景/应用

- 与家长谈孩子问题前，先判断「我这句话会不会变成一次体罚」，再决定措辞与场合。
- 学校建立不带惩罚委托的沟通规范：反馈问题同时给出学校自己承担的那部分措施。
- 家校冲突复盘时把「谁在执行惩罚」写清楚，它是判断沟通是否越界的硬指标。
