# 分类盲审结果（99 张样本，两批独立判读）

## 方法与可复现性

- 样本：从全部 718 张论述卡**按算法主归属等比例分层**随机抽 99 张（种子 20260910），题目文件只给「原文摘录 / 编辑转述 / 出处」，旧标签与算法结论另存 `key.json`。
- 判读：4 个独立 agent 各判一批，只能读题目 + 条目速查 + `taxonomy.md` 第二节；**同一批内容判了两遍（pass A / pass B）**，用来量判读本身的噪声。
- 作废 1 张：`sk-0317` —— `taxonomy.md` §六 人工裁定表里明文写着它的答案，判读者照抄了规格。
- 数字口径：「条目级一致」= 判读与算法给出同一条目；「同范畴一致」= 至少同一个观察角度；「前三可接受」= 判读答案落在算法关键词得分前 3 名内。

## 一、先量判读自身的可靠度

**两批独立判读互相一致 80/85（94.1%）**（85 张两边都给了答案）。

⚠️ **这是「两次判读彼此一致的比例」，不是正确率，也不是严格的噪声地板**——
两批判读是同一类判断者、同一套材料、同一份规格，它们的共同偏差不会被这个数字捕捉到。
它只能说明一件事：**判读结果稳定、可复现，所以下面的低一致率不是随机的判读抖动**。
（外部评审判定这个措辞不严谨，已改正。）

## 二、总体一致率

- **条目级：42/91（46.2%）** —— 判读与算法给出同一条目。
- **同范畴：58/91（63.7%）** —— 至少落在同一个观察角度里。
- **前三可接受：65/91（71.4%）** —— 放宽到「算法前三名算可接受」。

两个参照：① 19 个可选条目均匀随机猜是 5.3%；② 两批判读彼此一致 94.1%。
**46.2% 明显高于瞎猜；也明显低于判读的稳定度——差距主要落在条目边界上，不是随机抖动。**

（同范畴 63.7% 是「地图是否成立」的指标；条目级 46.2% 是「边界划得准不准」的指标。）

## 四、错误的结构：这不是随机噪声，是有成因的四类

### 类型 1｜两个条目在规格里就重叠（最该修，也最好修）

- **A5 尊严、爱与信任 ↔ A10 教师**（4 张，最大单一混淆）。A5 的判定关键词收了「教育者的爱 / 厚爱」，A10 的收录写的是「教师读书、自由时间、教育信念、校长工作」。
  于是「教师必须爱学生」「教学是人与人的关系」「没有信任便没有教育」这类卡**按关键词该归 A5，按旧标签 teacher-growth 该归 A10**——规格自己没给答案。
- **A5 ↔ A19 道德判断与品德培养**：判读两批都点出这是最糊的一簇。A5 关键词有「良心 / 奉献 / 自尊」，A19 收录是「一般德育」；「怎样培养良心感」「懂得奉献」两边都收。
- **A12 自然与思维课 ↔ A15 思维与智力**：判读四批里三批都提。A12 名字窄但收录写「观察与提问」，A15 收录写「记忆与注意」，凡是讲观察的卡两边都能接。

### 类型 2｜条目变成大口袋（关键词太泛）

- **A3 幸福与精神生活**：11 张样本里只对 1 张（9.1%）。关键词「情感 / 心灵 / 感受 / 体验」在几乎任何讲内心活动的卡里都出现，于是美育卡、德育卡都被吸到 A3。
- **A13 阅读与书籍**：7 张里只对 2 张。关键词里有单字**「书」**——它匹配「教科书」（df=212，全库 57 行是「教科书/证书」这类误命中）。「真正的学校是积极思维的王国」「学生应当掌握的最重要的技能和技巧」这种跟阅读无关的卡，被「顺带提到的阅读」拉进 A13。

> 这一类的病根在于：现在的打分是**「这些词出现过没有」**，不是**「这张卡是不是在讲这件事」**。
> 一个词在正文里被顺带提一次，就按 IDF 全额计分，所以越罕见的词越容易「一击致命」。

### 类型 3｜旧标签本身粗，先验把它拉偏

- 按定案方式拆：旧标签先验定下的 36/75（48.0%），算法推翻旧标签的 6/16（37.5%）——**两者都低**，说明问题不是「该不该信旧标签」，而是条目边界本身。
- 典型：`learning-difficulties` 的次选是 A15、`teacher-growth` 的首选是 A10，于是「后进生」「给教师的建议」系列被整批拉向 A15/A10，不管这张卡实际在讲什么。

### 类型 4｜规格真的没有那一格（7 张弃权全是这个原因）

## 六、处置建议

1. **不要在这 91 张上调关键词参数。** 试过了：逐个关键词降为弱证据，最好的一档只把一致率从45.7% 抬到 47.8%（+2.2pt）。调参在这里没有杠杆——**病在条目定义，不在词表**。
   （`local_working_copy/tune_experiment.py` 记录了这个扫描；真要调也只能拿它产生假设，**不能再用这 91 张报业绩**，否则就是过拟合。）
2. **先收紧条目定义**：把类型 1 的三对重叠写成互斥规则（A5 只管「怎么对待儿童的行为」，教育者的爱归 A10；A19 只管「培养品质」，A5 只管「对待方式」；A12 只管「自然中的课」，观察作为智力方法归 A15）。评审判读反复要求的那条元规则也要写：**以卡片主张的落点为准，不以标题为准**。
3. **补上缺口条目**，或不补但明确「这类卡归 X」。
4. **改打分口径**：把「出现过」换成「是不是主题」（例如按标题/首句加权，或对单字/泛词封顶）。
5. **做完以上三条后，用新样本复验**（换种子、换一批卡），再决定能不能迁移。
