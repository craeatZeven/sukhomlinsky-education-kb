# Card sk-1397 — 教师手里最巧妙的工具是语言

## 原文/Excerpt

> 教师应该掌握一种隐藏着同情心和对少年短处的宽容态度的最巧妙的工具一—语言。要小心谨慎，别使你的话成为一根触摸娇嫩的身体，灼伤它并使它永远留下难看的伤疤的鞭子。

## 中文转述/说明

语言是教师最主要的工具，也是最能伤人的工具。他要求话里**藏着同情心和对短处的宽容**。

## 教育场景/应用

说之前先过一遍：这句话留下来的会是一个提醒，还是一条疤。
