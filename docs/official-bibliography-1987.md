## 覆盖地图使用方法

1. 打开本地 CSV：`local_working_copy/bibliography-1987-entries.csv`（Excel 可读，UTF-8 BOM）
2. 按 `section_slug` 筛选，例如只补“儿童故事”就看 `tales` 分部（113 条）
3. 每条原始文本可回溯到 PDF 页码，进一步找到全文（合法渠道）
4. 与 `INDEX.md` 里的 335 张卡交叉比对，标注“已有卡 / 待补卡”
