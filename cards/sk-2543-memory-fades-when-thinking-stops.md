# Card sk-2543 — 记忆衰退的病因，是该动脑的时候没有动脑

## 原文/Excerpt

> 记忆力的衰退恰恰会发生在少年时期，出现这种现象的原因是，当个人需要尽可能多思考的时候却不想去动脑筋。要引导那些接受能力差的和思想不灵敏的学生去自己弄懂道理，直至恍然大悟。这种醒悟不但对领会具体材料来说是必要的，它也是智能发展的特定阶段。一个人从弄懂道理中得到了愉快，通过自己的努力而获得的真理使他感到惊异，这使一个人增强了自信心，感到自豪和自尊。

## 中文转述/说明

这段把「记不住」和「想不动」接成一条因果：记忆不是独立的仓库，它靠理解过程来维持；不肯用脑去弄清道理，储存本身就开始漏。作者给出的做法不是加大记忆负担（这条路被明确否掉），而是把理解这件事交回学生手上，让他自己走到恍然大悟的那一刻。关键在最后一句的定位——顿悟不只是记住材料的手段，它本身就是智力发展的一个台阶，所以它值得花时间，也值得教师耐心等待。

## 教育场景/应用

- 面对背了很久仍记不住的学生，先别加背诵量，挑一个他能动手弄清的小问题，让他自己讲出道理。
- 把「恍然大悟」的瞬间记进个别观察笔记，作为这个孩子智能进展的证据，而不是只记分数。
- 与家长沟通时，把「多抄几遍」换成「让他给你讲一遍他是怎么想通的」。
