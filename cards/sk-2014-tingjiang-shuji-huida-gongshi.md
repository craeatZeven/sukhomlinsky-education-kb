# Card sk-2014 — 课堂若按“听讲—熟记—回答”运行，思想只是一掠而过

## 原文/Excerpt

> 遗憾的是，在某些教师的课堂上，脑力劳动是按“听讲—熟记—回答”这样一个公式进行的。按照这种公式，思想在学生的意识里只是一掠而过。我曾跟这样一位青年妇女谈过话，她中学毕业后变成一个虔诚的教徒，进了修道院，但是以后又因为阅读自然科学书籍而渐渐摆脱了宗教世界观的影响。

## 中文转述/说明

公式化课堂的后果，苏霍姆林斯基用一个人的经历来说明：她自称当时只是“一部能熟记课本和答老师提问的机器”，思想没有触动过内心，后来进了修道院；真正起作用的是出自兴趣、出自求知需要的读书。这段叙述的价值在于把课堂公式与多年后的世界观连起来——短期看是顺畅高效，长期看是学生没有自己的判断。对今天的课堂，提示要留出“思想停驻”的时间，而不只是让问答环节走得漂亮。

## 教育场景/应用

- 备课时在“听讲—熟记—回答”之外安排一段由学生自己提问并追下去的时间。
- 讲评课上让学生说出“我原来怎么想、现在怎么想”，把思想变化留下痕迹。
- 发现学生只求把答案背对时，改用需要自己找材料、自己下判断的任务。
