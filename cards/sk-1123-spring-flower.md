# Card sk-1123 — 报春花

## 原文/Excerpt

> 太阳唤醒了森林。融化了松树顶上的雪。融化了的雪水滴到雪地上。穿透了雪堆和枯叶。就在雪水滴落的地方，露出一根绿梗。而在绿梗上开出一朵蓝色的铃铛花。它望着雪地，感到惊讶：“我是不是醒得太早啦？”“不，不早，是时候啦，是时候啦”，小鸟一齐唱了起来。于是春天来了。

## 中文转述/说明

卡佳写第一朵报春花怎样从融雪下钻出来。雪水穿透雪堆和枯叶，滴落处露出一根绿梗，绿梗上开出蓝色的铃铛花；花问自己是不是醒得太早，小鸟齐声回答“不早，是时候啦”。整篇像一则微型童话：把季节转换写成花与鸟的对话，把“春天来了”这个判断落在雪、水、绿梗、蓝花和鸟鸣上。

孩子不是先知道“春天到了”再去找景物，而是让景物自己开口说话。这正是苏霍姆林斯基“祖国语言”一节反复强调的：孩子在大自然里感受到美，才有表达美、反映美的愿望。

## 教育场景/应用

- 可用于春季自然观察：找第一朵野花，记录它周围的雪、水、土和鸟声，再写一段话。
- 可用于童话创作：让学生给花、鸟、雪写一段对话，用自己的方式解释“春天为什么来了”。
- 可用于朗读与语感：读“是时候啦，是时候啦”的重复句，体会节奏和期待感。
- 可用于科学衔接：观察后追问报春花为什么在雪还没化尽时就能开放，再查资料验证。
