# Card sk-2263 — 到了每个孩子都渴求创造的那天，所有教师都要成为教育家

## 原文/Excerpt

> 如果每个学生都能热情地、全方位地渴求知识、渴求劳动、渴求创造，那么我们这个世界将成为什么样子呢?这样的时代是一定会到来的。到那时，首先所有的教师都要成为教育家。每个孩子的天赋都会毫无例外地被开发出来，让他们的智慧得以充分发展。让我们社会的道德和知识都发展到这样的高水平，这就是我们的目的，这就是共产主义。

## 中文转述/说明

这条把「教育家」设成一个全员门槛，而不是少数人的头衔：一旦学生的求知欲被普遍打开，靠照本宣科维持的课堂就撑不住了，教师必须自己会研究人、研究怎么教。作者把目标写得很大——道德与知识同时到高位——但路径是从每个孩子的天赋都被开发开始，中间那一环恰恰是教师。对学校的启示是，教师进修别只补学科知识，还要补「怎么看人」这一半；缺了后者，学生越活跃，课堂越难带。

## 教育场景/应用

- 教研会上留一段时间专门谈某个学生，而不是只谈进度和考题。
- 教师进修计划里加入观察儿童、分析个案的内容。
- 判断一节课好不好，看学生有没有提出自己的问题。
