# Card sk-1900 — 为了能够认识美，每个人在童年、少年和青年时代应当受到哪些教育——这个课题还是研究的空白点

## 原文/Excerpt

> 在这个学年结束时，我打算就学校的情感教育问题提出初步的设想，即每个人在童年、少年和青年时代，为了能够认识美，应当受到哪些教育。在我的这些设想中，对学生感官的训练给予很大的注意。这个课题实际上还是教育研究中的一个空白点。

## 中文转述/说明

这条判断的价值在于它把美育问题换成了一个内容清单问题：不问「要不要美育」，而问「为了能够认识美，一个人在童年、少年、青年时代分别应当受到哪些教育」。作者的答案往感官上落——设想中对感官的训练给予很大的注意，并且直说这个课题实际上还是教育研究中的一个空白点。承认空白不等于放弃，而是把美育从口号拉回到需要逐段设计的内容上：每个年龄段该训练哪一种感知、用什么材料、达到什么程度，都要写出来并排出次序。

## 教育场景/应用

- 做美育规划时先按童年、少年、青年三段回答「为了能认识美，各段要受哪些教育」，而不是只写一句「加强美育」。
- 把感官训练单列成条目：每个年龄段训练哪一种感知、用什么材料、达到什么程度。
- 遇到自己学校也说不清的环节，如实标为空白点并列入研究计划，不用现成说法覆盖。
