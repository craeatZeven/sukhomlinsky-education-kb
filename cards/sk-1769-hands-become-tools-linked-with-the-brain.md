# Card sk-1769 — 训练动作的灵活、轻巧与优美，是把少年的双手变成与大脑相联系的劳动工具

## 原文/Excerpt

> 我发现，少年受集体精神生活中各种事件所引起的刺激愈多，则在他们行动的目的与他们在这个动作中所费的体力之间的不协调就愈大。生活告诉我们，训练动作灵活、轻巧和优美是必要的，这是协调体格与精神发展的最为重要的一个组成部分。我训练少年做一些复杂而细腻的动作，这些动作要求技巧与体力的结合。首先我关心的是使少年的双手成为他们灵巧的、技艺高超的，与大脑有着千丝万缕联系的劳动工具。

## 中文转述/说明

作者先从三件很小的事故入手——球打碎玻璃、搬床弄断床脚、关书桌碰落螺丝——把它们归到同一个机制：少年受集体生活中事件刺激越多，行动的目的与所费的体力之间就越不协调。由此得出一个教育结论：训练动作的灵活、轻巧和优美不是体育的附加项，而是协调体格与精神发展的最重要组成部分之一。落点尤其值得记下来：训练复杂细腻的动作，最终是要让少年的双手成为灵巧的、与大脑有千丝万缕联系的劳动工具——手在这里不是被训练的器官，而是心智伸进世界的接口。

## 教育场景/应用

- 把打碎玻璃、弄断床脚这类「事故」当作动作协调问题来读，而不是当作调皮或破坏纪律。
- 排劳动课时为复杂而细腻的动作留出位置，要求技巧与体力结合，而不是只做耗体力的粗活。
- 看学生的手工与劳动成品时，同时看手的灵巧程度，把它当作心智发展的一项指标。
