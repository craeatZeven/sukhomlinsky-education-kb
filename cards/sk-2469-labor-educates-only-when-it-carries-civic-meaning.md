# Card sk-2469 — 劳动只有在带有公民观念时才是教育力量，零散的干活等于零

## 原文/Excerpt

> 多年的经验使我深信：只有当劳动具有某种公民观念时，它才会成为强大的教育力量。如果劳动局限于偶然的日常工作，下一些偶然到手的活计或其他某某人没有干完的活计，这种劳动的教育力量就等于零。

校勘记录（已校勘 3 处，改前→改后）：

- 局限千→局限于
- 日常丁作量→日常工作
- 偶然到于的活计→偶然到手的活计

## 中文转述/说明

这段话把「劳动教育」的成败系在一个很具体的开关上：劳动里有没有公民观念。作者用两条边界说明它——有公民观念的劳动是强大的教育力量；只做些偶然到手的活计、替别人收拾没干完的尾巴，这种劳动的教育力量等于零。值得注意的是「等于零」这个说法不是说效果差一点，而是说它根本不算教育。对学校的启示是：安排劳动时先问这项劳动向学生指向了什么、它属于谁的事情，再谈劳动量。一天干多少活，本身不产生教育。

## 教育场景/应用

- 排劳动任务时先写清这项劳动对谁有用、学生能认出它的意义，再排工时。
- 把「临时抓差」式的打扫、搬运从教育性劳动里剔出去，或明确当作纯粹的校务。
- 学期末回顾劳动清单时逐项标注它指向的公民意义，找不出意义的就不列进教育计划。
