# Card sk-0705 — 多想长得也像爸爸

## 原文/Excerpt

> 3岁的索尼娅长得很像妈妈。她的长相完全跟妈妈一模一样：蓝色的眼睛、黑色的眉毛、淡黄色的辫子、端庄的小小的鼻子、粉红色的嘴唇、长长的睫毛。甚至左耳下的一颗小小的黑痣也与妈妈的一模一样。……不管谁到拖拉机手斯捷潘·彼得连科的家，所有的人都要说：“女儿是多么像妈妈啊……”索尼娅感到很奇怪：为什么她不像爸爸？她问妈妈，妈妈回答说：“等稍微长大一点，也会像爸爸的。”但是索尼娅不想等待。……今天爸爸回来了，在院子里的井边洗脸。索尼娅走到洗脸盆前也开始洗脸了。“索尼娅，你干吗洗脸？”妈妈感到奇怪。“我也想像爸爸。”

## 中文转述/说明

三岁的索尼娅长得和妈妈一模一样：蓝眼睛、黑眉毛、淡黄色辫子，甚至左耳下的黑痣都一样；她笑起来也像妈妈。每个到家里来的人都说她像妈妈，索尼娅因此很奇怪：为什么自己不像爸爸？妈妈安慰她说，等稍微长大一点也会像爸爸的。但索尼娅不想等。晚上爸爸下班回来在井边洗脸，索尼娅也走到洗脸盆前洗脸。妈妈问她为什么，她说：“我也想像爸爸。”

故事捕捉到幼儿对父母的认同与模仿：孩子想通过做和爸爸一样的事，变得像自己爱的人。这种“想长得像爸爸”的愿望不是外貌问题，而是孩子把父母当作榜样的情感表现。教育者不必用成人逻辑纠正，而应看到孩子正在从父母身上寻找自己要成为的样子。

## 教育场景/应用

- 可用于儿童观察：幼儿模仿父母洗脸、干活、说话，是认同与爱的萌芽，成人应珍惜并做好日常示范。
- 可用于家庭榜样教育：回答“我为什么不像爸爸/妈妈”时，可把话题引向“你可以像爸爸一样认真劳动、像妈妈一样善待别人”。
- 可用于亲子讨论：让孩子说说想学爸爸妈妈的哪些优点，帮助他把对外貌的认同转向对品质的认同。
- 可用于家校沟通：家长希望孩子成为什么样的人，先要在日常小事中做给他看，因为孩子真的会照着学。
