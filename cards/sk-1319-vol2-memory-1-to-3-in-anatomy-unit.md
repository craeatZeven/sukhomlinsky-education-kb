# Card sk-1319 — 爱惜并发展青少年的记忆力

## 原文/Excerpt

> 造成这种大灾难的主要原因之一，是少年和青年用儿童的方法去获得知识：分批背熟课本上的材料，为的是后来再分批把自己的知识说给老师听，好得个分数。过多的有意记忆简直可以使入变成傻瓜。
>
> 要做到这一点，惟一的办法是：建立有意记忆和尤意记忆的合理比例关系。如果八年级学生应记住的教材数量用x表示，那么，在这个时期内学:生应理解和思考的教材就应多儿倍，为3x。同时，要记住的教材内容和只要求理解而不是非记住不可的教材内容之间，应有一定的联系———不一定是直接的联系，但最好是与问题相关的联系。例如，解剖学和生理学中研究人的神经系统。这部分教材里有许多完全新的知识，儿乎都应当记住。为使学习不致变成死记硬背，可建议学生看些关于入体的有趣书籍，以了解入体的各种器官、神经系统以及著名科学家在这些方面的研究成果。学生从并不要求记住的阅读中会记住许多乐西，但这完全足另一种记忆，是无意记忆，同学生有意地去记住教材内容是有质的区别的。这种识记建立在兴趣、思考和读书入了迷的基础上，认识的情感因素在这里起着很大的作用。……多年的经验使我确信，如果有意记忆以无意记忆为基础，即以阅读和思考为基础，那么，少年学生在学习课本的过程中就会产生许多问题。他知道得越多，他不懂的地方就越多；不懂的地方越多，他按照教科书学正课就越容易。
>
> 建立无意记忆和有意记忆的合理比例关系，这首先取决于教师。……你对新教材的叙述和讲解，应含有星星之火，它能点燃学生勤奋好学和渴求知识的火药。听了你的课后，学生应有强烈的愿望阅读你顺便提到过的书籍。他应念念不忘这种书，一定要找到它。
>

## 中文转述/说明

这是“有意记忆∶无意记忆＝1∶3”这一比例在解剖学·神经系统单元里的落地课例。教材数量用 x 表示，同一时期内学生应理解与思考的教材应为 3x；两部分内容之间要有联系，不一定是直接联系，但最好是与问题相关的联系。神经系统这一单元里几乎全是必须记住的新知识，正因为如此，最容易变成死记硬背。

苏霍姆林斯基的配书办法是：建议学生读一些关于人体的有趣书籍，了解人体各种器官、神经系统以及著名科学家在这些方面的研究成果。这些读物并不要求记住，但学生从中记住了许多东西——那是无意记忆，与有意去记教材有质的区别：它建立在兴趣、思考和读书入了迷的基础上，认识的情感因素起很大作用。

无意记忆怎样托住有意记忆？他的经验是：有意记忆以无意记忆为基础，即以阅读和思考为基础，少年学习课本时就会产生许多问题——知道得越多，不懂的地方越多；不懂的地方越多，按教科书学正课反而越容易。所以查“背了就忘”时，不该只查学生背了多少遍，而应查他这一单元背后有多少“不必记”的阅读与思考撑着。这也把责任落回教师：讲解里要含“星星之火”，学生听完课应有强烈愿望去找你顺便提到的那本书。

## 教育场景/应用

- 备中高年级以记忆为主的单元（神经系统、化学方程式、地理名词等）时，先配一份“不必背的读物清单”，让无意记忆有来源。
- 用 1∶3 做自我检查：这一单元要求记住 x 的内容，是否安排了约 3x 的理解性阅读与思考材料；两者最好与同一问题相关，而不是各说各话。
- 遇到“背了就忘”的学生，先问他读过什么相关的书、课上想过什么问题，而不是只加重背诵遍数。
- 讲新课时留一两句“顺便提到”的书名或问题，把学生的阅读兴趣接到本单元上。
- 与 sk-1096（现有卡）连读：sk-1096 给出记忆比例关系的方法原则，本卡是同一比例在解剖学·神经系统单元的具体课例——配什么读物、无意记忆怎么托住有意记忆、怎么查“背了就忘”，一张是规则，一张是现场。
