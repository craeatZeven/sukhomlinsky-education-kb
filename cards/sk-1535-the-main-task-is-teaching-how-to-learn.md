# Card sk-1535 — 低年级的主要任务是教会儿童学习

## 原文/Excerpt

> 然而，低年级阶段的主要任务还是教会儿童学习。应当教会他们使用那种工具，没有它，儿童掌握知识就会--年比一年感到吃力；没有它，儿童的成绩渐渐就会不及格，他们就会变得缺乏能力。

校勘记录（已校勘 1 处，改前→改后）：

- 口具→工具

## 中文转述/说明

他强调低年级阶段的主要任务还是**教会儿童学习**：应当教会他们使用那种工具 —— 没有它，儿童掌握知识就会一年比一年感到吃力；没有它，成绩渐渐就会不及格，他们就会变得缺乏能力。同页他还点出后果：低年级和以后各学习阶段之间的脱节，就从这里产生。

## 教育场景/应用

他把「工具」当成可以交到手里的东西，而不是等它自己长出来。
