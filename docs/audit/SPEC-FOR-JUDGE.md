# 分类规格（判读用）

## 元规则

> **主归属以卡片所收原文直接支持的中心主张为准。**标题用于检索和提出候选，
> 编辑转述用于辅助理解；**二者均不得覆盖原文**，也不得补入未经核验的分类依据。
>
> 先写明「本文对什么对象提出了什么判断或要求」，并指出对应原文；
> 再区分其中的**主张 / 理由 / 手段 / 例子 / 背景**，按**主张所回答的问题**选类。
>
> 原文明示的「首先、关键、应当、目的」可以作为证据，但**不按首句位置、词频或标题自动定案**；
> 也**不得一律按最远端教育目标分类**——否则阅读、劳动、艺术都会被吸进「全面发展」。
>
> 两个主张确实并列且无可见主次时，标「**待拆分**」，**不按编号强行破平局**。

## 五个观察角度（不是层级，只是看教育的不同角度；只用来帮助定位，选条目按定义）

| 角度 | 回答的问题 |
|---|---|
| 宗旨 | 教育要把孩子培养成什么样的人？ |
| 立场 | 怎么看待儿童、怎么对待儿童？ |
| 教育关系与组织 | 教育在什么关系里发生、由谁承担？ |
| 内容与方法 | 教什么、怎么教？ |
| 衡量 | 怎么反馈、怎么评价？ |
| 关照 | 面向哪一类具体孩子（**复分标签**：不参与主归属分区，只给相关卡片加标记） |

## 条目定义（**判读只看「收录什么 / 不收录什么」这两栏**）

| 编号 | 名称 | 角度 | 收录什么 | 不收录什么 |
|---|---|---|---|---|
| A1 | 全面发展与个性 | 宗旨 | 宗旨层的总纲：和谐发展、个性、世界观与理想——**持卡**（共现多不等于没有中心论点） | 阅读、劳动、艺术各自的主张（**不得按最远端目标吸进来**） |
| A2 | 公民与祖国 | 宗旨 | 人的社会维度：公民意识、祖国情感、社会理想、义务感、把个人确立为社会力量的信念 | 一般道德故事（归故事域 / A19） |
| A3 | 幸福与精神生活 | 宗旨 | **主张本身在评价幸福或精神生活的状态** | 情感、心灵只是用来解释其价值或机制的段落（讲德性归 A19、讲美育归 A14、讲劳动归 A11） |
| A4 | 自我教育 | 宗旨 | 教育的终点：自我要求、意志、自律；**道德信念与知行合一**（知道规范 ≠ 形成信念） | 一般德育内容（归 A19）；教师对学生的外部要求（归 A10/A16） |
| A5 | 尊严、爱与信任 | 立场 | **规范教育者对儿童的态度与行为**：爱护、尊重、信任、明智的严格、教育者的爱 | **规定儿童应形成的品质或行善动机**（归 A19）；教师自身的成长与学校管理（归 A10） |
| A6 | 了解儿童 | 立场 | 怎么认识儿童：观察、兴趣、个别对待、了解学生的志向 | 一般儿童故事（归故事域）；年龄阶段特征本身（归 A21） |
| A7 | 健康与作息 | 内容与方法 | **儿童身体这一"教学内容"**：作息制度、户外、饮食、疾病与疲劳（原在「立场」，评审后移入） | 体育课的具体教案（暂缺） |
| A8 | 家庭与母亲 | 教育关系与组织 | 第一教育关系：母亲、父亲、家庭精神生活、家校沟通 | 学校内部的集体生活（归 A9）；只是顺带提到母亲/父亲的段落 |
| A9 | 集体与同伴 | 教育关系与组织 | 学校里的教育关系：集体的形成、同伴关系、共同劳动 | 家庭内部关系（归 A8） |
| A10 | 教师 | 教育关系与组织 | **教师自身的成长与学校管理**：专业发展、读书、自由时间、教研、校长工作 | 一切「教师作主语」的段落（**主语不构成依据**）；怎么上课（归 A22）；对儿童的态度（归 A5） |
| A11 | 劳动与创造 | 内容与方法 | 手脑并用的途径：劳动与智慧、手工与技术、创造；劳动与珍惜（付出心血才懂珍重） | 把劳动当惩罚的论述（归 A16 批评点） |
| A12 | 自然与思维课 | 内容与方法 | **明确规定自然观察活动或「思维课」这一具体课程**的组织、内容或作用 | 只论观察、记忆、语言等一般认知机制、没有课程或自然对象限定的（归 A15） |
| A13 | 阅读与书籍 | 内容与方法 | **规定读什么、怎样读、怎样组织阅读** | 论证一般思维机制或学习动机、阅读只作实例的（归 A15）；教师自身读书（归 A10） |
| A14 | 美与艺术 | 内容与方法 | **主张在谈美育内容本身**：音乐、绘画、审美敏感 | 自然观察（归 A12）；以「美德 / 美好 / 教育艺术」泛称出现的段落 |
| A15 | 思维与智力 | 内容与方法 | 智育方法：思维训练、记忆与注意、想象、学习动机、语言与思考的联结 | 思维课这一具体课程（归 A12）；学生自己的学习技能（归 A23） |
| A16 | 评价与分数 | 衡量 | 怎么判定一个孩子：分数、表扬与批评、惩罚的边界；**反对形式主义评比** | 检查与考查的具体做法（归 A20）；学生的自我评价（归 A4） |
| A17 | 习惯与纪律 | 内容与方法 | **日常规训这一教育内容**：习惯养成、纪律与自由（原在「衡量」，评审后移入） | 集体纪律的建设（归 A9） |
| A19 | 道德判断与品德培养 | 宗旨 | **规定儿童应形成的道德品质、行善动机或对他人的行为**；教师实施培养**不**使它转入 A5 | 教育者对儿童的态度行为（归 A5）；具体帮扶某个孩子（归 A18 标记） |
| A20 | 检查知识与考查 | 衡量 | 怎么知道学生会不会：检查知识的方法、复习与巩固、提问与回答（实测全文命中 91 张，其中 84 张原不在 A16） | 分数与奖惩本身（归 A16） |
| A21 | 儿童发展与年龄阶段 | 立场 | **把某个年龄阶段的特征、或某个发展转折本身当作论述对象**：学前期、少年期、青年期、生理与心理的成熟 | 某个年龄段的具体教育做法（归相应条目，如作息归 A7、德育归 A19） |
| A22 | 教学方法与教育艺术 | 内容与方法 | **怎么上一节课、怎么讲一段话、怎么呈现一段教材**：教学法、教育艺术、教师的语言、隐蔽的教育意图 | 教师自身的成长与学校管理（归 A10）；学生怎么学（归 A23） |
| A23 | 学习方法与学习技能 | 内容与方法 | **学生自己那一端的学**：学习方法、学习技能、时间安排、笔记与书写 | 教师教的方法（归 A22）；读什么书（归 A13） |

> 注：另有 **A18 学习困难学生**是「复分标签」，不参与主归属——凡谈这类孩子的卡片都加此标记，
> 但主归属仍按内容另选一条。判读时**不要选 A18**。
