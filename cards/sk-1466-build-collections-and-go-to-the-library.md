# Card sk-1466 — 从低年级开始藏书，并带学生去图书馆

## 原文/Excerpt

> 因此，我建议从低年级开始藏·书，然后逐步教学生利用学校的图书馆。对这件事绝不可放任自流。要跟自己所教的学生一道去学校图书馆，向他们介绍那里的书籍，建议他们可以借哪些书来阅读。要给图书管理员开列阅读推荐书目（当然，书目应包括藏书架上陈列的书籍）。

## 中文转述/说明

他的办法是从低年级就开始藏书，然后逐步教学生利用学校图书馆；而且这件事**绝不可放任自流** —— 要跟自己教的学生一道去图书馆、介绍那里的书、建议借哪些，还要给图书管理员开推荐书目。

## 教育场景/应用

「一道去图书馆」是关键：让学生自己在书架前站一会儿，比发一张书单有用。
