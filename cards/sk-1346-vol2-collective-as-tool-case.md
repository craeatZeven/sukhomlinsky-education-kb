# Card sk-1346 — 集体是教育的工具，怎样建立集体它靠什么来维持

## 原文/Excerpt

> 集体—儿童的、少年的、青年的集体，是很复杂的统一体。这是由成千上万条溪流汇合成的江河。集体是渐渐地建立起来的。……我感到有-种说法很幼稚：集体借以维持的主要东西，是严格要求和组织上的从属制度。……严格要求、责任心、服从和领导，都是集体借以维持的非常重要的基础，但如果没有其他同样重要的基础，那就没有，也不可能有集体。……集体并不是一种不知来自何处的东西。集体是教师的创造。在集体中，如在水滴中一样，反映出的是教师的教育理想和他的世界观。……我认为，形象地说，集体是在共同的思想、共同的智力、共同的情感、共同的组织这几个基石之上建立起来的。……我认为，集休的建立是从思想一致开始的，它是组织一致这块基石所依靠的根底。……对于奠定集体的最初基础来说，非常重要的是要让儿童努力做好事，为善良而斗争，通过集体活动建立福利。……在共同斗争的同志关系中，个人会认识另一个人，会产生极重要的精神需要—需要别人，需要别人给他支援，给他帮助。一个人在管（领导）别人之前，先要学会管自己，迫使自己做自己良心吩咐的事情。……我的青年朋友！你要善于通过劳动把学生联合起来，因为在劳动中鲜明地表现了为人民服务，为人们的福利贡献力量的思想。……例如，学生眼前就有一块空地，他们已经对路旁这块成了垃圾场的空地习以为常，视而不见。你要让他们看见这块空地，想在这里造出一片多荫的小树林，作为炎夏酷暑时感到倦怠的行路人休息的地方。……请记住，为人们的幸福而从事集休劳动，就是真正思想教育的初步。在这种劳动中，集休的思想基石和情感基石相一致并结合起来了。……用空话是进行不了教育的。集体是在实践活动中，在斗争和劳动中产生和巩固起来的。

## 中文转述/说明

这个案例的起点是一个被普遍误解的前提：很多教师以为选出几个领导者、分好职责、提出严格要求，集体就建起来了。苏霍姆林斯基说这种希望在实践上是无结果的——严格要求和组织上的从属制度是集体赖以维持的重要基础，但只有这一块，就不可能有集体。集体不是凭空产生的东西，它是教师的创造，在水滴里映出的是教师的教育理想和世界观。

他给出的建立顺序是：先有共同的思想（对善与恶、对“什么是好与什么是坏”的一致概念），再谈共同的组织。所以他没有从选班干部开始，而是从让儿童努力做好事、为善良而斗争、通过集体活动建立福利开始。在这一步上，儿童获得最初为好事而斗争的道德经验，尝到了这种斗争的快乐——而这种快乐最初只能来自共同建立某种美好的事情。在共同斗争的同志关系里，人才会认识到需要别人、需要别人给他支援和帮助；在管别人之前，先要学会管自己。

具体做法是把学生“通过劳动联合起来”，因为劳动中鲜明地表现出为人民服务、为人们的福利贡献力量的思想。案例里的场景很朴素：路旁有一块已经成了垃圾场的空地，学生习以为常、视而不见。教师要做的是让他们看见这块空地，想在这里造出一片多荫的小树林，作为炎夏酷暑时行路人休息的地方。为人们的幸福而从事集体劳动，就是真正思想教育的初步——在这类劳动中，集体的思想基石和情感基石一致并结合起来了。

最后是一条操作纪律：不要让学生对开始做了的事半途而废、前功尽弃，这会使人变坏；也不要让学生只会说这也不好、那也不好，而一点也不动手去做好事。用空话是进行不了教育的，集体是在实践活动中、在斗争和劳动中产生和巩固起来的。

## 教育场景/应用

- 新建班级或新接班时，先做一件有公益意义的集体劳动（种一片小树林、整理一段空地、为行人做一处休息点），再谈班规与职责分工，顺序不要颠倒。
- 挑项目遵循“被忽视但有价值”的原则：学生天天路过却视而不见的角落，最容易转化为“我们让它变好”的集体记忆。
- 劳动项目要能善始善终：一次劳动安排到看得见成果为止，宁可小而完整，也不要大而半途而废。
- 把“说”和“做”分开检查：不允许出现只会批评“这也不好那也不好”却不动手的学生，教师自己也以身作则先动手。
- 班干部产生放在集体劳动之后：让组织权威来自劳动中自然形成的榜样，而不是先给头衔再要求威信。
