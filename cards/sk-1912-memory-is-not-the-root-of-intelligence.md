# Card sk-1912 — 不能先训练记忆再造智力

## 原文/Excerpt

> 我在课堂上研究过落后儿童的脑力劳动情况，并且同时对天赋好的儿童进行观察。毫无疑问，儿童劳动的效率在很大程度上取决于记忆。但是，能不能做出结论说首先训练记忆，然后发展智力呢？能不能说记忆是条件，而脑的完善的机能性活动是结果呢？换句话说，能不能先用某种急进的手段来改善记忆，并以此来对智力的发展施以影响呢

> 说明：原文该段末尾的“呢”后无标点（扫描件此处断句缺失），本卡按句意完整截到该设问句末，未改动原文。

## 中文转述/说明

苏霍姆林斯基在这里拆的是一个流行的因果链：先把记忆练好，智力自然跟着发展；记忆是条件，脑的完善的机能性活动是结果。他没有直接否定，而是把它还原成三个必须分别验证的设问，并且强调这些是他在课堂上同时观察落后儿童和天赋好的儿童之后提出的。这层意思对今天的教学仍然锋利：如果记忆力与智力发展之间只是相关而非因果，那么「多背、多重复」就不一定把人变聪明，甚至可能占用掉真正起作用的那一环。作者用提问的方式给出了一个可检验的研究纲领，而不是一句结论。

## 教育场景/应用

- 教师集体备课讨论「基础差就先抓背诵」时，把这段话当议程：先设计一个能分开「记住」与「想明白」的小任务，看两类学生各自在哪一步卡住。
- 给一个背得很快但理解停留在表层的孩子换任务——让他解释、举例、提问，而不是继续加重复次数，观察他的理解是否随之变化。
- 教研组把「记忆是条件、智力是结果」这类说法列为待验证假设：每学期用一组课堂观察去核对，允许结论被推翻。
