# Card sk-1682 — 评价是教师手里的一种教育工具，而不是惩罚

## 原文/Excerpt

> 评价是教师手里的一种教育工具，它应当激发儿童的学习愿望，帮助形成这种愿望，而不是对于不愿学习的一种惩罚。如果由于学生不善于学习而给他一个不及格的评价，那就更糟：儿童觉得教师已经把他看得什么都不行，他就会欺骗和弄虚作假。学生不善于学习，如果教师不重视这件起初的小事，那就会酿成大祸—懒惰和散漫。

## 中文转述/说明

这一段把评价的性质说透了：评价的作用是激发并扶住学习愿望，一旦它被当成对「不愿学习」的报复，工具就变成了反工具。苏霍姆林斯基点出最坏的一种情形——学生本来是不会学，教师却给不及格，孩子于是认定自己被判了「什么都不行」，接下来不是努力而是欺骗和弄虚作假。他对教师的要求是：先把「不会学」当成需要教的事，而不是需要罚的事，否则懒惰与散漫会接踵而来。

## 教育场景/应用

- 给低分之前先问一句：他是没学，还是不会学？若是后者，先补方法、给台阶，暂缓打分。
- 写评语时把「努力的程度」与「能力的结果」分开写，别让一个分数替两者下结论。
- 对同一个学生控制评价频次，避免天天打分让分数贬值、让孩子对评价麻木。
- 出现抄袭、撒谎时，先回看自己上一次的评价是否把他逼到那一步，再处理行为本身。
