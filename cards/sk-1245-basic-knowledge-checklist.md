# Card sk-1245 — 让学生记住基本知识

## 原文/Excerpt

> 我从事学校工作30年，发现了一个依我看是重要的秘密—一条独特的教育规律：中、高年级出现落后和成绩不好的现象，主要是由于学生在低年级学习时没把作为知识基础的基本真理牢牢地保存在记忆中终生不忘。……你们从一年级开始工作时，要把四年级的教学大纲拿来，首先要拿语文和数学的教学大纲，还要拿五年级的数学教学大纲。此外，也要拿历史、白然、地理的课外读物和这些课在四年级的教学大纲。把所有这些材料加以对照和比较，并考虑.下为使学生能在四年级和五年级顺利地学习，三年级的学生需要知道什么。……俄语中有2000至2500个单词，好比是识字和知识的骨架。经验说明，儿蛮如果在小学牢固地记住了这些单词，他就会成为-个识字的人。……我把2500个单词分配为每个工作H让学生学3个单词。……我认为，非常重要的一种练习是记住400个修辞短语，我坚信，它们可以说是种最基本的语言修养框架。……在低年级学习期间，学生在数学方面要记住一些基本的运算，这些运算由于常用，就成了十分熟练的数学概括，以至每次用时不必花脑筋去想。这不仅是指乘法表，也包括最经常使用的1000以内的加减乘除。……我的出发点是，中、高年级学生的智慧不应担负很重的单词作业，以使尽可能多地把脑力用于创造性的工作。

## 中文转述/说明

这份“必须终生牢记”的清单不是凭经验随手列的，而是从高年级大纲倒推出来的。苏霍姆林斯基要求小学教师从一年级起就动手：把四年级的语文、数学教学大纲拿来，还要拿五年级的数学教学大纲，再加上历史、自然、地理的课外读物和这些课在四年级的大纲，把所有这些材料加以对照和比较，弄清一件事——为使学生能在四年级和五年级顺利学习，三年级的学生需要知道什么。

倒推出来的清单有分层。第一层是骨架：俄语中2000至2500个单词，好比识字和知识的骨架，在小学牢固记住，学生才成为一个识字的人，而小学学会的识字是中、高年级掌握知识的工具。第二层是框架：400个修辞短语，是最基本的语言修养框架，专门收录因日常用语影响而常犯的典型错误；另有600个“童话”单词，用来巩固最低限度词汇。第三层是工具：数学上要记住乘法表和1000以内最常用的加减乘除，练到由于常用而成为熟练的数学概括，每次用时不必花脑筋去想。

清单还要落到年级分工和日常节奏上：2500个单词分配到每个工作日学3个，写在长期使用的生字本上；上课时堂堂课做各种练习，让已记住的单词经常得到复习和使用；再用游戏成分和自我检查（回家路上回想、早晨醒来默写）维持长期记忆。这样做有明确的出发点——让中、高年级学生的智慧不再担负很重的单词作业，把尽可能多的脑力用于创造性工作。换句话说，清单不是越长越好，而是把“终生要用的最小集合”在小学阶段练到自动化。

## 教育场景/应用

- 可用于编制“终生识记清单”：先拿高年级乃至毕业年级的大纲、考试要求，倒推低年级该牢固记住什么，再逐项确认“是否终生要用”。
- 可用于年级衔接：把清单拆成各年级识记任务（字词量、修辞短语、运算熟练度），明确写出“到四年级前必须自动化”的项目。
- 可用于日常落实：把清单切成每天三五分钟的固定小练习，配一本长期使用的生字本，并让课堂练习持续复习使用它们。
- 可用于给清单分层：骨架（单词）、框架（修辞短语）、工具（运算）三个层次，各配不同的练习方式与验收标准。
- 可用于减负论证：以“中、高年级学生的智慧不应担负很重的单词作业”为理由，把重复性识记前移到低年级完成。
- 与 sk-1039（现有卡）连读：sk-1039 用“地基与楼房”说明基本知识为什么必须牢固，本卡补的是这份清单“怎么列、怎么倒推、怎么分工”的操作步骤。
