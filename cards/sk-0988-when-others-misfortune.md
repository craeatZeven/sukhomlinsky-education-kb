# Card sk-0988 — 当他人遇到不幸时，你怎么办

## 原文/Excerpt

> 我们打算到郊区做一次有趣的旅行，到那里去已准备好多天了……一切都已准备就绪，可突然发生了不幸：一年级学生加利娅的父亲得了重病，送进了医院。怎么办？可以让孩子们丢下别人的不幸不管；旅行的欢乐也会把他们头脑里关于加利娅的思绪挤掉，但是，这就意味着在孩子们的心头上“冻结”一层冰。不行，决不能这样做。我向孩子们解释，加利娅在承受着她家里的多么大的不幸，如果我们去旅行，她会怎么想呢。孩子们很难放弃自己的愿望，但他们懂得，他们的欢乐是要付出丢下他们的女同学的不幸不管为代价的。

## 中文转述/说明

全班为一次郊区旅行准备了很多天，临出发前却出了不幸：一年级学生加利娅的父亲得了重病，住进医院。苏霍姆林斯基面临选择——可以让孩子们丢下别人的不幸不管，让旅行的欢乐挤掉对加利娅的惦记，但那等于在孩子心上“冻结”一层冰。他选择向孩子们解释加利娅一家正在承受的痛苦；孩子们虽然很难放弃自己的愿望，却懂得欢乐要以丢下女同学的不幸为代价是不值得的，最终放弃了旅行。苏霍姆林斯基把这件事称作一堂“精神上的慷慨奉献、愿望上养成守纪律以及人的共同参与课”。

## 教育场景/应用

- 可用于集体决策：当集体活动与某个成员的困难发生冲突时，把决定权交给孩子充分讨论。
- 可用于移情教育：让孩子设身处地想一想“如果我是加利娅，会怎么想”。
- 可用于愿望的纪律：不把放弃旅行说成牺牲，而说成“我们选择不做那种对别人不幸装看不见的人”。
- 可用于防止集体孤立：明确“全班转过身去不理一个同学”，比利己主义更糟。
