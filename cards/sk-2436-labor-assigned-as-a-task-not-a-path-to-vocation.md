# Card sk-2436 — 学校安排了劳动，却没有把它当成培养志向的手段

## 原文/Excerpt

> 但是，这种劳动无论如何也还没有成为每个学生的精神需求，没有使他们产生兴趣，给他们带来灵感。很多青年学生，还没有把本来应该成为人们重要需求的劳动，像阅读有趣的书籍，幻想未来的国家一样，构筑进自己的现实计划和长远规划中去。现在很多学校里，给高年级的学生都安排劳动，但是遗憾的是，这仅仅是为了完成劳动任务的计划，却没有把它当成培养学生志向的一种手段，也没有把它当成引导青年人走上能找到自己在生活中的位置，能找到个人幸福的正确之路的现实可能性。

## 中文转述/说明

这段批评的是一种普遍做法：劳动已经进了学校，却没有进入学生的精神需求——它没有引起兴趣，也没有带来灵感，因而没有被学生写进自己的现实计划和长远打算。更具体的问题出在用意上：安排劳动只是为了完成劳动任务的计划，而不是当成培养志向的手段，也没有把它当作一条现实的路，让学生借此找到自己在生活中的位置和幸福。区别很实在：一边是完成指标，一边是让学生在劳动中看见自己的可能。

## 教育场景/应用

- 安排劳动前先问：这次劳动能不能让学生看见自己的某种能力，而不只是完成任务量。
- 让学生把劳动写进自己的学期计划与长远打算（想继续做什么、下一步学什么）。
- 检查劳动教育时看两件事：学生是否主动延续这件事，以及它是否指向某个具体志向。
