# Card sk-1774 — 对学习困难学生的内部精神世界要特别关注：冷淡会把他们推向说教

## 原文/Excerpt

> 对那些学习上感到困难、尚未显露出创造性劳动的明显才能的少年儿童和青年男女的内部精神世界，要特别予以关注。如果对他们表示冷淡，他们就会感到自己孤独，就会由于认为自己不够格而深感苦恼，而这对宗教的说教及其观点的传播则是最适宜的土壤。

## 中文转述/说明

这段话的落点不是「学习差怎么办」，而是「不许对这类孩子冷淡」。作者把学习困难、一时显不出才能的少年儿童单列出来，要求特别关注他们的内部精神世界；紧跟的是一句警告——冷淡会让孩子感到孤独，并因自认不够格而苦恼，而这种状态恰恰是宗教说教最容易扎根的土壤。这一层因果在今天的班级里同样成立，只是趁虚而入的东西换掉了：可能是网络上的算命，也可能是各类极端说辞。判据因此变得很实用：一个班怎样对待学得最慢的那几个孩子，直接决定他们会不会去别处找解释体系。

## 教育场景/应用

- 接手一个班时，先把「学得最慢、还看不出特长」的那几个孩子圈出来，把对他们的关注写成具体安排，不停留在态度上。
- 发现某个孩子沉迷算命、玄学或极端说辞时，先查他最近在班里是否被冷落、是否常因成绩被比较。
- 评价一次补差：不只看分数有没有上去，看这个孩子在集体里是否还感到自己受欢迎、有分量。
