# Card sk-1689 — 只有襟怀坦白的人才能是有坚定信念的人

## 原文/Excerpt

> 只有襟怀坦白的人才能是有坚定信念的人。真理的胜利是培养坚定的共产主义信念的极为重要的条件，它跟胆小怕事、谨小慎微是毫不相容的。恐惧心会扼杀勇敢精神。会摧残对邪恶、虚伪和欺骗行为的不调和态度。教师要明确地认识到自己的培养目标——培养为共产主义而奋斗的积极而坚定的战士，他要经常关心如何使自己的学生在无畏中表现诚实，在诚实中表现无畏。

## 中文转述/说明

苏霍姆林斯基把「勇敢」当作信念的前提来处理：恐惧会先掐掉愤怒与不妥协，人就再也长不出立场。所以他给教师的检验标准很朴素——学生敢不敢说真话。培养方法也落在日常：孩子因疏忽做错事时不用惩罚吓他，否则他学会的是隐瞒而不是诚实。他把目标写成一句对仗的话：在无畏中表现诚实，在诚实中表现无畏。两者在他那里是一件事的两面，缺一样都不成立。

## 教育场景/应用

- 孩子主动承认错误时，先处理事情本身，把「说实话」这一点当场肯定下来。
- 对撒了谎的学生，先分辨他是害怕后果还是习惯欺骗，前者先降低惩罚压力。
- 班里出问题时，教师自己先示范承认判断失误，让学生看到坦白不会带来灾难。
- 观察哪些孩子在课堂上从不敢表达不同意见，把他们作为重点，给安全的发言机会。
