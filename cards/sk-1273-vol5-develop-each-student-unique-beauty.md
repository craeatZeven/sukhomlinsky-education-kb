# Card sk-1273 — 开发出每个学生独特的人格之美

## 原文/Excerpt

> 有几次，我和孩子们一一起在田野上、在树林里活动，在这里，巴甫利克与在教室里相比完全变成了另外一个人。他给我和他的小伙伴们讲述他自己所观察到的一些动植物的有趣现象。他的讲述让我感到吃惊，因为他善于第一眼就发现那些事物与事物之间和现象与现象之间的无形的联系。……按自然课老师的说法，他的智慧就“在手指尖上”。……“那我能不能试试呢？”孩子问。这时他的眼里闪着愉快的光。……我们的学生人学后的最初几天、最初几周（在个别情况下甚至可以延续几个月），是他们熟悉高年级学生所从事的各种各样的劳动形式的阶段。让学生们在从事各种各样的创造性劳动的氛围中努力去做他们力所能及的工作，让他们试着从一项工作转向另一项工作，这并不危险。在学生进行探寻的这个最初阶段里，我们认真研究他们的兴趣和能力……学生对劳动的兴趣有时表现得很冷漠。……这只能说明我们还没有找到开发他创造力的形式，没有为他营造出一种把自己的智慧表现为动手能力的环境。

## 中文转述/说明

观察什么：不看孩子在课堂上的读写反应，而看他在自然与劳动现场的行为。巴甫利克在教室里被判定“思维迟钝”“对自然景物和自然现象都无动于衷”，到了田野和树林里却完全变成另一个人——他讲自己观察到的动植物现象时，能“第一眼就发现事物与现象之间的无形联系”。另一类同等重要的信号是手：自然课老师说他的智慧“在手指尖上”，即动手的精度与技巧超出同龄水平。所以观察指标至少两组：发现联系的能力，和手上有无技巧。

多久记一次、记多久：入学后的最初几天、最初几周，个别情况下可以延续几个月，是学生熟悉各种劳动形式的“探寻期”。这个阶段允许孩子从一项工作转向另一项工作，苏霍姆林斯基明确说“这并不危险”。教师在探寻期的任务是研究兴趣和能力，而不是提前下结论；记录频率应落在“孩子在哪件事上停留最久、提问最多、动手最细”这类可追踪的观察上。若一个学生长期对什么都冷漠，结论不是“他没有天赋”，而是“我们还没有找到开发他创造力的形式，没有为他营造出把智慧表现为动手能力的环境”。

怎么变成任务：观察到能力之后，必须把它落成一项具体的、可长期跟踪的劳动任务。巴甫利克在嫁接课上提出“能不能不嫁接就直接培育树苗”，教师没有用一句“别胡思乱想”掐掉，而是回答“可以，但这非常难”，带他去温室、教他准备和进行实验。一个问题由此变成一项持续数年的实验，能力从偶发表现变成稳定特长，并反过来带动了智力发展。

## 教育场景/应用

- 观察什么：把观察场所从教室搬到现场（田野、树林、实验室、工作间），记录两类信号——孩子能否指出别人没看到的联系，动手精度是否明显超出同龄水平。
- 多久记一次：入学后设 2 周至 3 个月的“探寻期”，允许换项目；教师每周至少记录一次每个学生在哪个项目上停留最久、提问最多，探寻期内不写“有没有能力”的结论。
- 怎么变成任务：把孩子自己提出的疑问直接转成可长期跟踪的实验任务（如“能不能不嫁接就培育树苗”），教师提供条件、教方法、允许失败，让能力从偶然表现变成稳定特长。
- 长期冷漠先归因于环境而非孩子：面对“对什么都不感兴趣”的学生，先自问“我是否为他营造了把智慧表现为动手能力的环境”，再考虑其他解释。
- 与 sk-0272（现有卡）连读：sk-0272 立论“所有孩子都有才，关键在找到并开发其独有能力”，本卡给这条立论配操作面——观察什么、多久记一次、怎么把发现变成任务。
- 与 sk-0273（现有卡）连读：sk-0273 用珠宝匠作比讲心法，本卡讲具体工序；一个是“为什么必须这么做”，一个是“下一步做什么动作”。
