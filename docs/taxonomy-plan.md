## 二、定稿结构：域 › 界 › 纲 › 目 › 卡片

采用「界门纲目」式的**显式层级命名**——名字本身就说明它在哪一层，读者不会再把地基和钥匙并排看。

```
域 (2)   论述域（他论教育，718 张）      故事域（他写给孩子，668 张）
  │
  ├─ 论述域
  │    界 (5)   总纲界 · 前提界 · 场域与主体界 · 内容与方法界 · 工具与评价界
  │      纲 (18)  E1–E18（E18 学困生为「横切纲」，可跨界出现）
  │        目     每个纲下 2–5 个目（由该纲关键词组自然形成，见 §三示例）
  │          卡片
  │
  └─ 故事域
       界 (2)   通读界（原书顺序）·  分面界（主角 / 处境）
         纲     主角：母亲与家人 / 动物 / 同伴 / 成人 / 老人
                处境：自然与季节 / 美与歌 / 劳动 / 帮助他人 / 学校与学习 /
                      离别与非 / 恐惧 / 羞愧与良心
           目     每一篇故事
```

**「总纲界」的处理（决策 2）**：目的层（E1–E4）**做成总纲页**，在导航与地图上作为独立一界（一级入口）出现，**不作为并列筛选复选框**——目的是纲，不该和「评价与分数」平起平坐。筛选器里保留一个「总纲」折叠组，需要时可展开。

## 四、故事域：按「主角 + 处境」分面（决策 3）

**为什么不能按教育主题切**：用品格词扫 668 篇故事，是长尾——妈妈 31%、美 17%、劳动 11%，其余全部 <6%（诚实 1.2%、勇敢 2.2%、分享 0.7%）。这些故事**每篇是独立情境**，不是主题的例证。

**为什么「主角 + 处境」成立**：同样扫一遍分面词，**99% 的故事至少落进一个分面**（对比主题词只有 75%）：

| 分面 | 篇数 | 占比 |
|---|---|---|
| 处境：自然与季节 | 428 | 64.1% |
| 主角：母亲与家人 | 367 | 54.9% |
| 处境：美与歌 | 307 | 46.0% |
| 处境：劳动 | 224 | 33.5% |
| 处境：帮助他人 | 165 | 24.7% |
| 主角：动物 | 163 | 24.4% |
| 主角：成人（教师/司机/农艺师…） | 144 | 21.6% |
| 处境：学校与学习 | 136 | 20.4% |
| 主角：同伴 | 126 | 18.9% |
| 处境：离别与非 | 110 | 16.5% |
| 处境：恐惧与害怕 | 90 | 13.5% |
| 处境：羞愧与良心 | 79 | 11.8% |
| 主角：老人 | 59 | 8.8% |

**关键理由**：老师家长的检索意图是「**孩子怕黑**」「**想要讲妈妈的故事**」——处境与主角比抽象主题更接近真实问题。

**三层组织**：
1. **通读界**：按原书页码顺序读完 541 篇（现有 `stories.html` 已如此，保留）；
2. **分面界**：按上面 13 个纲筛选（新增）；
3. **选集**：10–20 组人工策展，按**使用场景**组织（如「一年级开学第一周」「亲子共读十分钟」「第一次面对失去」），带一段导读。

**故事卡仍保留教育主题作次标签**（搜索「诚实」能命中相关故事），但**不参与主归属与地图面积**。

**篇幅数据**（决定选集怎么做）：中位数 222 字，四分位 126–301 字，最长 804 字——都是 1–3 分钟能读完的短篇。**发现 1 篇摘录为空（0 字），迁移时一并核查。**

## 六、一次性切换的迁移步骤（决策 4：不保留旧 slug 并存）

每步跑 `python scripts/validate_all.py`，任一步失败即停。

| 步 | 动作 | 产物 / 验证 |
|---|---|---|
| 1 | 新建 `taxonomy.yml`：18 纲 + 13 故事分面的定义（名称、界、关键词、收录说明） | 单一事实源，页面与脚本都读它 |
| 2 | `scripts/classify_cards.py`：按 IDF 规则给每张卡写 `primary`（论述）或 `story_facets`（故事） | 建议值 + 复核清单（得分接近第二名的卡） |
| 3 | 人工复核清单：约 150–200 张，抽检与修正 | 修订写回 `taxonomy.yml` 的例外表 |
| 4 | 卡片 frontmatter 重写：`topics:` → `primary` + `facets`；**旧 12 个 slug 全部删除**（一次性） | `check_kb.py` 校验 frontmatter 合法性 |
| 5 | 生成 18 个纲页 + 6 个界页 + 1 个总纲页 + 13 个故事分面页（`topics/` 目录重写） | 每页含「收录什么 / 不收录什么」判定规则 |
| 6 | 站点改造：`topics.html` 分层、`explore.html` 按界/纲筛选、`stories.html` 加分面、`clusters.html` 标注每簇对应的纲 | 审计脚本全绿 |
| 7 | 地图：纵轴 = 5 界，每界内按纲面积 ∝ 主归属数；故事域单独一块不参与主题面积 | 面积合计 = 1386 |
| 8 | 文档同步：`docs/kb-status.md`、`INDEX.md`、`SKILL.md`、`web/README.md` | 全链路 ALL OK |

**外部影响提醒**：`explore.html?topic=<旧slug>` 这类外链会失效（一次性切换的代价）。已在方案内接受；如需保留，可在 Nginx/Pages 侧做 301（Pages 不支持，故只在站内做一次「旧地址 → 新地址」的提示页）。

## 八、本规划的验证门槛（写进 `validate_all.py`）

1. 每张卡有且只有一个 `primary`（或 13 个故事分面之一）；
2. 每个纲的主归属数量落在 **15–200**；
3. 最大纲占比 ≤ **20%**；
4. 故事分面覆盖率 ≥ **95%**；
5. 无摘录为空的卡片（当前 1 张待修）。
