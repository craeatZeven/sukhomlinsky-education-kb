# Card sk-1419 — 教育者的使命是让孩子自愿变好

## 原文/Excerpt

> 教育者的使命就在于去教会孩子们，青少年去追求美好的东西，去逼迫自己思想好，做好事，对自己心灵上的消极和懒惰要有不满感。我们应当启迪自己的学生们有一股精神力量，使他们想成为好人，而且使这种愿望能成为他们自愿的劳动。

校勘记录（已校勘 1 处，改前→改后）：

- 删乱码书眉「迪自已分審姆林斯基选集五在么的学」
- 回补误删正文「启迪自己的学生们有」
- 自已→自己

- **存疑说明**：已按页图（卷2 扫描件第 458—459 页）核对：458 页止于「我们应当启迪自己」，459 页起于「的学生们有一股精神力量」—— 回补正确

## 中文转述/说明

教育者的使命是让孩子**自己想成为好人**，并把这种愿望变成自愿的劳动。

## 教育场景/应用

判据是“自愿”：靠外部奖励撑起来的“做好事”，不算这一条达成。
- 与 [[sk-1391]] 连读：同一命题的案例面：五岁谢辽扎「应当—困难—好」的完整链条。
